# 报考条件与全流程时间表

> 这一份是"操作手册"：什么时候做什么、准备什么材料、报名系统怎么填、哪一步最容易错。

---

## 一、报名前先自查：你符合条件吗

按顺序打勾，任何一项不满足都要先解决：

- [ ] 中国公民，拥护中国共产党领导，遵守宪法和法律
- [ ] 未因犯罪受过刑事处罚；未被撤销过教师资格
- [ ] 学历达标（见下表，**以本省公告为准**）
- [ ] 能选择户籍地 / 居住证地 / 学籍地之一作为报考考区
- [ ] 在校生：已到可报考年级（一般本科三年级及以上、专科毕业年级）
- [ ] 能在认定前拿到普通话证书（语文二甲 / 其他二乙）

### 学历要求速查

| 报考学段 | 《教师法》最低学历 | 实际报名常见要求 |
|---|---|---|
| 幼儿园 | 幼儿师范学校毕业及以上 | 大专及以上（多数省份） |
| **小学** | **中等师范学校毕业及以上** | **大专及以上（绝大多数省份）** |
| 初级中学 | 高等师范专科或其他大学专科及以上 | 大专及以上 |
| 高级中学 / 中职 | 高等师范院校本科或其他大学本科及以上 | 本科及以上 |

> 关键提示：**以本省当年报名公告为准**。个别省份对师范类中专学历有过渡政策，也有省份对非全日制学历另有说明（学信网可查即可）。

### 报考地三选一（只能选一个）

| 身份 | 可选报考地 | 需要的证明 |
|---|---|---|
| 社会人员 | 户籍地 | 身份证 / 户口本 |
| 社会人员（异地） | 居住证所在地 | **有效期内的居住证**（办理通常需 6 个月社保或居住登记，务必提前办） |
| 在校生 | 学籍所在地 | 学生证 / 在籍学习证明 |

**最高频的报名失败原因**：异地报考却没有有效居住证。**如果你打算异地考，现在就去办居住证**，别等到报名那几天。

## 二、笔试报名操作流程（每期一样）

| 步骤 | 做什么 | 注意 |
|---|---|---|
| 1. 注册 | 登录「中小学教师资格考试网」ntce.neea.edu.cn，注册账号 | 手机号要能收验证码，一个手机号只能注册一个账号 |
| 2. 填写个人信息 | 姓名、身份证号、学历、学校、照片 | **照片要求**：近 6 个月白底证件照，JPG/JPEG，不大于 200KB，295×413 像素；不合格会被退回 |
| 3. 选择考区与科目 | 选省份、考区、报考科目（小学两科可同时报） | 考区名额有限，**尽早报**，热门城市很快满 |
| 4. 等待审核 | 多数省份网上审核，1–2 个工作日；少数需现场审核 | 审核期间随时登录看状态，被退回按提示修改重交 |
| 5. 缴费 | 审核通过后在线缴费，约 60–70 元/科 | **逾期未缴费视为放弃报名**，这是第二大翻车点 |
| 6. 打印准考证 | 考前一周开放 | 用 A4 纸黑白打印即可，多打两份 |
| 7. 参加考试 | 带身份证 + 准考证 + 黑色签字笔 + 2B 铅笔 + 橡皮 | 提前踩点，迟到 15 分钟不得入场 |

### 报名常见问题

| 问题 | 处理 |
|---|---|
| 照片上传失败 | 用证件照工具裁剪到 295×413、压缩到 200KB 以内、确认是白底 |
| 学历填错 | 审核前可自行修改；审核通过后联系考区 |
| 考区已满 | 换邻近考区，或等下期 |
| 忘记缴费 | 只能等下期，报名费不退（也没交） |
| 身份证过期 | 提前换证，考试当天必须有效身份证 |
| 报名信息与身份证不一致 | 一律以身份证为准，报名信息必须完全一致 |

## 三、考试当天安排（笔试）

| 时间 | 科目 | 时长 | 满分 |
|---|---|---|---|
| 上午 9:00–11:00 | 综合素质（小学） | 120 分钟 | 150 |
| 下午 13:00–15:00 | 教育教学知识与能力 | 120 分钟 | 150 |

（具体时间以准考证为准；部分地区下午场为 13:00 或 13:30 开考，务必看清准考证。）

**要带**：身份证、准考证、2B 铅笔、黑色签字笔（2 支）、橡皮、手表（非智能）。
**不要带**：手机（关机放指定位置）、智能手表、任何资料。

---

## 四、成绩查询与复核

- 查询入口：ntce.neea.edu.cn「成绩查询」。
- 报告分满分 120，**70 分及以上合格**。
- 对成绩有异议：在成绩公布后规定期限内（一般 5–10 个工作日）向报考考区提出复核申请，复核只查漏评、错统、漏统，不重新评卷。
- 两科都合格 → 才能报名面试；只过一科 → 2 年内补考另一科。

## 五、面试报名与考试

| 项目 | 内容 |
|---|---|
| 报名条件 | 笔试全部科目合格且在有效期内 |
| 选学科 | 小学可选语文、数学、英语、音乐、体育、美术、科学、信息技术、心理健康、道德与法治等（以本省开考科目为准） |
| 费用 | 一般 200–300 元（各省不同） |
| 流程 | 候考 → 抽题 → 备课 20 分钟 → 结构化 5 分钟（2 题）→ 试讲 10 分钟 → 答辩 5 分钟 |
| 合格线 | 满分 100 分，60 分合格 |
| 注意 | 面试学科建议与未来考编方向一致；试讲必须"无生上课"（没有学生但要演出互动） |

## 六、教师资格认定（最后一步，材料最多）

### 认定时间

各省一般每年组织 **2 次**（春季 3–6 月、秋季 9–12 月），具体看本省教育厅/认定机构公告。合格证明 3 年内必须完成认定。

### 认定材料清单

| 材料 | 说明 |
|---|---|
| 身份证 | 原件 + 复印件 |
| 学历证书 | 原件；学信网《教育部学历证书电子注册备案表》 |
| 普通话水平测试等级证书 | 语文二甲及以上，其他二乙及以上 |
| 《中小学教师资格考试合格证明》 | 中国教育考试网自行下载打印 |
| 体检表 | 指定医院按《教师资格认定体检标准》体检，有效期一般 1 次认定周期 |
| 近期免冠正面 1 寸彩色白底照片 | 若干张，与网报同版 |
| 户籍/居住证/学籍证明 | 与报考地口径一致 |
| 个人承诺书 | 网报系统内下载签名 |
| 无犯罪记录证明 | 部分地区由认定机构统一核查，不需要个人提供 |

### 认定流程

```
中国教师资格网（www.jszg.edu.cn）注册 → 网上申报（选认定机构、填信息、上传材料）
  → 提交 → 现场确认 / 线上审核 → 体检（部分省份体检在网报前）
  → 认定机构审核 → 公示 → 制证 → 领取证书（可邮寄）
```

**提醒**：认定必须选对认定机构——一般幼儿园/小学/初中教师资格由**县级**教育行政部门认定，高中/中职由**市级**认定。选错要重新申报。

## 八、一页纸清单：现在到考前要做的 12 件事

1. 查本省最近一期报名公告，确认学历与报考地要求。
2. 异地报考的，立刻去办居住证。
3. 注册 ntce.neea.edu.cn 账号，熟悉界面。
4. 拍一张合规白底证件照（295×413、<200KB），存好电子版。
5. 准备普通话测试报名（很多省份每月都有场次，越早越好）。
6. 打印本套资料的 `02-90天备考计划`，填入自己的日期。
7. 准备错题本（纸质或电子表格）。
8. 关注本省教育考试院公众号，开启报名提醒。
9. 确认考试用笔、手表、身份证有效期。
10. 报名开启当天上午就完成填报，避开系统拥堵。
11. 缴费后截图保存报名成功页面。
12. 考前一周打印准考证并踩点。
