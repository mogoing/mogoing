# 第三章 班级管理

> 本章的特点是"**理论少、实务多、好得分**"。它不像心理学那样抽象，绝大多数考点都能在真实班级情境中"想出来"。但也正因为感觉容易，很多人背得笼统，答题时写不出"组建—核心形成—发展—成熟""教师促成、集体促成、任务促成、自我促成"这样的标准表述。本章材料分析题出现频率很高，务必把**四张表**（班集体形成阶段、班级管理模式、课堂纪律类型、偶发事件处理原则）背到能默写。

## 一、班级与班集体

### 1. 班级的概念与功能 ★★★

| 要点 | 内容 | 怎么考 |
| --- | --- | --- |
| 班级的概念 | 学校为实现一定的教育目的，将**年龄和知识程度相近**的学生编班分级而形成的、有固定人数的**基本教育单位** | 单选 |
| 班级的产生 | 最早出现于 **16 世纪西欧**；**夸美纽斯**在《大教学论》中奠定了**班级授课制**的理论基础 | 单选（高频） |
| 班级的地位 | 是学校教育的**基本单位**，是学生实现个体社会化的基本途径 | 单选 |
| 班级的功能 | ①**社会化功能**（传递社会规范、培养社会角色）；②**个性化功能**（促进个体发展、形成独特个性）；③**选择功能**（为学生未来发展提供分类与选择）；④**保护功能**（保护学生身心安全） | 单选、简答 |
| 班级与班集体的区别 | 班级是**组织形式**（行政单位），班集体是班级**发展的高级形态**，是班级群体发展到一定阶段的产物 | 单选（高频） |

### 2. 班集体的形成阶段（必背四阶段） ★★★★★

| 阶段 | 别称 | 主要特征 | 班主任的角色 | 怎么考 |
| --- | --- | --- | --- | --- |
| **①组建阶段** | 孤立期 | 学生互不熟悉，班级缺乏凝聚力；成员各自为政，依赖班主任 | 班主任**直接指挥**，事无巨细地管理 | 单选（极高频） |
| **②核心形成阶段** | 形成期／同化期 | 班级涌现出积极分子，**班干部队伍初步形成**；学生开始认同班级目标 | 班主任**指导**班干部工作，逐步授权 | 单选 |
| **③发展阶段** | 成熟期 | 班集体目标明确，班干部能独立开展工作，正确舆论与良好班风初步形成 | 班主任**引导**，发挥集体自我教育作用 | 单选 |
| **④成熟阶段** | 完善期 | 集体成为教育主体，能自主管理、自我教育，舆论健康，凝聚力强 | 班主任**放手**，做幕后的支持者与顾问 | 单选 |

> **记忆口诀**："**组—核—发—成**"，班主任的管理方式也相应从"**直接管**"→"**指导管**"→"**引导**"→"**放手**"。
>
> **易错点**：班集体形成的**标志**不是"选出了班干部"（那是核心形成阶段），而是"**形成了正确的舆论和良好的班风**"以及"**具有共同奋斗目标**"。

### 3. 良好班集体的基本特征（六条必背） ★★★★★

1. **明确的共同奋斗目标**（方向，是班集体形成的首要标志）；
2. **健全的组织机构**和坚强的**领导核心**（班委会、团支部/少先队中队）；
3. **严格的规章制度**与共同的生活准则（班规班约）；
4. **正确的舆论**和**良好的班风**（最重要的标志，是班集体成熟的标志）；
5. **开展丰富多彩的集体活动**（**集体活动是形成班集体的基础**，是凝聚集体的纽带）；
6. 成员之间**平等、友爱、互助**的人际关系，学生有较强的集体荣誉感。

**班集体的教育作用**：①有利于形成学生的群体意识与社会性；②有利于培养学生的社会交往与适应能力；③有利于训练学生的自我教育能力；④是班主任进行教育工作的**得力助手**与依靠力量。

### 4. 组织和培养班集体的方法 ★★★★

| 方法 | 要点 | 怎么考 |
| --- | --- | --- |
| 确定共同的奋斗目标 | 目标要**由易到难、由近及远，分阶段递进**；先有近期目标，再有中、远期目标 | 简答 |
| 选拔和培养班干部 | 民主选举与教师培养相结合，形成坚强的领导核心 | 简答 |
| 建立严明的规章制度 | 班规要由师生共同制定，简单明确、可执行 | 简答 |
| 培养正确的舆论和良好的班风 | 通过表扬批评、树立榜样、专题讨论形成集体舆论 | 简答（高频） |
| 开展丰富多彩的班级活动 | 活动是班集体形成的**基础与载体** | 简答 |
| 做好个别教育工作 | 面向全体，兼顾后进生与特长生 | 简答 |

## 二、班级管理

### 1. 班级管理的概念、内容与功能 ★★★

**概念**：班级管理是班主任按照一定的原则和具体要求，对班级中的各种资源进行计划、组织、协调、控制，以实现教育目标的组织活动过程。它是一种**有目的、有计划、有步骤**的社会活动。

| 项目 | 内容 |
| --- | --- |
| **管理内容** | ①班级**组织建设**（班委会、小组、少先队中队）；②班级**制度管理**（班规、考勤、值日）；③班级**教学管理**（配合任课教师、学习管理）；④班级**活动管理**（班会、文体、社会实践）；⑤班级**文化管理**（班风、环境、舆论）；⑥**偶发事件与问题行为**管理 |
| **管理功能** | ①**维持功能**（维持班级秩序，形成良好班风）；②**促进功能**（促进教学目标实现，提高学习效率）；③**发展功能**（锻炼学生能力，学会自治自理） |
| 班级管理的根本目的 | **促进学生的发展**，实现教育目标 |

### 2. 班级管理的基本原则 ★★★

| 原则 | 内涵 |
| --- | --- |
| **科学性原则** | 遵循教育规律与学生身心发展规律，科学决策、科学管理 |
| **民主性原则** | 尊重学生主体地位，让学生参与班级管理，班主任不搞一言堂 |
| **整体性原则** | 面向全体学生，协调各方面教育力量，促进全面发展 |
| **针对性原则** | 从班级和学生实际出发，区别对待、因班施管 |
| **教育性原则** | 管理即教育，管理与教育相结合，寓教育于管理之中 |
| **发展性原则** | 着眼于学生的长远发展，培养自我管理能力 |
| **有效性原则** | 讲求管理效率与实效，避免形式主义 |
| 规范性原则 | 依法依规、有章可循 |

> **最核心的一条**：**教育性原则**——班级管理不是"管住学生"，而是"通过管理育人"。

### 3. 班级管理模式（四种必背） ★★★★★

| 模式 | 代表人物/来源 | 核心内涵 | 优缺点 | 怎么考 |
| --- | --- | --- | --- | --- |
| **常规管理** | — | 通过制定和执行**规章制度**来管理班级日常事务（考勤、值日、作业、纪律） | 稳定有序，但易僵化，需与弹性管理结合 | 单选 |
| **平行管理** | **马卡连柯** | 班主任既通过对**集体**的管理去间接影响个人，又通过对**个人**的直接管理去影响集体，把集体与个人管理结合起来（"**平行教育影响**"） | 有利于通过集体教育个人，效率高 | 单选（极高频）、材料分析 |
| **民主管理** | — | 班级成员在班主任指导下，**共同参与**班级事务的决策与管理（班委会、班级议事会、值日班长轮换） | 主体性强，培养责任感与参与能力；但需班主任引导 | 单选（高频） |
| **目标管理** | **德鲁克**（目标管理理论） | 班主任与学生**共同确定目标**，以目标为导向、以成果为标准进行管理，强调**自我控制** | 方向明确、激励性强；目标需具体可测 | 单选（极高频） |

> **区分技巧**："通过集体影响个人、通过个人影响集体"→ **平行管理**；"师生共同定目标、以目标为导向"→ **目标管理**；"人人参与、轮流当班干部"→ **民主管理**；"靠班规制度"→ **常规管理**。

## 三、班主任工作

### 1. 班主任的角色与地位 ★★★★

依据教育部《中小学班主任工作规定》（2009 年）：

| 要点 | 内容 |
| --- | --- |
| 角色定位 | 班主任是**班级的组织者、领导者和教育者**，是中小学日常思想道德教育和学生管理工作的**主要实施者**，是中小学生健康成长的**引领者**，要努力成为中小学生的人生导师 |
| 地位 | 是学校领导的**得力助手**，是联系各任课教师的**纽带**，是沟通学校、家庭、社会的**桥梁** |
| 任职规定 | 由学校从班级任课教师中选聘；担任一个班级的班主任时间一般应**连续 1 学年以上** |
| 工作量 | 按当地教师标准课时工作量的**一半**计入基本工作量 |
| 待遇 | 应享受相应的岗位津贴；教育行政部门和学校应将其工作表现作为**评优评先、职务晋升**的重要依据 |

### 2. 班主任工作的内容（八项，必背） ★★★★★

| 序号 | 工作内容 | 关键点 | 怎么考 |
| --- | --- | --- | --- |
| ① | **了解和研究学生** | 是班主任工作的**前提和基础**；方法有观察法、谈话法、调查法、书面材料分析法 | 单选（极高频） |
| ② | **组织和培养班集体** | 是班主任工作的**中心环节/首要任务** | 单选（极高频） |
| ③ | 建立学生成长档案 | 收集学生基本信息、成绩、作品、评价 | 单选 |
| ④ | **做好个别教育工作** | 面向全体，重点是**后进生的转化**与**特长生的发展** | 简答、材料分析（高频） |
| ⑤ | **组织班会活动和课外活动** | 班会分**常规班会**与**主题班会**；主题班会是主要形式 | 单选 |
| ⑥ | **协调各种教育影响** | 统一任课教师、家庭、社会、少先队等各方力量 | 简答 |
| ⑦ | **操行评定** | 一学期一次，以《中小学生守则》为依据，客观公正、以激励为主 | 单选 |
| ⑧ | 写好班主任工作计划与总结 | 计划与总结要具体、有针对性 | 单选 |

> **口诀**："**了组档个，班协评计**"——了解学生、组织班集体、建档案、个别教育、班会活动、协调影响、操行评定、计划总结。

**后进生的转化（材料分析高频答题点）**：
1. **查明原因**：是学习基础、家庭因素、心理因素还是同伴影响，对症下药；
2. **关心爱护**，消除戒备心理，建立信任（"亲其师，信其道"）；
3. **发现闪光点**，用优点克服缺点（长善救失）；
4. **降低起点、小步子前进**，让他们不断获得成功体验；
5. **培养学习兴趣与习惯**，教给学习方法；
6. **形成教育合力**：与任课教师、家长配合，保持一致；
7. **抓反复、反复抓**，允许反复，持之以恒。

### 3. 班主任工作的方法 ★★★

| 方法 | 内涵 |
| --- | --- |
| **说理教育法** | 摆事实、讲道理，以理服人 |
| **榜样示范法** | 以优秀人物、教师自身、同伴榜样影响学生 |
| **实际锻炼法** | 通过班级活动、值日、社会实践训练行为 |
| **情感陶冶法** | 通过班风、环境、活动氛围潜移默化地感染学生 |
| **心理咨询法（心理疏导法）** | 通过谈心、倾听、共情帮助学生排解心理困扰 |
| **评价激励法** | 通过表扬、奖励、操行评定激励学生 |

### 4. 班干部的选拔与培养（"选、育、用"三步） ★★★★

| 环节 | 要点 |
| --- | --- |
| **选拔** | ①**民主选举**（最重要，学生认可度高）；②自荐与推荐相结合；③班主任考察指定（新生班初期可用）；④注意能力与责任心兼顾，不只看成绩 |
| **培养** | ①明确职责分工，制定工作守则；②**教给工作方法**（如怎样组织活动、怎样处理同学矛盾）；③**放手让他们干**，允许犯错，在实践中锻炼；④严格要求，防止骄傲，接受同学监督；⑤实行**定期轮换**（如值日班长制），让更多学生得到锻炼 |
| **使用** | ①信任支持，树威信；②定期评议，班主任及时指导；③把握"用其所长、避其所短"；④不把班干部当"告密者"，避免班干部与同学对立 |

### 5. 操行评定 ★★★

| 要点 | 内容 |
| --- | --- |
| 含义 | 以《中小学生守则》等为依据，对学生**一个学期**内在学习、劳动、品行等方面的小结与评价 |
| 方式 | 等级评定法、操行评语（最常见）、学生自评与互评结合 |
| 要求 | ①**客观公正、实事求是**；②**有针对性**，写出个性而非套话；③以**表扬鼓励为主**，指出努力方向；④措辞恰当，注意保护学生自尊；⑤结合平时记录，不凭印象 |

## 四、班级文化建设

### 1. 班级文化的内涵与结构 ★★★★

| 层次 | 内容 | 地位 | 怎么考 |
| --- | --- | --- | --- |
| **物质文化**（表层） | 教室布置、班级标识（班徽、班旗）、卫生环境、图书角、墙报、座位安排 | 班级文化的**外在体现与载体** | 单选 |
| **制度文化**（中层） | 班规班约、考勤制度、值日制度、奖惩制度、班级公约、班级议事规则 | 班级文化的**保障** | 单选 |
| **精神文化**（深层） | 班风、班训、班级目标、班级舆论、价值取向、人际关系、集体荣誉感 | 班级文化的**核心与灵魂** | 单选（极高频） |

### 2. 班级文化建设的途径 ★★★

1. **明确班级精神**：提炼班训、班风、班级口号，形成共同的价值追求；
2. **优化班级环境**：精心设计教室布置（墙报、荣誉栏、图书角），让"每一面墙都会说话"；
3. **健全班级制度**：由师生共同制定班规，做到"有章可循、有章必循"；
4. **培育正确舆论**：通过班会讨论、评比表彰、批评与自我批评形成健康舆论；
5. **开展班级活动**：以活动为纽带增强凝聚力、形成班级特色；
6. **重视人际关系建设**：营造平等、友爱、互助的师生关系与同伴关系。

> **答题要点**：班级文化建设的核心是**精神文化**，其形成的**最高标志是良好班风与正确舆论**。

## 五、班级活动的组织

### 1. 班级活动的主要类型 ★★★

| 类型 | 举例 |
| --- | --- |
| **班会** | **常规班会**（每周例行，总结布置工作）、**主题班会**（围绕一个主题展开的教育活动，是最主要的形式） |
| 晨会（晨检） | 每日的常规教育、时事、安全提醒 |
| 文体娱乐活动 | 运动会、文艺会演、朗诵比赛、课本剧 |
| 社会实践活动 | 参观、访问、志愿服务、社会调查 |
| 劳动实践活动 | 值日、大扫除、种植、手工 |
| 科技活动 | 科技小制作、科学实验、观察记录 |
| 少先队活动 | 入队仪式、主题队会、红领巾活动 |

### 2. 组织班级活动的原则与步骤 ★★★★

**原则**：①**目的性**（有明确教育目标）；②**教育性**（寓教育于活动）；③**针对性**（切合学生年龄特点与班级实际）；④**自主性**（学生是活动的主体，教师指导而非包办）；⑤**趣味性**（形式生动活泼）；⑥**全员性**（面向全体，人人参与）；⑦**安全性**（生命第一，做好安全预案）。

**步骤**：①**确定主题**（从学生需要和班级问题出发）→ ②**制定方案**（目标、内容、时间、分工、物资、安全预案）→ ③**做好准备**（宣传动员、分工培训、场地物资）→ ④**组织实施**（过程把控、随机应变、安全第一）→ ⑤**总结反思**（成果展示、表彰、经验总结）。

> **材料分析关键句**："活动设计要发挥学生的主体作用，教师只做指导者"——这体现自主性原则，是素质教育与新课改的学生观要求。

## 六、课堂管理

### 1. 课堂管理的功能与影响因素 ★★★

| 项目 | 内容 |
| --- | --- |
| **功能** | ①**维持功能**（维持课堂秩序，保证教学进行）；②**促进功能**（创设良好课堂气氛，促进学习）；③**发展功能**（培养学生自我管理能力） |
| **影响因素** | ①**教师因素**（教学能力、人格威信、管理方式、期望）；②**学生因素**（学习动机、自控力、个性、同伴影响）；③**课堂环境**（物理环境：座位、光线、噪音；心理环境：气氛、人际关系）；④**课堂规则**（是否明确、合理、被认同）；⑤**教学内容与节奏**（难度、趣味性） |

### 2. 课堂气氛（三种类型） ★★★★

| 类型 | 特征 | 学生的反应 | 怎么考 |
| --- | --- | --- | --- |
| **积极的课堂气氛** | 师生关系融洽，学生情绪饱满、思维活跃、参与度高，纪律良好 | 主动思考、积极发言、互助合作 | 单选 |
| **消极的课堂气氛** | 气氛沉闷、冷漠，学生紧张、被动、注意力涣散 | 被动听讲、不愿发言、敷衍应付 | 单选 |
| **对抗的课堂气氛** | 师生对立，学生有意违反纪律、敌视教师，秩序混乱 | 起哄、顶撞、故意捣乱 | 单选（高频） |

**创设良好课堂气氛的策略**：①树立教师威信（人格魅力与专业能力）；②建立和谐师生关系（尊重、民主、公正）；③采用启发式教学，激发兴趣；④合理控制教学节奏，张弛有度；⑤及时强化与鼓励；⑥妥善处理问题行为。

### 3. 课堂纪律（四种类型必背） ★★★★★

| 类型 | 含义 | 举例 | 怎么考 |
| --- | --- | --- | --- |
| **教师促成的纪律** | 由教师通过制定规则、监督奖惩而形成的纪律 | 教师制定的课堂常规、奖惩办法 | 单选（极高频） |
| **集体促成的纪律** | 由班集体（同伴群体）的舆论与压力而形成的纪律 | 为了不给班级丢分而遵守纪律 | 单选（极高频） |
| **任务促成的纪律** | 由具体学习任务的吸引力与要求而形成的纪律 | 完成小组任务时高度投入、自觉守纪 | 单选 |
| **自我促成的纪律** | 学生把外部规范**内化为自身要求**，自觉自愿遵守 | 无人监督也认真听讲 | 单选（最重要、**最高水平**） |

> **记忆提示**：从"教师管"→"集体管"→"任务管"→"自己管"，**自我促成的纪律是课堂纪律发展的最高阶段**，也是课堂管理的最终目标。

**课堂纪律的形成过程**（可参考皮亚杰、科尔伯格的他律—自律思路）：**强制阶段 → 认同阶段 → 内化阶段**（由他律走向自律）。

### 4. 课堂问题行为的处置 ★★★★

**常见课堂问题行为**：交头接耳、走神发呆、做小动作、看课外书、起哄、顶撞教师、迟到早退、攻击同学。

**处置原则**：
1. **最小干预原则**——能用眼神解决的不用语言，能课下解决的课上不点名；
2. **不中断教学原则**——尽量在推进教学的同时化解问题；
3. **尊重学生原则**——不讽刺、不体罚、不当众羞辱；
4. **预防为主原则**——通过优化教学、明确规则减少问题行为发生；
5. **一致性原则**——同一问题前后处理方式一致，对所有学生一视同仁。

**处置方法（由轻到重）**：

| 层级 | 方法 | 说明 |
| --- | --- | --- |
| 1 | **非言语暗示** | 眼神注视、停顿、走近学生、手势示意（最快、最不伤自尊） |
| 2 | **言语提示** | 用提问、点名、暗示性语言提醒，或表扬其旁边守纪律的同学（**替代强化**） |
| 3 | **课后个别谈话** | 了解原因，讲明道理，共同约定改进办法 |
| 4 | **与家长沟通** | 形成教育合力，共同寻找原因 |
| 5 | **行为矫正** | 运用强化、消退、代币制等方法系统干预 |
| 6 | 纪律处分 | 依校规进行，须符合规定，避免体罚与变相体罚 |

## 七、家校沟通与家访

### 1. 家校沟通的意义与方式 ★★★

**意义**：①形成教育合力，保证教育影响的一致性；②全面了解学生，提高教育的针对性；③争取家长理解与支持，优化育人环境；④促进家长教育观念的更新。

| 方式 | 特点与要求 |
| --- | --- |
| **家访** | 最直接、最深入的方式；分**普访**（面向全体）、**重点访**（针对问题学生）、**随访**（随机） |
| **家长会** | 面向全体家长，介绍班级情况、交流教育方法；忌变成"成绩通报会"或"批评会" |
| 家长学校/家庭教育讲座 | 系统提升家长教育素养 |
| **家长委员会** | 家长参与学校与班级管理，形成民主监督与支持机制 |
| 书面与网络沟通 | 家校联系册、电话、微信、班级公众号；注意保护隐私、控制频率 |
| 接待家长来访 | 热情、平等、耐心，不居高临下 |

### 2. 家访的要求 ★★★★

1. **目的明确**——事先想好要了解什么、沟通什么，准备好学生在校表现材料；
2. **提前预约**——尊重家长时间，突然造访易引起反感；
3. **态度诚恳、平等**——不训斥、不告状，与家长共同商量教育办法；
4. **以表扬鼓励为主**——先肯定优点再谈问题，做到"报喜也报忧"，切忌"一见面就数落"；
5. **尊重家长与学生隐私**——不向他人泄露家庭情况；
6. **做好家访记录**——便于后续跟进与教育衔接；
7. **注意安全与礼节**——不接受宴请与礼品，遵守师德规范。

## 九、偶发事件处理与教育机智

### 1. 偶发事件的特点与处理原则 ★★★★

**偶发事件**：在教育教学过程中突然发生的、出乎教师预料的、需要教师立即处理的事件。特点是**突发性、偶然性、不确定性、影响面广**。

| 处理原则 | 内涵 | 怎么考 |
| --- | --- | --- |
| **沉着冷静** | 遇事不慌、控制情绪，不冲动发火，避免事态扩大 | 材料分析（极高频） |
| **因势利导** | 把突发事件转化为教育契机，"化消极因素为积极因素" | 材料分析（极高频） |
| **教育为主** | 以教育学生、促进成长为目的，而非单纯惩罚或"下台阶" | 简答 |
| **当机立断** | 该立即处理的（安全、伤害）迅速处置，不拖延 | 简答 |
| **共同协调** | 涉及多方时争取学校、家长、任课教师配合 | 简答 |
| **掌握分寸** | 处理适度，既解决问题又不伤害学生自尊，不扩大影响 | 简答 |

**处理流程**：①迅速控制局面、保障安全 → ②了解事实、弄清原委 → ③冷静分析、判断性质 → ④妥善处理、教育引导 → ⑤事后跟进、总结反思。

### 2. 教育机智 ★★★★

| 要点 | 内容 |
| --- | --- |
| 概念 | 教师在教育教学过程中面对**突发情境**时，迅速、恰当、灵活地作出反应，采取有效教育措施的能力 |
| 性质 | 是教师劳动**创造性**的突出表现，是教师教育素养的综合体现 |
| 主要表现 | ①**善于因势利导**（顺着事情的发展趋势加以引导）；②**随机应变**（灵活调整教学方案）；③**掌握分寸**（处理适度、恰如其分）；④**对症下药**（针对不同学生的特点采取不同办法） |
| 形成条件 | ①高尚的师德与教育责任感；②深厚的专业知识与广博的学识；③丰富的教育实践经验；④敏锐的观察力与灵活的思维；⑤稳定的情绪与良好的心理素质 |

**经典案例答题话术**：
- "该教师面对突发情况沉着冷静，体现了良好的**教育机智**"；
- "教师没有简单批评，而是**因势利导**，把偶发事件转化为教育契机"；
- "教师**掌握分寸**，既维护了课堂秩序，又保护了学生的自尊心"；
- "教师善于**随机应变**，体现了教师劳动的**创造性**"。

2. **C**。平行管理，源于马卡连柯的平行教育思想。

4. **D**。自我促成的纪律是学生把规范内化为自觉要求，是最高水平、也是课堂管理的最终目标。

9. ①沉着冷静；②因势利导；③教育为主；④当机立断；⑤共同协调；⑥掌握分寸。
10. 精神文化主要包括班风、班训、班级目标、班级舆论、价值取向、人际关系和集体荣誉感。它是班级文化的**核心与灵魂**，其形成的最高标志是形成良好的班风和正确的舆论，对学生的价值观与行为习惯具有潜移默化的深远影响。
