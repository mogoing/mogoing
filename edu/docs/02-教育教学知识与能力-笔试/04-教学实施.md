## 一、教学过程

### 1.1 教学过程本质的几种学说（选择题考点，认名字即可）

| 学说 | 核心主张 | 代表人物/关键词 |
|---|---|---|
| 特殊认识说 | 教学过程是一种特殊的认识过程 | 凯洛夫体系、我国通行表述 |
| 发展说 | 教学过程的本质是促进学生发展 | 赞科夫"发展性教学" |
| 实践说 | 教学过程是一种实践活动 | 强调动手、做中学 |
| 交往说 | 教学过程是师生交往、沟通的过程 | 强调对话、互动 |
| 传递说 | 教学过程是知识经验的传递 | 强调传承 |

**通行教材结论（背诵原文）**：教学过程是**教师根据一定社会的要求和学生身心发展的特点，有目的、有计划地引导学生掌握系统的文化科学基础知识和基本技能，发展学生智力和体力，培养良好思想品德和审美情趣的过程**。就其本质而言，教学过程是一种**特殊的认识过程**，同时也是一个**促进学生身心发展的过程**。

**为什么说它"特殊"（4 个特殊性，简答可拆条）**：

1. **认识的间接性**——学生主要学习间接经验（书本知识），而不是事事亲历。
2. **认识的交往性**——认识活动在师生、生生的交往互动中完成。
3. **认识的教育性**——认识过程同时是受教育、受熏陶的过程。
4. **有领导的认识**——学生的认识是在教师指导下进行的，不是自发摸索。

> **怎么考**：单选常问"教学过程本质上是一种（特殊的认识过程）"；简答可问"简述教学过程为什么是一种特殊的认识过程"。

### 1.2 教学过程的基本规律（4 条，★★★★★ 必背原文）

> 记忆口诀：**间直、知能、主导主体、知德**（间接直接、知识能力、教师主导学生主体、知识品德）。

#### 规律一：间接经验与直接经验相统一（直接经验与间接经验相结合）

- **含义**：学生认识的主要任务是学习间接经验（书本知识），但间接经验必须以直接经验为基础；两者相互依存、相互促进。
- **贯彻要求**：
  1. 以学习间接经验为主，保证知识的系统性；
  2. 防止脱离实际、空洞说教，重视学生的直接经验；
  3. 组织必要的实践、观察、操作活动，为理解书本知识提供感性基础；
  4. 把间接经验与直接经验有机结合，防止"唯书本"与"唯经验"两种偏向。
- **例子**：讲《植物的一生》，先让学生观察自己种的豆芽，再读课文归纳植物生长条件。
- **怎么考**：材料中"老师只让学生背结论，学生不会用"→ 违背此规律（脱离直接经验）；"老师花大量时间带学生做实验，课本知识没讲完"→ 也违背（间接经验为主被削弱）。

#### 规律二：掌握知识与发展能力相统一（传授知识与发展智力相统一）

- **含义**：掌握知识是发展能力的基础，能力发展又是掌握知识的重要条件；两者相互依存、相互促进，但并非自然同步。
- **贯彻要求**：
  1. 重视知识的系统性传授，为学生能力发展打基础；
  2. 在传授知识过程中有意识地训练思维、发展智力，防止"死记硬背"；
  3. 教给学生学习方法，培养自学能力；
  4. 通过练习、实践、探究活动促进知识向能力转化。
- **例子**：数学讲"圆的面积"，不只让学生记公式，而是让学生动手剪拼、推导公式，发展空间观念与推理能力。
- **怎么考**：材料中"学生成绩好但不会举一反三""老师满堂灌、只求背下来"→ 违背此规律。

#### 规律三：教师主导作用与学生主体作用相统一（教师主导与学生主体相结合）

- **含义**：教师在教学中起组织、引导、激励的主导作用；学生是学习的主体，只有调动其主动性、积极性，教学才能有效。
- **贯彻要求**：
  1. 承认并发挥教师的主导作用，认真备课、科学组织教学；
  2. 尊重学生的主体地位，激发学习兴趣和内在动机；
  3. 发扬教学民主，鼓励学生质疑、讨论、发表不同意见；
  4. 引导学生学会自我计划、自我监控、自我评价（学会学习）。
- **例子**：小组合作探究时教师巡视点拨而不包办，汇报时追问"你为什么这样想"。
- **怎么考**：材料中"教师一言堂、学生被动听"→ 忽视主体；"教师完全放手、放任自流"→ 放弃主导。两者都错。

#### 规律四：传授知识与思想品德教育相统一（教学的教育性规律）

- **含义**：教学不仅是传授知识技能的过程，也是进行思想品德教育、形成正确价值观的过程；知识是思想品德形成的基础，思想品德的提高又为学习提供动力。
- **贯彻要求**：
  1. 在知识教学中挖掘思想性、教育性因素，寓教育于教学之中；
  2. 防止两种偏向：脱离知识内容的空洞说教、只顾知识不顾育人的"纯知识教学"；
  3. 教师以身作则，用自己的言行感染学生；
  4. 结合学科特点与学生实际，做到自然渗透而非贴标签。
- **例子**：语文《圆明园的毁灭》在品读语言中自然激发爱国情感，而不是课末硬加一句"我们要爱国"。
- **怎么考**：材料中"老师借课文内容引导学生体会爱国情怀"→ 体现此规律；"老师说这节课只讲知识点，不谈其他"→ 违背此规律。

#### 四条规律速查对比表

| 规律 | 关键词（看材料抓这几个词） | 违背表现 | 贯彻核心句 |
|---|---|---|---|
| 间接经验与直接经验相统一 | 书本、实践、观察、操作 | 只背结论／只玩不讲 | 以间接经验为主，以直接经验为基础 |
| 掌握知识与发展能力相统一 | 举一反三、思维训练、方法 | 死记硬背、满堂灌 | 授知中发展能力，授之以渔 |
| 教师主导与学生主体相统一 | 引导、启发、参与、民主 | 一言堂／放任 | 教师引导到位，学生主动参与 |
| 传授知识与思想品德教育相统一 | 情感、价值观、育人 | 空洞说教／纯知识 | 寓教育于教学，自然渗透 |

### 1.3 教学过程的基本阶段（5 阶段）

| 阶段 | 主要任务 | 教师行为 | 学生行为 |
|---|---|---|---|
| ① 激发学习动机 | 引起求知欲，形成学习心向 | 创设情境、提出问题、联系生活 | 产生兴趣与期待 |
| ② 领会知识（中心环节） | 感知教材 + 理解教材 | 直观演示、讲解、引导分析概括 | 观察、阅读、思考、形成概念 |
| ③ 巩固知识 | 强化记忆、防止遗忘 | 组织复习、提问、小结、变式练习 | 复述、整理、记忆 |
| ④ 运用知识 | 由懂到会，形成技能技巧 | 布置练习、指导实践、迁移训练 | 练习、操作、解决问题 |
| ⑤ 检查知识（评价） | 反馈教学效果 | 提问、测验、作业批改、讲评 | 自查、订正、反思 |

> **要点提示**：
> - **领会知识是教学过程的中心环节**（单选高频）。
> - **感知教材是理解教材的基础**，理解教材（形成概念、掌握规律）是核心。
> - 五阶段是"基本阶段"而非固定程序，可根据课型调整顺序或合并。
> **怎么考**：单选问"教学过程的中心环节是（领会知识）"；简答问"简述教学过程的基本阶段"。

## 二、教学原则（8 条，★★★★★ 材料分析题最高频）

> 记忆口诀：**直启循巩因，理科量**（直观、启发、循序渐进、巩固、因材施教、理论联系实际、科学性与教育性统一、量力性）。
> 答题格式固化：**原则名称 → 含义一句 → 材料中的做法 → 该做法如何体现/违背 → 正确做法**。

### 2.1 直观性原则

- **含义**：在教学中引导学生直接感知事物、现象，或通过形象的语言描绘、形象化教具，使学生获得生动的表象，从而比较全面、深刻地掌握知识。
- **贯彻要求**：
  1. 正确选择直观教具和现代化教学手段（实物、模型、图片、视频、演示实验）；
  2. 直观要与讲解相结合，防止"只看了个热闹"；
  3. 重视运用语言直观（生动形象的描述、比喻）；
  4. 直观教具的演示要适时、适度，讲求实效，防止形式主义。
- **例子**：讲"长方体体积"时拿出可拆分的 1 立方厘米小方块拼接演示；语文讲"燕子"时播放燕子飞行的短视频。
- **怎么考**：材料中出现"挂图、模型、实物、课件演示、教师用语言描述画面"→ 答直观性原则。若教师"只放视频不讲要点"→ 未与讲解结合。

### 2.2 启发性原则

- **含义**：在教学中教师要承认学生是学习的主体，注意调动他们的学习主动性，引导他们独立思考、积极探索、生动活泼地学习，自觉地掌握科学知识和提高分析问题、解决问题的能力。
- **贯彻要求**：
  1. 调动学生学习的主动性（激发求知欲与学习动机）；
  2. 启发学生独立思考，发展思维能力，善用提问与追问；
  3. 鼓励学生动手实践，在活动中获得启发；
  4. 发扬教学民主，建立民主平等的师生关系，鼓励质疑。
- **例子**：讲"分数的基本性质"，教师先给三张同样大的纸分别涂 1/2、2/4、4/8，问"你发现了什么？为什么？"
- **怎么考**：材料中出现"提问、追问、引导学生自己想出来、不直接给答案"→ 启发性原则。若教师"直接把结论告诉学生、让学生背下来"→ 违背启发性原则。

### 2.3 循序渐进原则（系统性原则）

- **含义**：教学要按照学科知识的逻辑系统和学生认识发展的顺序进行，使学生系统地掌握基础知识、基本技能，形成周密的逻辑思维能力。
- **贯彻要求**：
  1. 按教材的系统性进行教学，抓住重点与难点；
  2. 按学生认识发展的顺序由浅入深、由易到难、由简到繁地组织教学；
  3. 教学要连贯、有次序，前后衔接，及时复习巩固；
  4. 防止跳跃式教学与"炒冷饭"式重复，也反对不顾学生实际的一味求快。
- **例子**：拼音—字—词—句—段的推进；先学整数运算再学小数、分数运算。
- **怎么考**：材料中"老师按由易到难安排、前后知识衔接、及时复习"→ 循序渐进。若"跳过基础直接讲难题、进度过快学生跟不上"→ 违背。

### 2.4 巩固性原则

- **含义**：教学中要引导学生牢固地掌握所学知识和技能，使之能长久地保持在记忆中，并能根据需要迅速再现出来。
- **贯彻要求**：
  1. 在理解的基础上巩固，反对机械记忆；
  2. 重视组织各种复习，合理安排复习时间与方式（及时复习、分散复习）；
  3. 通过练习、运用、变式训练巩固知识；
  4. 教给学生记忆方法，培养记忆能力。
- **例子**：课末"知识梳理—当堂检测—三天后小复习"；英语单词用"滚雪球"式复现。
- **怎么考**：材料中"当堂练习、课堂小结、单元复习、错题重做"→ 巩固性原则。若"讲完就过、从不复习"→ 违背。

### 2.5 因材施教原则

- **含义**：教学中要从课程计划、学科课程标准的统一要求出发，面向全体学生，同时根据学生的个别差异（年龄特征、个性特点、学习水平），有的放矢地进行有区别的教学，使每个学生都能扬长避短、获得最佳发展。
- **贯彻要求**：
  1. 坚持统一要求与个别对待相结合，面向全体、照顾差异；
  2. 深入了解学生，研究学生的年龄特征和个性特点，做到"知人"；
  3. 针对不同学生采取不同措施（分层作业、分层提问、个别辅导、弹性要求）；
  4. 善于发现每个学生的兴趣、特长与"闪光点"，长善救失。
- **例子**：同一篇作文题，对基础弱的学生要求"写通顺、写完整"，对能力强的学生要求"有细节、有真情"；对学困生课后单独辅导。
- **怎么考**：材料中"老师对不同学生提不同要求、分层布置作业、个别辅导、发现学生长处"→ 因材施教。若"一刀切、用同一把尺子要求所有学生"→ 违背。

### 2.6 理论联系实际原则

- **含义**：教学要以学习基础知识为主导，从理论与实际的联系上去理解知识，注意运用知识去分析问题和解决问题，达到学懂会用、学以致用。
- **贯彻要求**：
  1. 书本知识的教学要注重联系实际（联系生活、生产、社会）；
  2. 重视培养学生运用知识的能力，组织练习、参观、实践、社会调查；
  3. 正确处理知识教学与技能训练的关系；
  4. 补充必要的乡土教材与本地资源。
- **例子**：数学"百分数"用商场折扣、银行利率做素材；科学课测量校园里的树高。
- **怎么考**：材料中"老师用生活实例引入、带学生到现场测量、布置实践性作业"→ 理论联系实际。若"只讲抽象公式、学生不知有何用"→ 违背。

### 2.7 科学性与思想性（教育性）相统一原则

- **含义**：教学中既要传授科学的、正确无误的知识（科学性），又要结合知识的内在教育因素进行思想品德教育、形成科学的世界观与正确价值观（思想性）。
- **贯彻要求**：
  1. 保证教学的科学性，概念、原理、表述准确无误；
  2. 挖掘教材的思想性，把思想教育渗透在知识教学中；
  3. 结合学科特点和学生实际，自然渗透、不贴标签；
  4. 教师要加强自身修养，以身作则，用自己的人格影响学生。
- **例子**：讲"我国古代四大发明"时渗透文化自信；讲"平均数"时用真实数据讲诚信与实事求是。
- **怎么考**：材料中"老师在讲授知识的同时自然渗透价值观教育"→ 体现该原则。若"讲错知识点""讲与知识无关的大道理"→ 违背科学性/思想性。

### 2.8 量力性原则（可接受性原则）

- **含义**：教学的内容、方法、分量和进度要适合学生的身心发展水平，是他们能够接受的，但又要有一定难度，需要他们经过努力才能掌握，以促进学生的身心发展（"跳一跳，摘桃子"）。
- **贯彻要求**：
  1. 了解学生的发展水平，从实际出发进行教学；
  2. 教材与讲授的难度要适当，既不过难也不过易，保持"最近发展区"的张力；
  3. 考虑学生认识发展的年龄特征与个别差异；
  4. 防止"拔苗助长"与"降低要求"两种偏向。
- **例子**：一年级识字量控制、低年级不布置超量书面作业；习题设置基础题+拓展题梯度。
- **怎么考**：材料中"作业太多学生做不完""题目过难全班都不会"→ 违背量力性；"难度适当、有梯度"→ 体现量力性。

### 教学原则速查表（材料分析考场可直接抄）

| 原则 | 一句话含义 | 材料信号词 | 贯彻要求关键词（背 3 条即可） |
|---|---|---|---|
| 直观性 | 用实物、形象化手段或语言描述让学生获得表象 | 实物、模型、挂图、视频、演示、形象描述 | 选好教具、直观与讲解结合、语言直观、适时适度 |
| 启发性 | 调动主动性，引导独立思考 | 提问、追问、引导发现、讨论、不直接给答案 | 调动主动性、启发思维、动手实践、教学民主 |
| 循序渐进 | 按学科逻辑与学生认识顺序教学 | 由浅入深、由易到难、前后衔接、系统复习 | 按系统教、抓重点难点、连贯有序、及时巩固 |
| 巩固性 | 使知识牢固保持并能再现 | 复习、当堂检测、小结、变式练习 | 理解基础上巩固、组织复习、练习运用、教记忆方法 |
| 因材施教 | 统一要求下照顾个别差异 | 分层、个别辅导、不同要求、发现特长 | 统一与个别结合、了解学生、区别对待、长善救失 |
| 理论联系实际 | 从实际理解理论，学以致用 | 生活实例、参观、操作、实践作业 | 联系实际、培养运用能力、教学与训练结合、乡土教材 |
| 科学性与思想性统一 | 知识正确 + 价值引领 | 准确讲授 + 自然渗透教育 | 保证科学性、挖掘思想性、自然渗透、以身作则 |
| 量力性 | 难度分量适合学生又具挑战 | 难度适当、有梯度、作业适量 | 了解水平、难度适当、考虑年龄特征、防止两偏 |

> **易混提醒**：
> - **直观性 vs 理论联系实际**：直观性重"感知获得表象"（看、听、摸），理论联系实际重"学以致用"（用知识解决问题）。
> - **循序渐进 vs 量力性**：循序渐进强调"顺序与系统"，量力性强调"难度与分量是否吃得消"。
> - **启发性 vs 教师主导学生主体规律**：问"原则"就答启发性，问"规律"就答第三条规律，不要混答。
> - **因材施教 vs 启发性**：因材施教针对"不同学生的差异对待"，启发性针对"所有学生被引导主动思考"。

## 三、教学方法

### 3.1 什么是教学方法

**教学方法**是教师和学生为了完成教学任务、实现教学目的，在教学过程中所采用的教与学相互作用的活动方式的总称。它包括**教师教的方法**和**学生学的方法**两个方面。

> 注意区分三个层次：**教学方法**（具体手段，如讲授法）⊂ **教学方式**（构成方法的具体做法）⊂ **教学策略**（为达成目标的方法组合与调控）。选择题常考"教学方法与教学方式的区别"。

### 3.2 教学方法分类表（按获取知识的主要途径分）

| 类别 | 具体方法 | 核心特征 | 典型场景 |
|---|---|---|---|
| 以**语言传递**为主 | 讲授法、谈话法、讨论法、读书指导法 | 通过口头语言/书面语言传递信息 | 新授课讲解、复习提问、班会讨论、阅读课 |
| 以**直观感知**为主 | 演示法、参观法 | 通过实物、教具或现场观察获得感性认识 | 实验演示、模型展示、博物馆参观 |
| 以**实际训练**为主 | 练习法、实验法、实习作业法、实践活动法 | 学生亲自动手做，形成技能技巧 | 计算练习、科学实验、社区调查 |
| 以**情感陶冶**为主 | 欣赏教学法、情境教学法 | 在体验、感受中受到熏陶 | 音乐欣赏、诗歌情境朗读 |
| 以**引导探究**为主 | 发现法（探究—研讨法）、问题教学法 | 学生自主发现问题、提出假设、验证结论 | 科学探究、数学规律发现 |

### 3.3 常用教学方法逐条精讲

#### ① 讲授法（最古老、使用最广）

- **含义**：教师运用口头语言系统连贯地向学生传授知识、发展能力的方法。
- **方式**：讲述、讲解、讲读、讲演（**讲述**重叙述事实；**讲解**重解释论证；**讲读**结合阅读；**讲演**重系统论述）。
- **优点**：能在短时间内系统高效地传授大量知识；便于发挥教师主导作用；可控性强、成本低。
- **缺点**：易变成"满堂灌"，学生被动；难以照顾个别差异；不利于培养动手与探究能力。
- **运用要求**：内容要有科学性与思想性；语言要清晰、准确、生动、有感染力；要善于设疑激趣、与其他方法配合；注意板书与节奏，留给学生思考时间。

#### ② 谈话法（问答法）

- **含义**：教师按一定教学要求向学生提出问题，要求学生回答，并通过问答形式引导学生获取或巩固知识的方法。
- **分类**：**启发式谈话**（引导发现新知识）、**复习式谈话**（检查巩固旧知识）。
- **优点**：能激发思维、集中注意；便于了解学生掌握情况；锻炼口头表达。
- **缺点**：耗时较多；问题设计不当易流于形式；难以面向全体。
- **运用要求**：问题要有启发性、层次性、明确性；面向全体、难易适度；善于追问与归纳；注意倾听并给予积极反馈。

#### ③ 讨论法

- **含义**：学生在教师指导下，围绕某一中心问题各抒己见、相互启发，从而获得知识、发展能力的方法。
- **优点**：发挥学生主体作用，培养合作、思辨与表达能力；有利于突破难点。
- **缺点**：耗时；易偏离主题或出现"搭便车"；对教师组织调控能力要求高。
- **运用要求**：议题要有讨论价值且难度适中；合理分组、明确规则与分工；教师巡视点拨、适时引导；讨论后要有归纳总结与评价。

#### ④ 演示法

- **含义**：教师通过展示实物、直观教具或进行示范性实验，使学生获得知识或巩固知识的方法。
- **优点**：直观具体，化抽象为形象；激发兴趣；便于形成正确表象。
- **缺点**：需设备条件；学生易只看热闹不动脑；大班后排观察效果差。
- **运用要求**：演示前交代目的与观察重点；演示中配合讲解与提问；保证可见度；演示后引导学生归纳。

#### ⑤ 练习法

- **含义**：学生在教师指导下反复完成一定动作或活动方式，借以形成技能技巧、巩固知识的方法。
- **类型**：口头练习、书面练习、操作练习；模仿性练习、创造性练习。
- **优点**：巩固知识、形成技能；便于反馈；可分层设计。
- **缺点**：过量易造成负担与机械重复；趣味性低。
- **运用要求**：明确目的与要求；精选练习内容、由易到难有梯度；分量适度、形式多样；及时检查与讲评，纠正错误。

#### ⑥ 实验法

- **含义**：学生在教师指导下，利用一定仪器设备，通过条件控制引起实验对象变化，从中获得知识、培养技能的方法。
- **优点**：动手动脑结合；培养科学态度与探究能力；印象深刻。
- **缺点**：耗材耗时；安全与组织管理难度大；受条件限制。
- **运用要求**：做好实验准备与安全预案；明确步骤与观察重点；指导学生规范操作、如实记录；实验后分析数据、得出结论。

#### ⑦ 参观法

- **含义**：教师根据教学需要组织学生到校外一定场所，对实际事物进行观察、研究，从而获得知识或巩固知识的方法。
- **分类**：准备性参观（学新知识前）、并行性参观（学习中）、总结性参观（学完后）。
- **优点**：联系实际、开阔视野；真实情境中的学习。
- **缺点**：组织难度大、安全责任重；受时间与资源限制。
- **运用要求**：目的明确、事先联系与踩点；做好安全与纪律教育；参观中指导观察记录；参观后总结交流。

#### ⑧ 读书指导法

- **含义**：教师指导学生通过阅读教科书和课外读物获取知识、培养自学能力的方法。
- **优点**：培养自学能力与阅读习惯；适应个别差异。
- **缺点**：见效慢；对低年级学生依赖教师指导多。
- **运用要求**：指导预习与复习阅读；教给圈点批注、做笔记的方法；推荐合适读物；检查阅读效果。

#### ⑨ 情境教学法

- **含义**：教师有目的地创设具有一定情绪色彩、以形象为主体的生动具体场景，引起学生一定的态度体验，从而帮助学生理解教材、发展心理机能的方法。
- **优点**：激发情感与兴趣；在体验中学习；利于语文、英语等学科的语言运用。
- **缺点**：情境设计成本高；易"为情境而情境"，偏离教学目标。
- **运用要求**：情境要贴近目标与学生生活；形式多样（生活展现、实物演示、图画再现、音乐渲染、角色扮演、语言描述）；情境与问题、任务相结合。

#### ⑩ 发现法（探究—研讨法）

- **含义**：在教师不加讲述的情况下，学生依靠自己的力量去获得新知识、寻求解决问题方法的一种教学方法（布鲁纳倡导）。
- **优点**：培养探究精神、独立思考与解决问题的能力；知识理解更深刻。
- **缺点**：耗时长、效率低；对基础与能力要求高；难以覆盖大量系统知识。
- **运用要求**：创设问题情境、提供必要材料；引导学生提出假设并验证；教师适度点拨而非包办；重视过程评价与归纳。

### 3.4 教学方法选用依据（简答高频，背 6 条）

1. **教学目的与任务**——要达成知识目标还是能力目标，决定方法取向。
2. **课程性质与教材内容特点**——理科多用实验、练习；语文多用朗读、情境；英语多用对话、情境。
3. **学生的年龄特征与知识基础**——低年级多用直观、游戏、情境；高年级可增多讨论、探究。
4. **教师自身的素质与条件**——教师的语言、组织、专业能力，以及学校设备条件。
5. **教学时间与效率要求**——时间紧、内容多宜以讲授配合练习为主。
6. **教学环境与班级规模**——大班额难以充分讨论与实验，小班化更利于探究。

> **答题句式**："教学方法的选用应综合考虑教学目的与任务、教材内容的特点、学生的年龄特征与知识基础、教师自身素质与教学条件、教学时间与效率要求等因素，做到多种方法优化组合、灵活运用。"

### 3.5 新课改倡导的学习方式（与教学方法一起考）

| 学习方式 | 核心特征 | 教师角色 | 常见误区 |
|---|---|---|---|
| 自主学习 | 自我计划、自我监控、自我评价；"能学、想学、会学" | 引导者、支持者 | 教师完全放手，缺少必要指导 |
| 合作学习 | 分组、分工、互动、共同完成；有明确责任分工 | 组织者、调控者 | 只"合坐"不"合作"，无分工无评价 |
| 探究学习 | 问题—假设—验证—结论；自主建构 | 情境创设者、点拨者 | 探究流于形式、结论被教师直接给出 |

## 四、教学组织形式

**教学组织形式**是指为实现一定的教学目的，围绕一定的教学内容，在一定时空环境中，师生相互作用的方式、结构与程序。

### 4.1 主要教学组织形式对比表（★★★★★）

| 组织形式 | 含义 | 优点 | 局限 | 关键词/人物 |
|---|---|---|---|---|
| 个别教学制 | 教师分别对个别学生进行教学 | 因材施教、针对性强 | 效率低、规模小、难以系统传授 | 古代主要形式 |
| 班级授课制 | 按年龄与知识水平编班，按固定课表分科集体上课 | 大面积培养人才、效率高、系统性强、利于发挥教师主导与集体教育作用 | 难以照顾个别差异、不利于培养创新与实践能力、学生较被动 | 夸美纽斯《大教学论》(1632) 系统论述；我国 1862 年京师同文馆最早采用 |
| 分组教学 | 按能力或成绩把学生分成若干组分别教学 | 照顾差异、便于分层 | 易造成标签效应、分组标准难把握 | 外部分组/内部分组；能力分组/作业分组 |
| 复式教学 | 一位教师在同一课堂内同时对两个以上年级的学生进行教学 | 解决人少、师资不足的困难；利于培养学生自学能力 | 教学干扰多、组织难度大、教师负担重 | 适用于人口稀少、交通不便的农村与山区 |
| 现场教学 | 把教学场所移到现场（工厂、农村、博物馆等）进行 | 理论联系实际、直观真实 | 组织难、受条件限制、系统性弱 | 常与参观法配合 |
| 走班制 | 学生根据自身情况选择不同层次的班级上课，行政班不变、教学班流动 | 尊重选择、因材施教、利于个性发展 | 管理难度大、易出现分层固化与"选课走班"乱象 | 新高考背景下常见 |
| 设计教学法 | 学生自己决定学习目的与内容，在活动中获得知识 | 尊重兴趣、强调经验 | 破坏知识系统性、效率低 | 克伯屈 |
| 道尔顿制 | 教师指定作业、学生自订进度自学，教室改为作业室 | 个别化、培养自学 | 易放任、缺乏系统讲授 | 帕克赫斯特 |
| 文纳特卡制 | 共同科目个别化学习 + 团体活动 | 兼顾个别与集体 | 编制教材工作量大 | 华虚朋 |
| 特朗普制 | 大班上课（40%）+ 小班研讨（20%）+ 个人自学（40%） | 综合多种形式优势 | 条件要求高 | "灵活的课程表" |
| 贝尔—兰卡斯特制 | 教师先教年龄大的学生，再由他们教其他学生（导生制） | 缓解师资不足 | 质量难保证 | 英国 |

### 4.2 班级授课制（必背重点）

**基本特点（"班、课、时"）**：

1. **以班为单位**——把学生按年龄和知识水平编成固定班级，班级人数固定；
2. **按课教学**——把教学内容分成若干学科，分科进行，各科有固定教师；
3. **按时授课**——按固定课表、固定时间（每节课一般为 40～45 分钟）进行教学。

**优点（背 4 条）**：① 有利于经济有效地大面积培养人才，提高教学效率；② 有利于学生获得系统的科学知识；③ 有利于发挥教师的主导作用；④ 有利于发挥集体的教育作用，促进学生社会化。

**缺点（背 3 条）**：① 难以充分照顾学生的个别差异，不利于因材施教；② 学生的实践与探究机会少，不利于培养创新精神与实践能力；③ 易导致"教师中心、教材中心、课堂中心"，学生较为被动。

**改革趋势**：班级规模小型化；教学组织形式多样化、综合化；适当增加个别化与分层教学成分；与走班制、选课制相结合。

> **怎么考**：单选常考"最早系统论述班级授课制的教育家（夸美纽斯）""我国最早采用班级授课制的学校（1862 年京师同文馆）"；简答考"简述班级授课制的优缺点"；材料分析中"老师班级人数多、只能统一讲授"就是从缺点角度切入。

### 4.3 分组教学与复式教学要点

- **分组教学类型**：
  - **外部分组**：打乱原有行政班，按能力或兴趣重新编班（如实验班、平行班）。
  - **内部分组**：在原有班级内部按能力或作业内容分组。
  - **能力分组**（按智力或学业水平分组）／**作业分组**（按学习内容与任务分组）。
- **复式教学要点**：合理编班（尽量把相邻年级编在一个班）、精心设计"自动作业"与"直接教学"的交替、培养小助手、建立良好的课堂常规。复式教学的关键是**动静搭配**（教师给一个年级上课时，另一年级做自动作业）。

## 五、教学工作的基本环节（★★★★★）

> 口诀：**备、上、作、辅、评**（备课—上课—作业的布置与批改—课外辅导—学业成绩的检查与评定）。

| 环节 | 地位 | 核心内容 |
|---|---|---|
| ① 备课 | **前提、先决条件** | 三备三写 |
| ② 上课 | **中心环节、中心工作** | 上好一堂课的标准 |
| ③ 作业的布置与批改 | 教学的**有机组成部分**、课堂教学的延续 | 分量、难度、形式、批改与讲评 |
| ④ 课外辅导 | 上课的**必要补充** | 答疑、补差、培优、学法指导 |
| ⑤ 学业成绩的检查与评定 | 教学的**重要环节**、反馈手段 | 考查、考试、评价与讲评 |

### 5.1 备课（"三备三写"）

**（1）三备**

- **备教材**：钻研课程标准与教科书，明确教学目标、重点难点、知识体系；先"由厚到薄"再"由薄到厚"。
- **备学生**：了解学生的知识基础、学习能力、兴趣态度、个别差异。
- **备教法**：选择教学方法与手段，设计教学环节与问题、板书、作业。

**（2）三写（三种计划）**

| 计划 | 内容 | 时间跨度 |
|---|---|---|
| 学期（学年）教学进度计划 | 教学总目标、章节进度、课时分配、考查安排 | 一学期 |
| 单元（课题）教学计划 | 单元目标、课时划分、各课重点难点、方法 | 一个单元 |
| 课时教学计划（教案） | 课题、目标、重难点、准备、过程、板书、作业、反思 | 一节课 |

**一份合格教案的要素（简答可用）**：课题与课时、教学目标（三维）、教学重点与难点、教学准备（教具）、教学方法、教学过程（导入—新授—巩固—小结—作业）、板书设计、教学反思。

> **怎么考**：简答常问"简述教师备课的基本要求/备课要做好的三方面工作"；材料中"老师照搬教参、不了解学生"→ 未备学生。

### 5.2 作业的布置与批改

**布置要求**：① 目的明确、符合课程标准要求；② 内容精选、难度适中、分量适当（落实"双减"，控制总量与时长）；③ 形式多样（口头、书面、实践、探究）；④ 要求明确、规定完成时间；⑤ 分层设计、照顾差异；⑥ 避免机械重复与惩罚性作业。

**批改要求**：及时、认真、规范；有评语与指导；做好记录与归类分析；及时讲评与订正；可适当面批、学生互批互改（教师把关）。

### 5.3 课外辅导

形式：个别辅导、小组辅导；内容：答疑解难、补差培优、学法指导、课外阅读与实践活动指导。要求：目的明确、因材施教、不加重负担、不搞有偿补课、不将辅导变成"提前上新课"。

### 5.4 学业成绩的检查与评定

- **检查方式**：考查（口头提问、作业、小测验、实验操作）与考试（期中、期末、单元测试）。
- **评定要求**：客观公正、标准明确；既要看结果也要看过程；定量与定性结合；注意发挥评价的诊断与激励功能；不得按成绩排名公布、不得单纯以分数评价学生。

## 六、一堂好课的标准（★★★★★ 简答必背）

> 口诀：**目标明、内容对、方法当、表达清、组织严、气氛活、效果好**。

| 标准 | 具体要求 |
|---|---|
| ① 目标明确 | 教学目标符合课程标准与学生实际，具体、可测；整节课围绕目标展开 |
| ② 内容正确 | 知识准确无误、科学性强；重点突出、难点突破；容量适当 |
| ③ 方法得当 | 教学方法选择恰当、灵活多样，符合学科特点和学生特点；注重启发 |
| ④ 表达清晰 | 教师语言清晰准确、生动形象、有感染力；板书规范、条理清楚 |
| ⑤ 组织严密 | 教学环节紧凑、过渡自然、节奏合理；时间分配科学，无空耗 |
| ⑥ 气氛热烈（积极性高） | 学生注意力集中、思维活跃、参与面广；师生关系融洽、教学民主 |
| ⑦ 效果好（目标达成度高） | 各层次学生都有收获，知识与能力目标达成；课堂效率高、负担轻 |

**补充表述（可作采分点加进去）**：一堂好课还要做到"**以学生发展为本**"，体现**因材施教与分层要求**，注重**生成性**（善于处理课堂突发情况、捕捉生成资源），做到**教书育人**（渗透思想教育）。

> **怎么考**：简答"简述一堂好课的标准"；材料分析中常让"评价这位老师的课"，就用这张表逐条对照，先肯定再指出不足。

## 七、教学评价

### 7.1 按评价的作用（时间）分类——最重要

| 类型 | 时间点 | 目的 | 例子 |
|---|---|---|---|
| 诊断性评价 | 教学活动**开始前** | 摸底、了解基础与问题，便于分层与安置 | 入学摸底测验、单元前测 |
| 形成性评价 | 教学活动**过程中** | 及时反馈、改进教与学，不重甄别 | 课堂提问、随堂练习、单元小测、作业批改 |
| 总结性评价 | 教学活动**结束后** | 鉴定、评定成绩、判断目标达成度 | 期末考试、毕业考试、结业评定 |

> **易混**：形成性评价重"改进"，总结性评价重"鉴定"；课堂提问属形成性评价，期末考试属总结性评价。

### 7.2 按评价的标准分类

| 类型 | 参照标准 | 解释 | 例子 |
|---|---|---|---|
| 相对评价（常模参照评价） | 参照**团体平均水平/名次** | 与他人比较，确定在群体中的位置 | 班级排名、选拔性考试、高考 |
| 绝对评价（标准参照评价） | 参照**预先确定的目标/标准** | 与固定标准比较，判断是否达标 | 教师资格考试、驾照考试、单元达标测 |
| 个体内差异评价 | 参照**自身过去或自身各方面** | 与自己比，看进步幅度 | 成长档案袋、前后测对比、偏科分析 |

### 7.3 其他分类与评价原则

- 按评价主体：**他评**（教师评、同伴评）与**自评**。
- 按评价内容：学业成绩评价、思想品德评价、综合素质评价。
- 按评价方法：定量评价（分数、统计）与定性评价（评语、观察记录）。

**教学评价的基本原则**：客观性原则、发展性原则、指导性原则、计划性原则、科学性（有效性）原则。

**新课改评价理念（采分点）**：① 评价目的重在**促进发展**而非甄别选拔；② 评价内容**多元化**（知识、能力、情感态度价值观）；③ 评价方式**多样化**（形成性评价与终结性评价结合、定性定量结合）；④ 评价主体**多元化**（教师、学生自评互评、家长）；⑤ 关注**过程**，重视表现性评价与成长记录。

> **怎么考**：单选考分类归属（"摸底考试属于（诊断性评价）""班级排名属于（相对评价）"）；简答考"简述教学评价的分类/新课程评价理念"；材料分析中教师用成长档案袋、评语鼓励学生 → 体现发展性评价理念。

## 八、课堂管理

### 8.1 课堂气氛

| 类型 | 特征 | 学生表现 | 教师应对 |
|---|---|---|---|
| 积极的课堂气氛 | 宽松、民主、活跃而有序 | 注意力集中、思维活跃、敢于发言 | 保持并适当提高挑战性 |
| 消极的课堂气氛 | 紧张、压抑或松散、冷漠 | 被动应付、沉默、走神 | 调整方式、增强互动、重建规则 |
| 对抗的课堂气氛 | 师生对立、秩序混乱 | 顶撞、起哄、故意捣乱 | 冷静处理、课后沟通、必要惩戒 |

**良好课堂气氛的营造**：① 建立民主平等的师生关系；② 创设合理的问题情境激发兴趣；③ 教师情绪饱满、语言生动；④ 公正对待每个学生、多鼓励；⑤ 建立明确可行的课堂规则。

### 8.2 课堂纪律与问题行为

**课堂纪律的类型**：教师促成的纪律、集体促成的纪律、任务促成的纪律、自我促成的纪律（**自我促成是最高境界、最终目标**）。

**课堂问题行为的类型**：

- **外向性问题行为**（攻击型）：打闹、大声喧哗、顶撞老师、故意破坏——**影响大、易发现**。
- **内向性问题行为**（退缩型）：走神、发呆、不参与、害怕发言、抄袭——**不易发现、危害隐蔽**。

**处理原则（材料分析高分点）**：① **预防为主**，通过合理组织教学减少问题行为发生；② **及时、冷静、低调处理**，尽量不影响正常教学（如眼神暗示、走近、提问）；③ **对事不对人**，尊重学生人格，不体罚、不侮辱；④ **分析原因、区别对待**（是疲劳、听不懂、求关注还是家庭问题）；⑤ **运用集体舆论与正向强化**；⑥ 严重或屡犯的问题课后沟通、与家长协作、依规处理。

### 8.3 教育机智

- **含义**：教师在教育教学过程中面对意外情况或突发问题，能够迅速、准确地作出判断，并巧妙、恰当地加以处理的能力。它是教师**教育智慧与应变能力的综合体现**。
- **表现**：善于因势利导、随机应变、掌握分寸、对症下药。
- **培养途径**：① 热爱学生、有高度的责任感；② 在实践中锻炼，积累经验；③ 加强理论学习，提高对儿童心理的洞察力；④ 善于反思总结；⑤ 保持情绪稳定、沉着冷静。

> **材料分析常见场景**：学生突然提问"超纲"问题、学生当面指出老师讲错、学生课堂上晕倒/争吵、突降大雨/停电等。答题模板：**稳定情绪 → 快速判断 → 巧妙转化（把意外变成教育资源）→ 保证教学继续 → 课后跟进**。

## 九、教学模式

| 模式 | 提出者/来源 | 程序 | 特点与评价 |
|---|---|---|---|
| 传递—接受模式 | 赫尔巴特四段说（明了—联合—系统—方法）→ 凯洛夫五环节 | 复习旧知—导入新课—讲授新知—巩固练习—布置作业 | 效率高、系统性强；易忽视学生主动性与探究 |
| 探究（发现）教学模式 | 布鲁纳 | 提出问题—创设情境—提出假设—验证假设—得出结论 | 培养探究与思维；耗时、对基础要求高 |
| 范例教学模式 | 瓦·根舍因（德国） | 范例性地阐明"个"—阐明"类"—掌握规律范畴—获得世界经验 | 以典型例子带动规律掌握，克服教材庞杂 |
| 抛锚式教学模式 | 建构主义（约翰·布朗斯福特） | 创设情境—确定问题（抛锚）—自主学习—协作学习—效果评价 | 以真实问题为"锚"，情境性强；需高质量情境 |
| 支架式教学模式 | 建构主义（源于维果茨基"最近发展区"） | 搭脚手架—进入情境—独立探索—协作学习—效果评价 | 教师逐步撤除支持，实现由扶到放 |
| 掌握学习模式 | 布卢姆 | 单元教学目标—班级教学—形成性测验—矫正/ enrichment—平行性测验 | 相信大多数学生都能掌握，重视反馈矫正 |
| 程序教学模式 | 斯金纳（行为主义） | 小步子—呈现问题—即时反馈—自定步调 | 个别化、及时强化；机械、缺乏人际互动 |
| 非指导性教学模式 | 罗杰斯（人本主义） | 创设氛围—探索问题—形成见识—计划与行动 | 以学生为中心，重情感与自我实现；效率较低 |

> **怎么考**：单选考"抛锚式的理论基础（建构主义）""支架式源于（最近发展区）""范例教学提出者（瓦·根舍因）"；简答偶尔考"简述建构主义教学模式的基本环节"。

## 十、本章速记与主观题套用

### 10.1 全套记忆口诀

- 教学过程四规律：**间直、知能、主主、知德**。
- 教学过程五阶段：**动（动机）领（领会）巩、用、查**。
- 八条教学原则：**直启循巩因，理科量**。
- 教学五环节：**备上作辅评**。
- 好课七标准：**目内方表组气效**。
- 评价三类型：**诊断在前、形成在中、总结在后**。
- 三种参照：**相对看名次、绝对看标准、个体看自己**。
- 班级授课制特点：**班、课、时**。

### 10.2 材料分析题"教学实施"方向万能提纲

1. **判断表态**：这位老师的做法总体上是恰当的（或存在不足）。
2. **理论依据（任选 3～4 条，写名称 + 一句话解释）**：
   - 体现了/违背了**启发性原则**（调动主动性、引导独立思考）；
   - 体现了/违背了**因材施教原则**（面向全体、照顾差异）；
   - 体现了/违背了**直观性原则**（实物与语言直观）；
   - 体现了/违背了**教师主导与学生主体相统一规律**；
   - 运用了**讨论法/情境教学法/发现法**，其优点是……
   - 教学环节完整（导入—新授—巩固—小结—作业），符合**教学过程基本阶段**；
   - 评价方式体现了**形成性评价/发展性评价理念**。
3. **结合材料分析**：引用原文关键句（"材料中老师……"），逐条对应。
4. **总结提升**：作为教师应……，做到以学生发展为本、多种方法优化组合。

### 10.3 高频易混辨析表

| 易混点 | 区别 |
|---|---|
| 教学原则 vs 教学过程规律 | 原则是"应该怎么做"的要求；规律是"客观上如此"的必然联系 |
| 直观性 vs 理论联系实际 | 前者重感知获得表象；后者重学以致用 |
| 循序渐进 vs 量力性 | 前者重顺序与系统性；后者重难度分量是否可接受 |
| 教学方法的分类依据 | 按获取知识的途径：语言传递、直观感知、实际训练、情感陶冶、引导探究 |
| 形成性 vs 总结性评价 | 前者过程中、重改进；后者结束后、重鉴定 |
| 相对 vs 绝对评价 | 前者与他人比（名次）；后者与标准比（达标） |
| 备课三备 | 备教材、备学生、备教法（不要写成"备大纲、备教案、备作业"） |
| 班级授课制 vs 分组教学 | 前者按年龄编班统一上课；后者按能力/成绩分组教学 |

### 10.4 本模块"怎么考"总结表

| 考点 | 单选 | 简答 | 材料分析 |
