# 07 材料分析题答题模板

---

## 一、先弄清楚：这 40 分是怎么给的

### 1.1 题型与分值

| 项目 | 说明 |
|---|---|
| 题量 | 通常 2 小题，每小题 20 分 |
| 材料长度 | 300～500 字的师生教育情境叙述 |
| 设问形式 | "请运用××理论/原则，评析材料中老师的做法""请分析该学生的问题及原因""如果你是老师，你会怎么做" |
| 答题篇幅 | 每小题约 400～600 字（写满答题区域 2/3 以上） |
| 给分方式 | **按采分点给分**：理论点 + 材料对应 + 结论/建议 |

### 1.2 阅卷四条采分线（每一分都在这四条上）

| 采分线 | 占比 | 具体表现 |
|---|---|---|
| ① 理论点是否准确 | 约 40% | 写出正确的原则/规律/理论名称，且名称是教材通行表述 |
| ② 材料是否对应 | 约 35% | 引用材料原话，说明"哪句话体现了哪条理论" |
| ③ 分析是否有逻辑 | 约 15% | 分点清楚、有条理、先说理后举例 |
| ④ 结论与建议是否到位 | 约 10% | 有总体评价 + 有可操作的建议 |

> **最大失分点**：只写理论不引材料（"空对空"），或只复述材料不写理论（"记叙文"）。**必须一条理论配一句材料。**

### 1.3 通用四步法（所有方向的骨架）

```
第一步 表态定性（1～2 句）：这位老师的做法总体上是恰当的 / 存在明显不足 / 部分恰当但仍有改进空间。
第二步 理论 + 材料（3～4 组）：【理论名称】+【一句话解释】+【材料中"……"体现了/违背了这一点】。
第三步 逐条评析（可并入第二步）：这一做法带来了什么影响（对学生、对教学效果）。
第四步 建议/总结（2～3 句）：作为教师应当……，做到……。
```

### 1.4 通用答题句式库（背 8 句，考场直接拼接）

| 功能 | 句式 |
|---|---|
| 表态 | "材料中×老师的做法总体上是值得肯定的，但也存在需要改进之处。" |
| 引理 | "这体现了（违背了）××原则/规律。该原则是指……" |
| 引材 | "材料中，×老师在学生……时，'……'，正是这一点的具体体现。" |
| 分析影响 | "这一做法有效地（不利于）保护了学生的……，促进了（阻碍了）……" |
| 转折指出问题 | "然而，材料中×老师'……'的做法，则不符合××的要求。" |
| 给建议 | "作为教师，应当……；同时要注意……，避免……。" |
| 学生问题归因 | "该学生的表现属于……问题，其原因主要有：①……②……③……" |
| 收尾 | "总之，教师应坚持以学生发展为本，把××理论与教育实践结合起来。" |

## 二、方向一：教学原则与教学方法（最高频）

### 2.1 识别信号词表（看到这些词就往这边想）

| 材料中的信号 | 指向考点 |
|---|---|
| 出示实物、图片、视频、模型，做演示实验，教师生动描述 | 直观性原则 |
| 提问、追问、"你先想想""谁还有不同想法""不直接告诉答案" | 启发性原则 |
| 由易到难、由浅入深、先复习旧知再学新知、前后衔接 | 循序渐进原则 |
| 反复练习、当堂检测、课堂小结、复习巩固 | 巩固性原则 |
| 分层作业、个别辅导、对不同学生提不同要求 | 因材施教原则 |
| 联系生活实例、带学生到现场、布置实践作业 | 理论联系实际原则 |
| 讲知识时渗透价值观、爱国、诚信教育 | 科学性与思想性统一原则 |
| 作业太多学生做不完、题目过难、进度过快 | 量力性原则（违背） |
| 小组讨论、角色扮演、动手操作、自主探究 | 讨论法、情境教学法、发现法 |
| 只讲不练、满堂灌、学生被动记笔记 | 违背启发性原则、忽视学生主体 |

### 2.2 理论清单（可调用的"弹药"）

- **8 条教学原则**：直观性、启发性、循序渐进、巩固性、因材施教、理论联系实际、科学性与思想性统一、量力性。
- **4 条教学过程规律**：间接经验与直接经验相统一、掌握知识与发展能力相统一、教师主导与学生主体相统一、传授知识与思想品德教育相统一。
- **5 个教学阶段**：激发动机、领会知识、巩固知识、运用知识、检查知识。
- **教学方法**：讲授法、谈话法、讨论法、演示法、练习法、实验法、参观法、读书指导法、情境教学法、发现法。
- **教学评价**：诊断性/形成性/总结性；发展性评价理念。

### 2.3 答题句式（这个方向的"填空题"）

> 材料中×老师的教学行为体现了（违背了）**××原则**。该原则要求教师在教学中……（一句话解释含义）。
> 材料中，"……（引原文）"，说明×老师……，这正是××原则的具体体现。
> 从教学效果看，这样做有利于（不利于）学生……，促进了（阻碍了）……目标的达成。
> 因此，教师在教学时应……（写出该原则 2 条贯彻要求）。

### 2.4 完整示范答案一

**材料**：王老师教三年级《认识周长》。上课伊始，她请学生用手摸一摸课桌面的边线，再指一指数学书封面的一周；接着发给每组一根绳子和一片树叶，让学生用绳子沿树叶边缘围一圈，再把绳子拉直用尺子量长度。巡视时她发现小林把起点和终点错开了，没有直接纠正，而是问："你是从哪个点出发的？走一圈又回到这个点了吗？"小林自己发现后重新量了一次。课末，王老师问："现在谁能用自己的话说说什么是周长？"学生纷纷举手。

**问题**：请运用教学原则的相关理论评析王老师的教学行为。

**示范答案**：

材料中王老师的教学行为总体上是恰当的，较好地贯彻了多条教学原则，值得肯定。

① **贯彻了直观性原则**。直观性原则要求教师引导学生直接感知事物，借助实物、教具或形象化手段帮助学生获得表象。材料中王老师让学生"摸一摸课桌面的边线""指一指数学书封面的一周""用绳子沿树叶边缘围一圈"，通过动作与实物把抽象的"周长"变成可看、可摸、可操作的对象，符合三年级学生以具体形象思维为主的特点，有效帮助学生建立了周长的表象。

② **贯彻了启发性原则**。启发性原则要求教师调动学生的学习主动性，引导其独立思考、积极探索，而不是直接把结论告诉学生。材料中王老师发现小林量错后"没有直接纠正"，而是用"你是从哪个点出发的？走一圈又回到这个点了吗？"两个问题引导小林自己发现错误并重新测量，既保护了学生的自尊，又让其在思考中真正理解"封闭图形一周"的含义，体现了"不愤不启、不悱不发"的启发艺术。

③ **体现了教师主导作用与学生主体作用相统一的教学规律**。王老师设计了操作活动并巡视点拨，起的是组织者、引导者的作用；而测量、发现错误、重新测量、概括"什么是周长"都由学生自己完成，学生是学习的主体。二者结合，使课堂既有明确方向，又有充分的自主空间。

④ **遵循了循序渐进原则**。教学中王老师安排了"摸边线—指一周—围树叶—量长度—说概念"的顺序，由直观动作到语言概括，由易到难、层层递进，符合学生认识发展的顺序。

⑤ 值得改进之处：材料显示学生"纷纷举手"，但未体现对不同水平学生的分层要求，若能在操作中为学有余力的学生增加"比较不同图形周长"的挑战任务，将进一步落实因材施教原则。

> **采分点自查**：表态 2 分；直观性原则（名称+含义+材料）4 分；启发性原则（名称+含义+材料）4 分；主导与主体统一规律 4 分；循序渐进 3 分；改进建议 3 分。理论与材料必须一一对应，只有理论不引材料最多得一半分。

### 2.5 完整示范答案二

**材料**：李老师教五年级《圆的面积》。他认为公式推导太费时间，直接把"圆的面积＝πr²"写在黑板上，要求学生背下来，然后连续讲了 6 道例题，布置了 40 道计算题。批改时他发现，学生套公式算标准题正确率尚可，但遇到"已知圆的周长求面积""半圆面积"就大面积出错，还有学生把 r² 算成 2r。李老师很困惑："公式都背了，题也刷了，怎么还不会？"

**问题**：请运用教学原则和教学过程规律分析李老师教学中存在的问题，并提出改进建议。

**示范答案**：

李老师的教学存在明显不足，违背了多条教学原则与规律，这正是学生"会套公式却不会解题"的根源。

① **违背了启发性原则**。启发性原则要求教师调动学生主动性、引导独立思考，让学生经历知识的形成过程。材料中李老师"认为公式推导太费时间，直接把公式写在黑板上，要求学生背下来"，把本应由学生探究发现的过程压缩为被动接受，学生只记住了结论而不理解"为什么是 πr²"，因而遇到变式题便无从下手。

② **违背了掌握知识与发展能力相统一的教学规律**。该规律要求教师在传授知识的同时发展学生的思维与能力，二者并非自然同步。李老师让学生"背公式 + 刷 40 道题"，只完成机械记忆，没有通过剪拼、转化等活动发展空间观念与推理能力，于是出现"把 r² 算成 2r"这类不明算理的低级错误。

③ **违背了巩固性原则的实质要求**。巩固性原则强调在**理解的基础上**巩固，并通过变式练习实现灵活运用。李老师的 40 道题几乎都是同一种标准题型，属于机械重复而非有效巩固；缺少变式训练，学生自然无法迁移到"已知周长求面积""半圆面积"等新情境。

④ **违背了量力性原则**。一节课连讲 6 道例题、布置 40 道题，分量明显超出五年级学生的承受范围，容易疲劳应付、抄袭潦草，反而不符合"减负增效"的要求。

⑤ **违背了循序渐进原则**。圆的面积推导应建立在"转化"思想基础之上，李老师跳过"化圆为方"的关键环节，学生缺少必要的认知准备。

**改进建议**：一是让学生动手把圆剪成若干等份拼成近似长方形，亲历"化曲为直、化圆为方"的推导过程，理解算理；二是在练习设计上减少数量、提高质量，按"基础—变式—拓展"分层编排，并安排已知周长求面积、组合图形等变式题；三是作业分层、控制总量；四是课末引导学生用自己的话复述推导思路，检测是否真正理解。

> **采分点自查**：表态 2 分；启发性原则 4 分；掌握知识与发展能力相统一规律 4 分；巩固性原则（理解基础上巩固、变式）3 分；量力性/循序渐进 3 分；改进建议 4 分。注意本题设问包含"并提出改进建议"，缺建议会直接丢 4 分。

## 三、方向二：德育原则与德育方法

### 3.1 识别信号词表

| 材料中的信号 | 指向考点 |
|---|---|
| 学生犯错后教师讲道理、摆事实、耐心开导、不压制 | 疏导原则（循循善诱） |
| 教师既严格要求又关心尊重学生、不当众羞辱 | 尊重信任与严格要求相结合 |
| 教师发现学生的闪光点、用长处带动短处 | 依靠积极因素克服消极因素（长善救失） |
| 组织活动、值日、志愿服务，在行动中养成品德 | 实际锻炼法、知行统一原则 |
| 教师以身作则、树立榜样、讲英雄故事 | 榜样示范法 |
| 美化教室、班风熏陶、艺术活动感染 | 情感陶冶法 |
| 表扬、奖励、评星、批评处分 | 品德评价法 |
| 学校、家庭、社会要求不一致 | 教育影响一致性与连贯性原则 |
| 对不同学生采用不同教育方式 | 因材施教原则（德育） |
| 班主任当众批评、讽刺、罚站、叫家长来训 | 违背尊重信任与严格要求结合、疏导原则 |

### 3.2 理论清单

- **德育原则 8 条**：导向性、疏导（循循善诱）、尊重信任与严格要求相结合、知行统一、正面教育与纪律约束相结合、依靠积极因素克服消极因素、教育影响一致性与连贯性、因材施教（另有集体教育与个别教育相结合）。
- **德育方法 6 种**：说服教育法（最基本）、榜样示范法、实际锻炼法、情感陶冶法、品德评价法、道德修养法（自我教育）。
- **德育过程 4 条规律**：知情意行统一（多开端）、思想内部矛盾斗争、活动与交往中形成、长期反复逐步提高。
- **品德心理结构**：道德认识（基础）、道德情感（动力）、道德意志（调节）、道德行为（标志）。

### 3.3 答题句式

> 材料中×老师对待××同学的方式，体现了（违背了）**××德育原则**。该原则要求……（一句含义）。
> 具体来看，当学生……时，×老师"……"，这说明他……（分析动机与效果）。
> 从德育过程规律看，学生品德形成具有**长期性、反复性**，因此教师应……
> 若我是班主任，我会：①……②……③……（给出 3 条可操作措施）。

### 3.4 完整示范答案一

**材料**：四年级的小宇近来多次拿同学的文具，被同学当场发现。班主任张老师非常生气，在班会上点名批评他"手脚不干净""以后大家都别理他"，并打电话让家长到校"把孩子领回去教育"。此后小宇变得沉默寡言，见了老师就低头躲开，班上同学也开始疏远他，他的成绩明显下滑。

**问题**：请运用德育原则和德育方法的相关理论，评析张老师的做法。

**示范答案**：

张老师的做法是不恰当的，违背了多条德育原则，不仅未能解决问题，反而造成了新的伤害。

① **违背了尊重学生与严格要求学生相结合原则**。该原则要求教师既对学生提出严格要求，又尊重、信任、关心学生，保护其自尊心。材料中张老师"在班会上点名批评""说学生手脚不干净""以后大家都别理他"，是当众羞辱与孤立，严重伤害了小宇的人格尊严，导致他"见了老师就低头躲开"，与教育目的背道而驰。

② **违背了疏导原则（循循善诱原则）**。疏导原则要求教师讲明道理、疏通思想、以表扬激励为主，帮助学生自觉改正。张老师没有了解小宇拿文具的真实原因，也没有进行耐心谈话与说理，而是简单地公开批评、推给家长，属于"堵"而不是"疏"。

③ **违背了依靠积极因素、克服消极因素原则（长善救失）**。每个学生身上都有闪光点，教师应发扬其积极因素去克服消极因素。张老师只看到"拿东西"这一缺点，将其全盘否定并贴上标签，没有发现和利用小宇的其他优点，使学生失去改进的信心。

④ **违背了教育影响的一致性与连贯性原则**。该原则要求学校、家庭、社会形成教育合力。张老师"打电话让家长把孩子领回去"，把责任推给家庭，没有与家长共同分析原因、商定一致的帮教方案，反而造成家校对立。

⑤ **从德育过程规律看**，学生品德形成是长期的、反复的，出现反复属正常现象，需要反复抓、抓反复。张老师一次犯错就公开定性，忽视了德育的长期性。

**正确做法**：一是私下与小宇谈心，了解行为背后的真实原因，保护其自尊；二是与他共同约定改正步骤，及时肯定每一次进步；三是通过承担班级服务岗位等方式，让他在集体中获得正面体验；四是与家长沟通、统一要求，共同关注而非指责；五是在班会上开展"尊重与信任"主题讨论，引导全班形成宽容互助的氛围。

> **采分点自查**：表态 2 分；尊重信任与严格要求相结合 4 分；疏导原则 4 分；长善救失 3 分；一致性连贯性 3 分；德育过程长期性 2 分；正确做法 2 分。本题关键是把"当众批评+叫家长"这两个动作识别为两条原则的违背。

### 3.5 完整示范答案二

**材料**：六年级的小峰脾气暴躁，常与同学发生冲突。一次他因排队纠纷推倒了同学，被同学告到办公室。班主任陈老师没有立即训斥，而是先让他坐下，递给他一杯水，等他情绪平静后问："当时发生了什么？你心里是怎么想的？"听完后，陈老师没有简单地判定谁对谁错，而是说："被人插队确实让人恼火，我能理解你的感受；但推人会让对方受伤，这不是解决问题的方法。"随后陈老师请小峰自己想三种不动手也能解决的办法，并约定下周由他担任"排队小管理员"。一周后，小峰与同学的关系明显缓和，还在班会上分享了自己管理排队的体会。

**问题**：请评析陈老师的教育行为。

**示范答案**：

陈老师的做法是恰当而富有教育智慧的，充分体现了德育的原则与方法，值得学习。

① **体现了疏导原则（循循善诱原则）**。疏导原则要求教师讲明道理、疏通思想、以理服人。材料中陈老师"没有立即训斥""等他情绪平静后"再询问原因，通过"被人插队确实让人恼火，我能理解你的感受"进行共情疏导，再用"推人会让对方受伤，这不是解决问题的方法"讲清道理，做到了先疏后导、以理服人。

② **体现了尊重学生与严格要求学生相结合原则**。陈老师"递给他一杯水""让他坐下"，尊重其人格与情绪；同时明确指出推人行为的错误，并提出"想出三种不动手也能解决的办法"这一明确要求，做到了严而有爱、严而有度。

③ **运用了实际锻炼法（知行统一原则）**。德育不能停留在说理上，还要在行动中养成品德。陈老师让小峰担任"排队小管理员"，使他在真实情境中练习规则意识与责任担当，由"被管理者"转变为"管理者"，实现了知行统一，效果也由"关系缓和"得到验证。

④ **体现了依靠积极因素克服消极因素原则（长善救失）**。小峰"脾气暴躁"的另一面是有较强的规则敏感与行动力，陈老师没有给他贴"爱打架"的标签，而是把这种能量引导到管理排队上，用积极因素克服消极因素。

⑤ **体现了德育过程是促进学生思想内部矛盾斗争的过程**。陈老师没有把结论强加给学生，而是请他自己"想三种办法"，促成其内部认知冲突与自我教育，符合"教育与自我教育相结合"的要求。

⑥ 从德育的心理结构看，陈老师既提高了学生的道德认识（讲明推人的后果），又丰富了道德情感（共情与理解），还通过岗位锻炼了道德意志与行为，实现了知、情、意、行的统一。

> **采分点自查**：表态 2 分；疏导原则（共情+说理）4 分；尊重与严格要求结合 4 分；实际锻炼法/知行统一 4 分；长善救失 3 分；内部矛盾与知情意行 3 分。正面材料的答法是"全部肯定 + 逐条对应"，同样必须引原话。

## 四、方向三：学生心理与学习动机

### 4.1 识别信号词表

| 材料中的信号 | 指向考点 |
|---|---|
| "我就是笨""反正我也学不会""再努力也没用" | 习得性无助、消极归因、自我效能感低 |
| 上课不举手、怕答错被笑、回避任务 | 自我效能感低、附属内驱力过强、焦虑 |
| 只有给奖励才学、为得到表扬而学 | 外部动机、附属内驱力 |
| 对内容本身感兴趣、主动钻研 | 内部动机、认知内驱力 |
| 考前失眠、心慌、拉肚子、脑子一片空白 | 考试焦虑、耶克斯—多德森定律 |
| 学生说"我这次考好是因为运气好" | 归因偏差（外部、不稳定、不可控） |
| 会做旧题不会做新题 | 学习迁移受阻、思维定式 |
| 上课走神、坐不住、小动作多、冲动 | 注意缺陷多动障碍（多动症）、注意力发展特点 |
| 不愿与人交往、独来独往、被孤立 | 人际关系问题、归属与爱的需要缺失 |
| 反复洗手、反复检查、害怕出错 | 强迫行为、焦虑 |
| 学生说"反正我爸妈也不管我" | 家庭教养方式、归属与安全需要 |

### 4.2 理论清单

- **动机理论**：内部/外部动机；奥苏贝尔三类内驱力（认知、自我提高、附属）；耶克斯—多德森定律（倒 U 型）；韦纳归因理论（内外源、稳定性、可控性）；马斯洛需要层次；班杜拉自我效能感；成就目标理论（掌握目标/表现目标）。
- **学习理论**：行为主义（强化、惩罚、消退）、认知（布鲁纳发现学习）、建构主义、人本主义（罗杰斯，无条件积极关注）。
- **发展理论**：皮亚杰认知阶段、埃里克森"勤奋对自卑"、科尔伯格道德发展。
- **心理辅导方法**：强化法、代币奖励法、系统脱敏法、理性情绪疗法（ABC 理论）、来访者中心疗法（真诚、接纳、共情）。

### 4.3 答题句式

> 该学生的表现属于**××问题**（如习得性无助、考试焦虑、学习动机不足）。
> 其原因主要有三个方面：①**个人因素**……②**学校/教师因素**……③**家庭因素**……
> 从××理论看，……（用理论解释机制）。
> 作为教师，可以采取以下措施：①……②……③……（每条都要具体可操作）。

### 4.4 完整示范答案一

**材料**：五年级的小凡数学成绩一直不理想。最近两次单元测验后，他对同桌说："我就是笨，怎么学都学不会，努力也没用。"此后数学课上他从不举手，老师提问时他低头不语，作业常常空着或者抄同学的。数学老师批评他"态度不端正、太懒"，他更加消沉，最近一次测验只考了 38 分。

**问题**：请分析小凡存在的问题及原因，并提出教育建议。

**示范答案**：

小凡的问题属于学习动机不足与**习得性无助**，并伴随自我效能感低下和消极的自我归因，需要教师及时干预。

**原因分析**：

① **归因方式消极**。根据韦纳的归因理论，归因可从内外源、稳定性、可控性三个维度分析。小凡说"我就是笨"，把失败归因于**能力**这一内部、稳定、不可控的因素。这种归因会让人认为失败无法改变，从而放弃努力，形成"努力也没用"的习得性无助。

② **自我效能感低下**。班杜拉认为，自我效能感是个体对自己能否成功完成某一行为的主观判断，其中**直接经验（成败经验）影响最大**。小凡接连失败、缺少成功体验，自我效能感不断降低，于是出现"从不举手""低头不语"等回避行为。

③ **教师评价方式不当**。数学老师批评他"态度不端正、太懒"，属于标签化评价，既没有分析其学习困难的真实原因（基础薄弱、方法不当还是某知识点未掌握），也没有提供具体帮助，反而加剧了挫败感，违背了发展性评价理念。

④ **需要层次未满足**。马斯洛指出，尊重与归属需要未满足时，学生难以产生高层次的成长需要。小凡在课堂上得不到肯定、屡被批评，尊重需要受挫，内在学习动力自然减弱。

⑤ **学习方法与基础问题**。作业"空着或抄同学的"，说明他已跟不上进度、存在知识断层。

**教育建议**：

一是**归因训练**，引导他把失败归因于"努力不够、方法不当"这类可控因素，如"这次错的是计算粗心，方法上再练一练就能提高"。二是**创造成功体验**，设置"跳一跳能摘到"的小目标（先掌握 3 道基础题），及时具体表扬，重建自我效能感。三是**降低起点、补齐基础**，通过课前小辅导、错题重做解决知识断层。四是**改进评价语言**，用发展性、描述性评价代替"懒""态度不端正"的标签。五是**家校沟通**，请家长关注进步而非只问分数。六是**学法指导**，如"先复习后作业""错题整理"，让他体验"努力—进步"的联结。

> **采分点自查**：定性（习得性无助/动机不足）2 分；归因理论三维度 4 分；自我效能感 3 分；教师评价不当 3 分；需要层次 2 分；建议 6 分（每条 1 分，越具体越好）。原因与建议要**一一呼应**，不能原因说归因、建议却说别的。

### 4.5 完整示范答案二

**材料**：六年级的小雅成绩优秀，但每逢大考就紧张得睡不着，进考场后手心出汗、心跳加快，有一次甚至"脑子一片空白"，会做的题也做错了。她妈妈常说"考不上好初中，你这辈子就完了"。最近小雅开始反复检查书包和文具，出门后总担心门没锁，要回去看好几遍。

**问题**：请分析小雅的问题及成因，并说明教师应如何进行辅导。

**示范答案**：

小雅的问题属于典型的**考试焦虑**，并已出现轻度的强迫性检查行为，需要从认知、行为与环境三方面进行辅导。

**问题与成因分析**：

① **考试焦虑的表现明显**。材料中"紧张得睡不着""手心出汗、心跳加快""脑子一片空白"，是焦虑的生理与认知反应。根据耶克斯—多德森定律，动机强度与效率呈倒 U 型关系，焦虑过高会使注意力狭窄、思维僵化，导致"会做的题也做错"。

② **认知层面存在不合理信念**。小雅把一次考试的结果等同于人生的全部价值，属于以偏概全、糟糕至极的不合理信念。理性情绪疗法（ABC 理论）指出，引发焦虑的不是事件本身，而是对事件的解释。

③ **家庭压力是重要诱因**。母亲"考不上好初中，你这辈子就完了"的表述，把爱变成了有条件的期待，使小雅的安全感与自我价值感完全系于分数，这是焦虑持续的直接外部原因。

④ **强迫性检查是焦虑的行为化表现**。反复检查书包、反复确认门锁，是通过重复行为暂时缓解焦虑，若长期强化会固化为强迫行为，需及早干预。

⑤ **从人格发展角度看**，小学高年级学生正处于埃里克森所说的"勤奋对自卑"阶段，过度关注结果评价会削弱其胜任感。

**辅导措施**：

一是**认知调整**：运用理性情绪疗法，与她讨论"考不好会怎样"，帮助其把"一次考试＝人生成败"改写为"考试是检测，不是判决"。二是**行为放松训练**：教给她深呼吸、渐进式肌肉放松、考前积极自我暗示，并做几次模拟考场练习。三是**合理设定目标**：把"必须考好"改为"把会做的题做对"，把不可控的结果目标转为可控的过程目标。四是**家校协同**：建议家长少谈"考不上就完了"，多肯定努力过程。五是**关注强迫行为**：不强化、不指责其反复检查，与其约定"检查两次即可"；若症状加重，建议转介心理教师或专业机构。六是**营造宽松氛围**：考前不排名、不渲染紧张气氛。

> **采分点自查**：定性（考试焦虑）2 分；耶克斯—多德森定律 3 分；ABC 理论与不合理信念 4 分；家庭因素 3 分；强迫行为识别 2 分；辅导措施 6 分（认知、行为、家校、转介各有分）。"会做的题也做错"这句原话务必引用，它是倒 U 型理论的直接证据。

## 五、方向四：班级管理与师生关系

### 5.1 识别信号词表

| 材料中的信号 | 指向考点 |
|---|---|
| 新班主任接手"乱班"，先立规矩、选班干部 | 组织和培养班集体、班级常规管理 |
| 通过集体影响个人、用个人影响集体 | 平行管理模式（马卡连柯） |
| 让学生参与制定班规、民主投票 | 民主管理模式、学生自主管理 |
| 师生共同制定目标、逐级分解 | 目标管理模式 |
| 教师当众批评、讽刺学生，学生顶撞 | 违背尊重信任原则、师生关系紧张 |
| 教师课后主动沟通、道歉、平等交谈 | 民主平等的新型师生关系、教育机智 |
| 课堂突然出现意外（停电、学生晕倒、学生提问超纲） | 教育机智、课堂突发事件处理 |
| 学生上课打闹、小声说话、睡觉 | 课堂问题行为处理 |
| 学生迟到、旷课、屡次不交作业 | 常规管理与个别教育、德育原则 |
| 家长不理解、指责教师、要求换班 | 家校沟通、教育影响一致性 |
| 班级出现小团体、孤立某同学 | 非正式群体引导、班级文化建设 |

### 5.2 理论清单

- **班集体**：形成阶段（组建—形成—发展）；良好班集体特征（共同目标、组织机构、规章制度、正确舆论、和谐人际关系）。
- **班级管理模式**：常规管理、平行管理、民主管理、目标管理。
- **班主任工作**：了解学生（前提）→ 组织培养班集体（中心）→ 个别教育 → 协调各方 → 操行评定。
- **课堂管理**：课堂气氛类型；课堂纪律类型（教师促成、集体促成、任务促成、自我促成）；问题行为处理原则。
- **师生关系**：新型师生关系特征（尊师爱生、民主平等、教学相长、心理相容）；影响师生关系的因素（教师素质、学生特点、环境）。
- **教育机智**：含义、表现（因势利导、随机应变、掌握分寸、对症下药）、培养。
- **德育原则**：尊重信任与严格要求相结合（处理冲突必用）。

### 5.3 答题句式

> 材料反映的是**班级管理（或师生关系、课堂问题行为）**问题。
> 该教师的做法存在问题（值得肯定），具体表现在：①……②……
> 从××理论看，教师应……（用班集体理论、师生关系理论、教育机智等）。
> 如果我是班主任，我会：①**事前**……②**事中**……③**事后**……（按时间顺序写，最容易得分）。

### 5.4 完整示范答案一

**材料**：新学期，李老师接手五年级（3）班。这个班纪律松散，上课时说话的、传纸条的不断，作业常有十几人不交。李老师没有急于批评学生，而是用一周时间与每个学生单独谈了话，记下他们的兴趣和家庭情况；随后组织全班讨论"我们希望三班是什么样子"，共同拟定了 8 条班规并贴在墙上；通过自荐和投票选出班委，还设立了"图书管理员""绿植养护员""课间安全员"等岗位，让每个学生都有事做。一个月后，班级秩序明显好转，有学生在日记里写："我是三班的人，我也有责任。"

**问题**：请结合班级管理理论，分析李老师的做法。

**示范答案**：

李老师的做法是成功而符合教育规律的，其核心在于把"管学生"转变为"建集体"。

① **重视了解和研究学生这一前提**。材料中李老师"用了一周时间与每个学生单独谈话""记下他们的兴趣和家庭情况"，这正符合班主任工作以了解学生为基础的要求。只有掌握了学生的个性与家庭背景，后续的班级建设才能对症下药。

② **确立了班集体的共同奋斗目标**。李老师组织全班讨论"我们希望三班是什么样子"，把教师的单方要求转化为学生共同认可的集体愿景，符合良好班集体"有共同的奋斗目标"这一特征，也体现了班级目标管理模式的思想。

③ **体现了民主管理模式与学生自主管理**。班规不是教师单方面制定，而是"共同拟定"；班委通过"自荐和投票"产生，学生成为班级制度的制定者与执行者。这使得规则由外在约束转化为内在认同，学生从"被管"走向"自治"，体现了民主管理与自我教育的要求。

④ **运用了平行管理模式**。通过"让每个学生都有事做"，用集体建设促进个人成长，又通过个人的责任承担反哺集体。学生日记中"我是三班的人，我也有责任"正是集体意识形成的标志，说明班集体已进入自觉阶段。

⑤ **发挥了积极的集体舆论与班级文化的作用**。班规上墙、岗位命名富有仪式感，营造了"人人有责"的班级精神文化，属于隐性课程的作用，对纪律的持续稳定具有重要意义。

⑥ **体现了尊重信任与严格要求相结合原则**。李老师没有"急于批评学生"，给了学生体面与空间，同时又通过明确的班规提出了严格要求，做到了严而有爱。

总体而言，李老师的做法遵循了班集体形成的规律（组建—形成—发展），通过目标、组织、制度、舆论四条线建设班集体，值得借鉴。

> **采分点自查**：表态 2 分；了解学生 3 分；共同目标 4 分；民主管理/自主管理 4 分；平行管理 3 分；班级文化/舆论 2 分；尊重与严格要求 2 分。材料是"正面范本"，要全肯定并把每条做法都对应到理论上。

### 5.5 完整示范答案二

**材料**：数学课上，王老师正在板书，听见后排有动静，回头发现小杰在给同学传漫画书。王老师当场把书没收，说："小杰，你成绩本来就差，还带坏全班，给我站到教室后面去！"小杰大声说："我又没影响别人，凭什么罚站！"两人僵持了几分钟，课堂气氛紧张，其他学生都不敢出声。课后，王老师把小杰叫到办公室，才发现他昨晚照顾生病的奶奶到很晚，上课实在困得不行，想借漫画提神。

**问题**：请评析王老师的处理方式，并说明如果你是王老师会怎么做。

**示范答案**：

王老师的处理方式是不妥的，虽是出于维持纪律的良好愿望，但方式简单粗暴，既伤害了学生，也影响了教学。

**问题分析**：

① **处理方式简单生硬，缺少教育机智**。教育机智要求教师面对突发情况能迅速判断、巧妙处理，做到因势利导、掌握分寸。材料中王老师"当场没收""当众说成绩本来就差，还带坏全班""罚站"，语言带有侮辱性与标签化，把偶发行为升级为师生对抗，导致课堂"僵持了几分钟"，其他学生"都不敢出声"。

② **违背了尊重学生与严格要求学生相结合原则**。严格要求不等于当众羞辱。王老师未了解原因就下判断、给处分，并用"成绩本来就差"否定学生的人格，伤害其自尊心，这正是小杰"大声顶撞"的直接原因。

③ **违背了课堂问题行为处理的基本要求**。处理课堂问题行为应做到"及时、冷静、低调、对事不对人"，尽量不影响正常教学。王老师本可以用走近、眼神示意等低调方式先维持教学，却选择了"公开对峙"。

④ **忽视了行为背后的原因**。小杰"昨晚照顾生病的奶奶到很晚"，属疲劳导致注意力难以集中，且是偶发行为。教师未做了解就定性为"带坏全班"，既不公平，也错过了教育契机。

⑤ **从师生关系角度看**，新型师生关系强调民主平等、心理相容。王老师的做法使师生关系走向对立，说明缺的正是"先了解，再处理"。

**如果我是王老师，我会**：一是**事中**冷静处理——边讲课边走到其座位旁轻敲课桌，把书暂时收起，继续上课；二是**课间个别沟通**——先问"你看起来特别困，是不是昨晚没休息好？"，了解真实原因；三是**给出可行办法**——提醒他课前洗把脸、暂时坐到靠前位置、困了可举手示意，并与家长沟通保障睡眠；四是**课后跟进**——说明课堂纪律的必要性，与其约定课堂行为规则；五是**反思自身**——避免"成绩差""带坏全班"这类标签化语言，多用"我注意到……"的表达。

> **采分点自查**：表态 2 分；教育机智缺失 4 分；尊重与严格要求 4 分；课堂问题行为处理要求 3 分；忽视原因 3 分；师生关系 2 分；具体做法 6 分（按事前/事中/事后写最清晰）。"如果我是老师"这类设问，做法部分几乎占一半分，必须写具体。

## 六、看不准方向时如何保底得分（通用框架）

> 考场最怕"读完材料不知道考哪个理论"。这时**不要空着、不要瞎写**，用下面的通用框架，至少能拿到 60%～70% 的分数。

### 6.1 五步保底法

| 步骤 | 写什么 | 字数 |
|---|---|---|
| 1 表态 | "材料中×老师的做法总体上是恰当的（存在明显不足），需要辩证看待。" | 1～2 句 |
| 2 一般原理 | "教育要以学生发展为本，遵循学生身心发展规律，做到科学性与教育性统一。" | 1～2 句 |
| 3 借力"万能三件套" | 从下面"万能理论池"挑 3 条，每条配一句材料 | 3 组，150～250 字 |
| 4 具体展开 | 对其中最有把握的 1～2 条写深一点（含义 + 材料 + 效果） | 100～150 字 |
| 5 建议/总结 | "因此，教师应……；同时要避免……"（3 条具体措施） | 80～120 字 |

### 6.2 万能理论池（几乎任何材料都能沾上，按顺序挑）

| 序号 | 万能角度 | 通用表述（可直接抄） |
|---|---|---|
| 1 | **以学生为本/学生主体** | 是否尊重学生的主体地位，是否调动了学生的主动性、积极性 |
| 2 | **启发性原则** | 是否引导学生独立思考，还是一味直接给答案、满堂灌 |
| 3 | **因材施教原则** | 是否关注学生个体差异，能否做到分层要求、个别对待 |
| 4 | **尊重信任与严格要求相结合** | 是否保护学生人格尊严，是否在尊重的基础上提出明确要求 |
| 5 | **直观性原则/理论联系实际** | 是否借助实物、情境帮助学生理解，是否联系生活实际 |
| 6 | **发展性评价/形成性评价** | 评价是否促进发展、是否具体、是否以鼓励为主、是否多元 |
| 7 | **新型师生关系（民主平等、教学相长）** | 师生是否平等对话，教师能否倾听、能否承认错误 |
| 8 | **教育机智** | 面对突发情况能否冷静、巧妙、有分寸地处理 |
| 9 | **德育规律（长期性、反复性）** | 学生成长有反复，需要反复抓、抓反复 |
| 10 | **家校社协同（一致性连贯性）** | 是否形成教育合力，还是互相推责 |
| 11 | **教育法律法规/学生权利** | 是否侵犯学生的人格尊严权、受教育权（体罚、劝退、羞辱） |
| 12 | **教师职业道德** | 是否关爱学生、教书育人、为人师表 |

### 6.3 万能句式（保底组合，抄下来就是一段）

> 材料中×老师的做法既有值得肯定之处，也存在明显不足。
> 从"以学生为本"的理念看，教师应尊重学生的主体地位，调动其主动性。材料中"……"，说明（没有）做到了这一点。
> 从教学（德育）原则看，教师应遵循（启发性/因材施教/尊重信任与严格要求相结合）原则。材料中"……"，体现了（违背了）该原则的要求，其结果是……。
> 从评价的角度看，教师应采用发展性评价，以鼓励为主、具体指导。材料中"……"，反映出评价方式（较为恰当/有待改进）。
> 因此，作为教师，应做到：①了解学生、因材施教；②改进方法、启发引导；③尊重学生、严慈相济；④家校协同、形成合力。

### 6.4 三种特殊设问的应对

| 设问 | 应对要点 |
|---|---|
| "请分析该学生的问题及原因" | 先**定性**（是什么问题），再分**个人、学校（教师）、家庭、社会**四个维度找原因，最后给措施；原因与措施数量对应 |
| "如果你是这位老师，你会怎么做" | 按**事前—事中—事后**三段写，每条都要具体到动作（"我会……，并……"），不要只写理念 |
| "请评析该老师的做法" | 必须**先表态**，再"优点 2～3 条 + 不足 1～2 条 + 改进建议"，只夸或只批都要扣分 |

## 七、书写规范与时间分配（细节分）

### 7.1 排版规范（直接影响阅卷体验）

1. **必须分点编号**：一、二、三；（一）（二）；①②③④。同一层级编号要统一。
2. **每点先写理论名称，再写材料**：把理论名称加粗或写在句首，方便阅卷老师一眼看到采分点。
3. **引材料必须打引号**，引用原话（"材料中×老师说'……'"），不要只写"材料中老师做得好"。
4. **每点 2～3 行**，不要一大段到底；点与点之间空一行更清晰。
5. **结尾单独一段**写总结或建议，让答案有"收束感"。
6. 字迹工整、不出格、不涂改；写错划一条横线即可。

### 7.2 时间分配（材料分析共 40 分，建议 35～40 分钟）

| 阶段 | 时间 | 动作 |
|---|---|---|
| 读材料 | 3 分钟 | 圈出教师行为、学生反应、关键对话 |
| 定方向 | 1 分钟 | 判断属于四大方向中的哪一个（教学/德育/心理/班级） |
| 列提纲 | 2 分钟 | 在草稿区写下 3～5 个理论名称 + 对应材料关键词 |
| 书写 | 12～15 分钟/题 | 按四步法写，注意分点 |
| 检查 | 2 分钟 | 看有无漏问、有无只写理论不引材料、有无错别字 |

### 7.3 十大失分点自查清单

| 序号 | 失分点 | 自查 |
|---|---|---|
| 1 | 没有表态，上来就分析 | ☐ |
| 2 | 只写理论名称，不解释、不引材料 | ☐ |
| 3 | 只复述材料，不写理论 | ☐ |
| 4 | 理论与材料对不上（写的原则与材料行为无关） | ☐ |
| 5 | 设问有两问，只答了一问（尤其漏"建议""怎么做"） | ☐ |
| 6 | 分点不清、一大段到底 | ☐ |
| 7 | 自造原则名称（如"爱心原则""鼓励原则"） | ☐ |
| 8 | 缺少"学生是主体""以学生为本"这类总结性表述 | ☐ |
| 9 | 字数过少（不足 300 字，明显拿不满分） | ☐ |
| 10 | 字迹潦草、超出答题区 | ☐ |

### 7.4 考前训练建议

1. **先抄 3 篇示范答案**（每天 1 篇），抄的过程中体会"理论 + 材料"的配对方式。
2. **再做"只列提纲"训练**：拿 10 道材料题，只写理论名称与对应材料关键词，每题 5 分钟，练"识别"速度。
3. **最后限时整篇模写**：每题 15 分钟，写完对照采分点自查表打分。
4. **建立个人"素材本"**：把常考理论名称、含义、材料信号词记在一页纸上，考前只看这一页。
