## Day1（考前第 7 天）教育基础

### 一、教育的本质与属性（★）

| 项目 | 内容 |
|---|---|
| **本质属性** | 教育是**有目的地培养人的社会活动**（区别于其他社会活动的根本特征） |
| **社会属性** | **永恒性**（与人类社会共始终）、**历史性**（不同时代不同性质）、**相对独立性**（有自身规律、有历史继承性、与生产力发展不平衡） |
| 三要素 | **教育者**（主导）、**受教育者**（主体）、**教育影响**（中介） |

### 二、教育起源四说（★只考"谁提出+核心词"）

| 学说 | 代表人物 | 核心观点 |
|---|---|---|
| 神话起源说 | — | 最古老，教育由神创造 |
| **生物起源说** | **利托尔诺、沛西·能** | 教育起源于动物界的生存本能（**第一个正式提出**） |
| **心理起源说** | **孟禄** | 教育起源于儿童对成人**无意识的模仿** |
| **劳动起源说** | **米丁斯基、凯洛夫** | 教育起源于人类**生产劳动**（马克思主义观点） |

> 口诀：**本能利沛、模仿孟禄、劳动米凯**。

### 三、教育与社会、与人的发展（★简答高频）

| 关系 | 要点 |
|---|---|
| 政治经济制度 → 教育 | 决定教育的**性质、领导权、受教育权、教育目的** |
| 教育 → 政治 | 培养所需人才、促进**政治民主化**、传播思想形成舆论 |
| 生产力 → 教育 | 决定教育的**规模与速度、结构、内容与方法手段** |
| 教育 → 生产力 | **再生产劳动力**、**再生产科学知识** |
| 文化 → 教育 | 影响教育内容与教育传统 |
| 教育 → 文化 | **传承、选择、融合、创新** |
| 人口 → 教育 | 数量、质量、结构、流动影响教育 |

### 四、个体身心发展 5 规律 + 4 因素（★★★★★ 必背）

| 规律 | 表现 | 教育要求 |
|---|---|---|
| **顺序性** | 由低到高、由简到繁，不可逆不可躐等 | **循序渐进** |
| **阶段性** | 不同年龄阶段有不同特征与主要矛盾 | 分阶段教育、**针对性** |
| **不平衡性** | 同一方面不同速、不同方面不同步 | 抓住**关键期** |
| **互补性** | 生理与生理、生理与心理可互补 | **扬长避短**、长善救失 |
| **个别差异性** | 个体之间在发展水平、速度、优势领域上不同 | **因材施教** |

| 因素 | 作用 |
|---|---|
| **遗传** | 生理**前提**、物质基础，为发展提供可能性 |
| **环境** | 现实条件，把可能变为现实 |
| **学校教育** | 起**主导作用**（有目的、有计划、有组织、有专职人员） |
| **个体主观能动性** | 是促进个体发展的**决定性因素** |

> 三理论：**内发论**（孟子、霍尔、格塞尔）／**外铄论**（荀子、洛克、华生）／**多因素相互作用论**。

## Day2（考前第 6 天）学生指导：心理与学习理论

### 一、皮亚杰认知发展四阶段（★★★★★）

| 阶段 | 年龄 | 核心特征 |
|---|---|---|
| **感知运动阶段** | 0—2 岁 | 感觉与动作；获得**客体永久性** |
| **前运算阶段** | 2—7 岁 | **自我中心**、思维不可逆、**泛灵论**、未获守恒 |
| **具体运算阶段** | 7—11 岁 | **守恒**、可逆、去自我中心；需具体事物支持（**小学生主要处于此阶段**） |
| **形式运算阶段** | 11—16 岁 | 抽象思维、**假设—演绎**推理 |

> 口诀：**感前具形，二七十一十六**。

### 二、小学生心理发展特点（★简答）

| 方面 | 特点 |
|---|---|
| **注意** | **无意注意占优势**，有意注意逐步发展；注意广度小、稳定性差、分配与转移能力弱 |
| **记忆** | 由**无意记忆、机械记忆**为主向有意记忆、意义记忆发展；**艾宾浩斯遗忘曲线：先快后慢** |
| **思维** | 以**具体形象思维**为主，逐步向**抽象逻辑思维**过渡；小学四年级（10—11 岁）是关键期 |
| **想象** | 有意想象增强、创造性成分增加、更富于现实性 |
| **情绪** | 易激动、外露、稳定性差，逐步学会调节 |
| **自我意识** | 自我评价由**具体、外部**向抽象、内部发展；由依赖他人评价向独立评价过渡 |
| **品德** | 从他律到自律（皮亚杰）、从前习俗到习俗水平（科尔伯格） |

**认知风格**：**场独立型** vs **场依存型**（威特金）；**冲动型** vs **沉思型**（卡根）。
**智力理论**：斯皮尔曼二因素（G 因素/S 因素）、卡特尔流体与晶体智力、**加德纳多元智能**、斯腾伯格三元智力。

### 四、学习动机（★★★★★ 最高频）

| 分类 | 类型 |
|---|---|
| 按来源 | **内部动机** / **外部动机** |
| 按与活动关系 | 近景直接性动机 / 远景间接性动机 |
| **奥苏贝尔** | **认知内驱力**（最稳定、最重要、内部）、**自我提高内驱力**（外部）、**附属内驱力**（外部，儿童早期最突出） |

**两个基本成分**：**学习需要**（内驱力）＋ **学习期待**（诱因）。

**耶克斯—多德森定律**：动机强度与效率呈**倒 U 形**；**中等动机最有利**；任务越**难**，最佳动机水平越**低**。

| 理论 | 人物 | 核心 |
|---|---|---|
| 强化理论 | 斯金纳 | 动机由外部强化引起 |
| 需要层次理论 | **马斯洛** | 七层：生理、安全、归属与爱、尊重、认知、审美、自我实现；前四层为**缺失性需要**，后三层为**成长性需要** |
| 成就动机理论 | **阿特金森** | 力求成功者选**50%** 中等难度任务；避免失败者选极易或极难 |
| **成败归因理论** | **韦纳** | 六因素三维度（见下表） |
| 自我效能感 | **班杜拉** | 影响活动的选择、努力、坚持与情绪 |
| 成就目标理论 | 德韦克 | **掌握目标**（能力增长观）vs **表现目标**（能力实体观） |
| 习得性无助 | 塞利格曼 | 反复失败后放弃努力 |

**韦纳归因表（必须默写）**：

| 因素 | 内外 | 稳定 | 可控 |
|---|---|---|---|
| **能力** | 内部 | **稳定** | 不可控 |
| **努力** | 内部 | **不稳定** | **可控** |
| **任务难度** | 外部 | **稳定** | 不可控 |
| **运气** | 外部 | 不稳定 | 不可控 |
| 身心状况 | 内部 | 不稳定 | 不可控 |
| 外界环境 | 外部 | 不稳定 | 不可控 |

> 教育启示：引导学生归因于**努力**（内部、不稳定、可控）；归因于**能力**易导致习得性无助。

**自我效能感四来源**：**直接经验**（影响最大）、替代经验、言语说服、情绪唤醒。

**动机激发 6 法**：创设问题情境（启发式教学）、控制动机水平、利用反馈信息、指导结果归因、合理设置竞争与合作、提供成功体验。
**动机培养 5 法**：满足需要、立志教育、正确自我概念、努力归因观、自我强化。

### 五、学习迁移（★）

| 理论 | 人物 | 核心 |
|---|---|---|
| 形式训练说 | 沃尔夫 | 训练官能，自动迁移 |
| **共同要素说** | **桑代克、伍德沃斯** | 两种学习有**共同要素**才迁移 |

| **关系转换说** | **苛勒** | 领悟情境中的**关系**才迁移 |

> 促进迁移：精选教材、合理编排教学内容、教授学习方法与策略、创设相似情境、加强练习与反馈。

### 六、学习策略与技能（★）

| 策略 | 具体 |
|---|---|
| **认知策略** | **复述**（重复）、**精加工**（联想、举例、做笔记）、**组织**（列提纲、画图表、分类） |
| **元认知策略** | **计划**、**监控**、**调节** |

- **心智技能三阶段**（冯忠良）：**原型定向 → 原型操作 → 原型内化**。

### 七、问题解决与创造性（★简答）

**问题解决过程**：发现问题 → 理解问题 → 提出假设 → 检验假设。
**影响因素**：知识经验、**定势与功能固着**、问题表征方式、动机与情绪、原型启发。
**创造性核心**：**发散思维**（流畅性、变通性、独创性）。

## Day3（考前第 5 天）德育与班级管理

### 一、德育过程四规律（★★★★★）

| 规律 | 内涵 | 教育要求 |
|---|---|---|
| **①知情意行统一** | 道德认识、情感、意志、行为相互促进；**知是基础，行是关键** | 晓之以理、动之以情、持之以恒、导之以行 |
| **②在活动和交往中形成** | 活动与交往是德育的**基础与源泉** | 组织有教育意义的活动 |
| **③促进学生内部矛盾斗争** | 把社会要求转化为自身需要 | 激发内在动机，培养自我教育能力 |
| **④长期、反复、逐步提高** | 品德形成需长期积累，会出现反复 | **抓反复、反复抓** |

> 口诀：**知行活动矛盾长**（知情意行—活动交往—内部矛盾—长期反复）。

### 二、德育九原则（★★★★★ 材料题必用）

| # | 原则 | 关键词 |
|---|---|---|
| 1 | **导向性原则** | 明确政治方向 |
| 2 | **疏导原则**（循循善诱） | 讲明道理、以理服人、因势利导 |
| 3 | **尊重学生与严格要求学生相结合** | **严慈相济** |
| 4 | **教育的一致性与连贯性原则** | 校内统一、家校社会协调、前后连贯 |
| 5 | **因材施教原则** | 从实际出发，针对年龄特征与个别差异 |
| 6 | **知行统一原则** | 既重认识又重实践，言行一致 |
| 7 | **正面教育与纪律约束相结合** | 正面引导 + 必要制度约束 |
| 8 | **发扬积极因素、克服消极因素**（长善救失） | 一分为二、发现闪光点 |
| 9 | **集体教育与个别教育相结合**（平行教育） | 通过集体教育个人，通过个人教育集体 |

> 口诀：**向导疏，尊严一；因知行，正长集。**
> 易混：第 3 条重**态度**（严慈相济）；第 7 条重**管理手段**（说服 + 制度）。

### 三、德育六方法（★★★★★）

| 方法 | 内涵 | 关键词 |
|---|---|---|
| **说服教育法** | 摆事实、讲道理，提高道德认识 | 讲解、报告、谈话、讨论、参观 |
| **榜样示范法** | 以他人高尚思想、模范行为影响学生 | 领袖、教师、同学、家长；**教师身教最直接** |
| **实际锻炼法** | 通过实际活动训练行为习惯 | 常规训练、实际锻炼 |
| **情感陶冶法** | 创设情境，潜移默化 | **人格感化、环境陶冶、艺术陶冶** |
| **道德修养法**（自我教育法） | 引导自我反省、自我教育 | 立志、学习、反思、**慎独**、座右铭 |
| **品德评价法** | 通过肯定或否定评价教育学生 | **奖励、惩罚、评比、操行评定** |

> 区分：**说服重"说理"**（明理），**陶冶重"熏染"**（情境感受）。题干"讲道理"→说服；"创设氛围、潜移默化"→陶冶。

**德育途径**：**思想品德课（道德与法治课）与其他学科教学**是**最基本、最经常、最主要的途径**；另有课外校外活动、劳动与社会实践、少先队活动、班会校会、班主任工作。

**德育模式**：认知模式（皮亚杰、科尔伯格）、体谅模式（麦克费尔）、社会模仿模式（班杜拉）、价值澄清模式（拉斯、哈明）。

### 四、班级与班集体（★★★★★）

| 项目 | 内容 |
|---|---|
| **班级** | 学校为实现教育目的，把年龄和知识程度相近的学生编班分级而形成的**基本教育单位**（组织形式） |
| **班集体** | 班级群体发展的**高级形态**，是教育主体 |
| **班集体四阶段** | **组建阶段**（班主任主导）→ **核心形成阶段**（班干部产生）→ **发展阶段**（舆论与班风初步形成）→ **成熟阶段**（自主管理） |
| **班集体六特征** | ①**明确的共同奋斗目标**（首要标志）②健全的组织机构与坚强的领导核心 ③严格的规章制度与共同的生活准则 ④**正确的舆论和良好的班风**（最重要标志）⑤开展丰富多彩的集体活动（形成基础）⑥平等友爱互助的人际关系与集体荣誉感 |

> **易错**：班集体形成的标志**不是"选出班干部"**，而是"形成正确的舆论与良好班风"＋"共同奋斗目标"。

**培养班集体的方法**：确定共同奋斗目标（由易到难、分阶段）、选拔培养班干部、建立班规、培养正确舆论与良好班风、开展集体活动、做好个别教育。

### 五、班主任工作（★简答）

| 项目 | 内容 |
|---|---|
| 角色 | 班级的组织者、领导者和教育者；学生成长的引路人；沟通学校、家庭、社会的桥梁 |
| **八项工作内容** | ①**了解和研究学生**（前提）②**组织和培养班集体**（**中心工作**）③建立学生成长档案 ④**个别教育**（优等生、后进生、中等生）⑤组织班会和课外活动 ⑥协调各方教育影响（家校沟通）⑦**操行评定** ⑧写好工作计划与总结 |
| 工作方法 | 说理教育法、**情感陶冶法**、榜样示范法、实际锻炼法、表扬奖励与批评处分 |

> **后进生转化**：关心爱护、尊重人格 → 查明原因 → 发现闪光点（长善救失）→ 培养学习兴趣与自信 → 持之以恒、抓反复。

### 六、课堂管理（★）

| 项目 | 内容 |
|---|---|
| 课堂气氛三类型 | **积极**（活跃有序）、**消极**（压抑松散）、**对抗**（师生对立） |
| 课堂纪律四类型 | **教师促成的纪律**、**集体促成的纪律**、**任务促成的纪律**、**自我促成的纪律**（**最高境界**） |
| 问题行为两类 | **外向性**（打闹、顶撞，易发现）／**内向性**（走神、退缩，不易发现、危害隐蔽） |
| 处理原则 | 预防为主；及时、冷静、**低调处理**；**对事不对人**；分析原因、区别对待；运用集体舆论与正向强化 |

**教育机智**：面对意外能迅速判断、巧妙处理的能力；表现为因势利导、随机应变、掌握分寸、对症下药。处理模板：**稳定情绪 → 快速判断 → 巧妙转化 → 保证教学 → 课后跟进**。

## Day4（考前第 4 天）教学原则与方法

### 一、教学过程四条规律（★★★★★）

| 规律 | 内涵 |
|---|---|
| **①间接经验与直接经验相统一** | 以学习**间接经验**为主，以直接经验为基础 |
| **②掌握知识与发展能力相统一** | 掌握知识是发展能力的基础，发展能力又促进知识掌握 |
| **③教师主导与学生主体相统一** | 教师主导作用与学生主动性结合，反对教师中心与儿童中心 |
| **④传授知识与思想品德教育相统一**（教学的教育性） | 教学永远具有教育性 |

> 口诀：**间直、知能、主主、知德**。

**教学过程五阶段**：**激发学习动机 → 领会知识（感知教材、理解教材，中心环节）→ 巩固知识 → 运用知识 → 检查知识**。

### 二、教学原则八条（★★★★★ 材料分析最高频）

| 原则 | 含义（一句话） | 材料信号词 | 贯彻要求关键词 |
|---|---|---|---|
| **直观性** | 用实物、形象化手段或语言描述使学生获得表象 | 实物、模型、挂图、演示、视频、形象描述 | 选好教具、直观与讲解结合、语言直观、适时适度 |
| **启发性** | 调动学生主动性，引导独立思考、积极探索 | 提问、追问、引导发现、不直接给答案 | 调动主动性、启发思维、动手实践、教学民主 |
| **循序渐进**（系统性） | 按学科逻辑系统与学生认识顺序教学 | 由浅入深、由易到难、前后衔接、系统复习 | 按系统教、抓重点难点、连贯有序、及时巩固 |
| **巩固性** | 使知识牢固保持并能迅速再现 | 复习、当堂检测、小结、变式练习 | 理解基础上巩固、组织复习、练习运用、教记忆方法 |
| **因材施教** | 统一要求下照顾个别差异，有的放矢 | 分层作业、个别辅导、不同要求、发现特长 | 统一与个别结合、了解学生、区别对待、长善救失 |
| **理论联系实际** | 从实际理解理论，学以致用 | 生活实例、参观、操作、实践作业 | 联系实际、培养运用能力、教学与训练结合、乡土教材 |
| **科学性与思想性（教育性）相统一** | 知识正确无误 + 价值引领 | 准确讲授 + 自然渗透教育 | 保证科学性、挖掘思想性、自然渗透、以身作则 |
| **量力性**（可接受性） | 内容、方法、分量、进度适合学生又有一定难度 | 难度适当、有梯度、作业适量 | 了解水平、难度适当、考虑年龄特征、防止过难过易 |

> 口诀：**直启循巩因，理科量**。
> 易混：**直观性**重"感知获得表象"；**理论联系实际**重"学以致用"。**循序渐进**重"顺序系统"；**量力性**重"难度分量吃不吃得消"。

**答题固化格式**：原则名称 → 含义一句 → 材料中的做法 → 体现/违背了什么 → 正确做法应如何。

### 三、教学方法（★分类 + 常用方法）

| 类别 | 方法 |
|---|---|
| 以**语言传递**为主 | **讲授法**（讲述、讲解、讲读、讲演）、**谈话法**、**讨论法**、读书指导法 |
| 以**直观感知**为主 | **演示法**、**参观法** |
| 以**实际训练**为主 | **练习法**、**实验法**、实习作业法、实践活动法 |
| 以**情感陶冶**为主 | 欣赏教学法、**情境教学法** |
| 以**探究**为主 | **发现法**（布鲁纳） |

**选用依据**：教学目的与任务、课程性质与教材特点、学生年龄特征与知识水平、教师自身素质、教学时间与设备条件。

**新课改倡导的学习方式**：**自主学习、合作学习、探究学习**。

### 四、教学组织形式（★）

| 形式 | 要点 |
|---|---|
| **班级授课制** | **夸美纽斯**确立；特点"**班、课、时**"；优点：大面积培养、系统高效；缺点：难兼顾个别差异、不利于培养创新 |
| 个别教学制 | 一对一，古代主要形式 |
| 分组教学 | 按能力或成绩分组 |
| **复式教学** | 一个教师在同一节课内对**两个以上年级**同时教学（适用于人口分散地区） |
| 现场教学 | 到现场（工厂、博物馆）教学 |
| 道尔顿制 | 学生自学 + 教师辅导，取消班级授课 |

### 五、教学工作五环节（★★★★★）

| 环节 | 要点 |
|---|---|
| **①备课** | **三备**：备教材、备学生、备教法；**三写**：学期计划、单元计划、课时计划（教案） |
| **②上课** | 教学工作的**中心环节**，是提高质量的关键 |
| **③作业布置与批改** | 分量适当、难度适度、形式多样、及时反馈 |
| **④课外辅导** | 个别辅导、答疑、补差 |
| **⑤学业成绩检查与评定** | 平时考查 + 考试；**命题要科学、评分要公正** |

### 六、一堂好课的标准（★★★★★ 简答必背）

> 口诀：**目内方表组气效**。

| 标准 | 要求 |
|---|---|
| ① **目标明确** | 目标符合课标与学生实际，具体可测，整节课围绕目标 |
| ② **内容正确** | 知识准确、重点突出、难点突破、容量适当 |
| ③ **方法得当** | 方法恰当灵活、符合学科与学生特点、注重启发 |
| ④ **表达清晰** | 语言准确生动、板书规范条理 |
| ⑤ **组织严密** | 环节紧凑、过渡自然、时间分配科学 |
| ⑥ **气氛热烈** | 学生注意力集中、思维活跃、参与面广、师生融洽 |
| ⑦ **效果好** | 各层次学生都有收获，目标达成度高 |

### 七、教学模式（★只考"提出者 + 环节"）

| 模式 | 提出者 | 环节 |
|---|---|---|
| 传递—接受 | 赫尔巴特四段 / 凯洛夫五环节 | 复习旧知—导入新课—讲授新知—巩固练习—布置作业 |
| **探究（发现）** | **布鲁纳** | 提出问题—创设情境—提出假设—验证假设—得出结论 |
| **范例教学** | **瓦·根舍因** | 阐明"个"—阐明"类"—掌握规律—获得经验 |
| **抛锚式** | 建构主义 | 创设情境—确定问题—自主学习—协作学习—效果评价 |
| **支架式** | 建构主义（源于**最近发展区**） | 搭脚手架—进入情境—独立探索—协作学习—效果评价 |
| **掌握学习** | **布卢姆** | 目标—教学—形成性测验—矫正—平行测验 |
| 程序教学 | **斯金纳** | 小步子—呈现问题—即时反馈—自定步调 |
| 非指导性 | **罗杰斯** | 创设氛围—探索问题—形成见识—计划行动 |

## Day5（考前第 3 天）教学评价与新课改

### 一、教学评价按作用分类（★★★★★ 必背）

| 类型 | 时间点 | 目的 | 例子 |

| **诊断性评价** | 教学活动**开始前** | 摸底、了解基础与问题，便于分层安置 | 入学摸底测验、单元前测 |
| **形成性评价** | 教学活动**过程中** | 及时反馈、**改进**教与学，不重甄别 | 课堂提问、随堂练习、单元小测、作业批改 |
| **总结性评价** | 教学活动**结束后** | **鉴定**、评定成绩、判断目标达成度 | 期末考试、毕业考试、结业评定 |

> 口诀：**诊断在前、形成在中、总结在后**；形成重"改进"，总结重"鉴定"。

### 二、按评价标准分类（★★★★★ 最易混）

| 类型 | 参照标准 | 例子 |
|---|---|---|
| **相对评价**（常模参照） | 参照**团体平均水平/名次** | 班级排名、选拔性考试、高考 |
| **绝对评价**（标准参照） | 参照**预先确定的目标/标准** | 教师资格考试、驾照考试、单元达标测 |
| **个体内差异评价** | 参照**自身过去或自身各方面** | 成长档案袋、前后测对比、偏科分析 |

> 口诀：**相对看名次、绝对看标准、个体看自己**。

**其他分类**：按主体（他评/自评）、按内容（学业/品德/综合素质）、按方法（定量/定性）。

**评价原则**：客观性、发展性、指导性、计划性、科学性。

### 三、新课改评价理念（★材料分析采分点）

1. 评价目的重在**促进发展**，而非甄别选拔；
2. 评价内容**多元化**（知识、能力、情感态度价值观）；
3. 评价方式**多样化**（形成性与终结性结合、定性与定量结合）；
4. 评价主体**多元化**（教师、学生自评互评、家长）；
5. 关注**过程**，重视表现性评价与成长记录袋。

## Day7（考前第 1 天）教学设计模板与模考

### 一、题型与分值（★先看清问几问）

教学设计题 **40 分**，通常给语文、数学、英语、音乐、体育、美术六个学科片段，**六选一**；常见小问：①写教学目标 ②写重难点 ③设计教学过程（含导入、新授、巩固、小结、作业）④写板书设计 ⑤说明设计意图。

### 二、教学目标写法（★核心采分点，ABCD 法）

| 要素 | 要求 |
|---|---|
| **A 主体** | 必须是**学生**（不能写"使学生……""培养学生……"） |
| **B 行为** | 用**可观察、可检测**的动词：认读、会写、说出、计算、概括、复述 |
| **C 条件** | 说明在什么条件下完成："通过朗读""借助方格纸""在小组合作中" |
| **D 程度** | 说明达到什么水平："至少正确计算 3 道""能用自己的话说出" |

| 维度 | 句式 | 常用动词 |
|---|---|---|
| **知识与技能** | 学生能够（认读/理解/掌握/说出/计算）…… | 认读、会写、理解、掌握、复述、计算、概括 |
| **过程与方法** | 通过（朗读/观察/操作/小组合作/探究）……，学生能够（体会/学会/提高）…… | 经历、发现、体会、学会、提高 |
| **情感态度与价值观** | 学生能够（感受/体会/产生/养成/树立）……，增强…… | 感受、体会、激发、养成、树立、增强 |

**目标三条速检**：主体是不是学生？动词能不能测？有没有条件与程度？

### 三、教学重难点（★一句话区分）

- **教学重点**：教材中最基本、最主要的内容，是"**必须会的**"。
- **教学难点**：学生难以理解、容易混淆出错的地方，是"**不好懂的**"。
- 句式：重点＝理解（掌握）……；难点＝理解……的推导/形成过程，体会……的写法/情感。

### 四、教学过程五环节（40 分里的 20—25 分）

| 环节 | 时间 | 必写内容 |
|---|---|---|
| ① **导入新课** | 3—5 分钟 | 导入方式 + 具体情境 + 学生反应（激趣/复习/设疑） |
| ② **新课讲授** | 15—20 分钟 | 分 **2—3 个层次**，每层含提问、活动、教师点拨 |
| ③ **巩固练习** | 8—10 分钟 | 基础题 + 变式题 + 拓展题（分层） |
| ④ **课堂小结** | 3—5 分钟 | 学生说收获 + 教师板书梳理 + 情感升华 |
| ⑤ **布置作业** | 2 分钟 | 分层作业（必做 + 选做/实践性作业） |

> **加分写法**：每个环节用表格写"**教师活动 | 学生活动 | 设计意图**"三列，阅卷老师最认这种结构。

### 五、板书设计（★必须有）

| 类型 | 适用 | 形式 |
|---|---|---|
| 提纲式 | 结构清晰的课文、概念课 | 大括号、箭头分层列要点 |
| 表格式 | 对比性内容 | 2—3 列表格 |
| 图示式 | 写景散文、空间图形 | 简笔画 + 关键词 |
| 线索式 | 情节推进 | 箭头串关键词 |
| 对比式 | 异同比较 | 左右对照 |

**板书三要求**：与教学过程一一对应；只写关键词与结构；有课题、有层次、布局美观。

### 六、三科模板速套（考场直接换内容）

| 学科 | 教学过程骨架 |
|---|---|
| **语文（阅读课）** | 情境导入 → 初读（扫清字词、整体感知）→ 精读（抓关键词句、品析写法、朗读指导）→ 拓展（仿写/迁移）→ 小结作业（背诵/练笔） |
| **数学（概念课）** | 情境导入（生活问题）→ 探究（操作、对比、归纳，得出概念）→ 建构（抽象概括、板书定义）→ 应用（分层练习）→ 小结作业 |
| **英语（词汇/对话课）** | 歌曲/游戏导入 → 呈现（图片、实物、TPR）→ 操练（听音跟读、开火车、小组问答）→ 运用（情境对话、角色扮演）→ 小结作业 |

### 七、设计意图句式（独立采分点）

1. "通过……，激发学生的学习兴趣，为引出课题作铺垫。"
2. "通过……活动，引导学生经历……的过程，突破教学难点，落实……目标。"
3. "采用……方法，体现以学生为主体、教师为主导的教学理念。"
4. "分层作业兼顾不同水平学生，体现因材施教。"

### 八、常见扣分点（考前 10 分钟扫一遍）

| 扣分点 | 后果 |
|---|---|
| 目标主体写成"使学生" | 目标分直接扣 |
| 目标动词不可测（"了解""认识"单用） | 扣分 |
| 教学过程没有环节名称与时间 | 结构分丢 |
| 板书空着或只写课题 | 扣 3—5 分 |
| 只写教师做什么，没有学生活动 | 扣"以学生为主体"分 |
| 三问只答两问 | 直接丢一问的分 |

### 九、考场 20 分钟答题流程

| 时间 | 动作 |
|---|---|
| 0—3 分钟 | 选定学科，读教材片段，圈出知识点与课后题 |
| 3—6 分钟 | 写三维目标（4 条以内）+ 重难点 |
| 6—16 分钟 | 写教学过程五环节（表格三列） |
| 16—18 分钟 | 画板书 |
| 18—20 分钟 | 补设计意图、检查问数是否答全 |

### 十、最后一天模考清单

1. 限时 **120 分钟**做 1 套完整卷，按"单选 25 + 简答 25 + 材料 35 + 教学设计 30"分配。
2. 只做"提纲式模考"：主观题不写全文，只列要点，节省体力。
3. 对答案只统计**失分类型**（记不住／写不准／没结合材料／时间不够），不再纠结分数。
4. 晚上只背：德育 9 原则、教学 8 原则、60 条简答首句、教学设计五环节。
5. 考前确认：准考证、身份证、黑色签字笔 2 支、2B 铅笔、橡皮、手表。
