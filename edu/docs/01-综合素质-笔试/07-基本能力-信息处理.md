- **通配符**（勾选"使用通配符"后生效）：

| 通配符 | 含义 | 例子 |
|---|---|---|
| `?` | 任意**一个**字符 | `教?` 可匹配"教师""教学" |
| `*` | 任意**多个**字符 | `教*` 可匹配"教育""教学法" |
| `[abc]` | 方括号内任一字符 | `[甲乙丙]老师` |
| `[!abc]` | 不在方括号内的任一字符 | — |
| `<` `>` | 词首 / 词尾 | `<教育` 只匹配以"教育"开头的词 |

- **替换格式**：把光标放在"替换为"框内，点"格式"按钮设定字体/段落，可一次性批量改格式。**这是"格式刷"做不到的批量操作。**

### 1.3 页眉、页脚与页码

| 操作 | 路径 | 关键点 |
|---|---|---|
| 插入页眉/页脚 | 插入 · 页眉/页脚 | 双击页面顶部/底部空白处也可进入编辑 |
| 插入页码 | 插入 · 页码 | 可选位置（页边距/页面顶端/底端）与格式 |
| 首页不同 | 页眉页脚工具 · 设计 · "首页不同" | 封面不要页眉时勾选 |
| 奇偶页不同 | 页眉页脚工具 · 设计 · "奇偶页不同" | 书籍排版常用 |
| 退出编辑 | 双击正文 或 点"关闭页眉和页脚" | — |

**最易错的一点**：**分节之后，新一节的页眉页脚默认"链接到前一条"**。想让第 2 节的页眉与第 1 节不同，必须**先取消"链接到前一条"**（在"设计"选项卡中点击该按钮使其弹起），再修改。不取消就直接改，第 1 节也会跟着变。

### 1.4 分页符与分节符

| 类型 | 插入方式 | 作用 | 与"回车"的区别 |
|---|---|---|---|
| 分页符 | Ctrl+Enter，或 插入 · 分页 | 强制从下一页开始 | 用回车挤到下一页会随内容变动而错位，**分页符才是规范做法** |
| 分节符（下一页） | 布局 · 分隔符 · 分节符（下一页） | 新一节从新页开始，可独立设置页眉、页码、纸张方向 | 节是"独立排版单位" |
| 分节符（连续） | 布局 · 分隔符 · 分节符（连续） | 同一页上分节，可对不同节设不同栏数 | 常用于"上半页单栏、下半页双栏" |
| 分节符（奇数页/偶数页） | 布局 · 分隔符 | 新一节从下一个奇数/偶数页开始 | 书籍章节常用 |

> **一句话辨析**：**分页符只管"换页"，分节符才管"换排版规则"。** 想让第 3 页开始横向排版，必须插分节符，插分页符无效。

### 1.5 其他常考点

- **打印预览与打印**：Ctrl+P；可设置打印范围、双面、每页版数。
- **页面设置**：纸张大小 A4、页边距（上/下/左/右）、装订线、纸张方向（纵向/横向）。
- **插入表格**：插入 · 表格；可"绘制表格""拆分/合并单元格"。
- **插入图片**：插入 · 图片；设置"文字环绕方式"（嵌入型、四周型、紧密型、衬于文字下方、浮于文字上方）。
- **拼写与字数统计**：审阅 · 字数统计。
- **自动生成目录**：引用 · 目录，**前提是正文标题应用了"标题 1/2/3"样式**。

## 二、Excel 电子表格

### 2.1 基本概念

| 概念 | 说明 |
|---|---|
| 工作簿（Workbook） | 一个 .xlsx 文件，可含多个工作表 |
| 工作表（Sheet） | 工作簿中的一页，默认 Sheet1、Sheet2 |
| 单元格 | 行列交叉的格子，名称如 A1、B3 |
| 单元格地址 | 列标 + 行号；区域写作 A1:C10 |
| 编辑栏 | 显示与编辑单元格真实内容（公式在此可见） |

### 2.2 常用函数（必背）

| 函数 | 语法 | 作用 | 例子 |
|---|---|---|---|
| SUM | `=SUM(数值1,数值2,…)` | 求和 | `=SUM(B2:B10)` 求 B2 到 B10 之和 |
| AVERAGE | `=AVERAGE(区域)` | 求平均值 | `=AVERAGE(B2:B10)` |
| MAX | `=MAX(区域)` | 求最大值 | `=MAX(C2:C50)` |
| MIN | `=MIN(区域)` | 求最小值 | `=MIN(C2:C50)` |
| IF | `=IF(条件, 真时返回, 假时返回)` | 条件判断 | `=IF(B2>=60,"及格","不及格")` |
| COUNTIF | `=COUNTIF(区域, 条件)` | **按条件计数** | `=COUNTIF(B2:B40,">=90")` 统计 90 分及以上人数 |
| SUMIF | `=SUMIF(条件区域, 条件, 求和区域)` | **按条件求和** | `=SUMIF(A2:A40,"一班",B2:B40)` 求一班总分 |
| VLOOKUP | `=VLOOKUP(查找值, 查找区域, 返回列序号, 匹配方式)` | 竖向查找 | `=VLOOKUP(A2,$F$1:$G$30,2,0)` |
| RANK | `=RANK(数值, 引用区域, 排位方式)` | 排名 | `=RANK(B2,$B$2:$B$50,0)` |
| COUNT | `=COUNT(区域)` | 统计数值单元格个数 | — |
| COUNTA | `=COUNTA(区域)` | 统计非空单元格个数 | — |

**六个最容易考的细节**

1. **所有公式以 `=` 开头**。
2. **文本要加英文双引号**：`=IF(B2>=60,"及格","不及格")`，中文引号会报错。
3. **VLOOKUP 的第 4 个参数**：`0` 或 `FALSE` 表示**精确匹配**（最常用）；`1` 或 `TRUE` 表示近似匹配。**省略时默认近似匹配，极易出错，考试中务必写 0。**
4. **VLOOKUP 只能"向右查"**：查找值必须位于查找区域的**第一列**，返回列序号从查找区域第一列起算。要向左查，需用 INDEX+MATCH。
5. **RANK 的排位方式**：`0` 或省略为**降序**（数值最大的排第 1）；非 0 为升序。
6. **COUNTIF 的条件是文本表达式**：`">=90"` 要写成带引号的字符串；若要引用单元格，写作 `">="&D1`。

### 2.3 单元格引用（相对 / 绝对 / 混合）

| 类型 | 写法 | 复制到其他单元格时 | 使用场景 |
|---|---|---|---|
| 相对引用 | A1 | 行列**都变** | 普通公式下拉 |
| 绝对引用 | $A$1 | 行列**都不变** | 引用固定区域、固定系数 |
| 混合引用 | A$1 / $A1 | 行固定列变 / 列固定行变 | 九九乘法表、二维查表 |

**切换方法**：编辑公式时选中引用部分，按 **F4** 循环切换：A1 → $A$1 → A$1 → $A1 → A1。

**经典例（原创示例）**：B1 中写 `=A1*$C$1`，向下填充到 B2 得 `=A2*$C$1`（行号随行变，$C$1 不变）。如果把 B1 写成 `=A1*C1` 再向下填充，B2 会变成 `=A2*C2`，结果全错。**这就是"引用方式"决定成败的典型场景。**

### 2.4 排序与筛选

| 操作 | 路径 | 要点 |
|---|---|---|
| 简单排序 | 数据 · 排序（升序/降序） | 会连带整行一起移动 |
| 多关键字排序 | 数据 · 排序 · 添加条件 | 主关键字、次关键字，逐一设定升降序 |
| 自定义排序 | 排序 · 次序 · 自定义序列 | 可按"低/中/高""周一…周日"排 |
| 自动筛选 | 数据 · 筛选 | 每个列标题出现下拉箭头，可按值、按颜色、按条件筛 |
| 高级筛选 | 数据 · 高级 | 需先建立条件区域，可实现多条件"与/或"组合 |

> **易错提醒**：排序前应确认"数据包含标题"已勾选，否则表头会被当作数据一起参与排序。

### 2.5 图表类型的选择（考"选对图"）

| 图表 | 最适合表达 | 不适合 |
|---|---|---|
| 柱形图 | 不同项目之间的**数值大小比较** | 表现趋势 |
| 条形图 | 项目名称较长时的横向比较 | — |
| 折线图 | 数据随**时间变化的趋势** | 比较占比 |
| 饼图 | 各部分占**整体的比例** | 比较接近的数值、类别过多 |
| 散点图 | 两个变量之间的**相关关系** | 单一系列比较 |
| 面积图 | 随时间变化的**累积量** | 精确比较 |
| 雷达图 | 多维度综合能力的**对比** | 时间趋势 |

**三条判断口诀**：**比大小用柱形，看趋势用折线，看占比用饼图。**
**饼图的重要限制**：**只能有一个数据系列**，且一般不超过 6—8 个扇区。

## 四、网络与信息安全

### 4.1 IP 地址与域名

| 概念 | 说明 |
|---|---|
| IP 地址 | 网络中每台主机的唯一标识。IPv4 为 **32 位**，用点分十进制表示（如 192.168.1.1）；IPv6 为 **128 位**，采用十六进制冒号分隔 |
| 私有地址段 | 10.0.0.0—10.255.255.255、172.16.0.0—172.31.255.255、192.168.0.0—192.168.255.255 |
| 子网掩码 | 用于划分网络号与主机号，如 255.255.255.0 |
| 域名 | 便于记忆的地址，如 www.moe.gov.cn |
| DNS | 域名系统，负责把**域名解析为 IP 地址** |
| URL | 统一资源定位符，格式 `协议://主机名:端口/路径/文件名`，如 `https://www.moe.gov.cn/index.html` |

**域名结构（从右到左，级别由高到低）**：`www.moe.gov.cn` 中，`.cn` 是**顶级域名**（国家/地区），`gov` 是**类别域名**（政府机构），`moe` 是机构名，`www` 是主机名。
常见类别域名：`com`（商业）、`edu`（教育）、`gov`（政府）、`org`（非营利组织）、`net`（网络服务）。

**协议速记**：

| 协议 | 用途 |
|---|---|
| HTTP / HTTPS | 超文本传输（HTTPS 为加密版，网址前有小锁） |
| FTP | 文件传输 |
| SMTP / POP3 / IMAP | 发邮件 / 收邮件 |
| TCP / IP | 传输控制 / 网际协议，是互联网的基础协议 |
| DNS | 域名解析 |

### 4.2 浏览器与常用操作

- **常用浏览器**：Edge、Chrome、Firefox、Safari。
- **书签（收藏夹）**：Ctrl+D 添加到收藏夹。
- **清除缓存与历史记录**：设置 · 隐私/历史记录。
- **无痕/隐私模式**：不保存浏览记录，但**不等于匿名，也不能防病毒**。
- **下载文件的安全性**：警惕 `.exe`、`.bat`、`.scr` 等可执行文件；陌生来源的压缩包解压前先杀毒。
- **Cookie**：网站保存在本地的小文本，用于记住登录状态；定期清理可减少追踪。

### 4.3 计算机病毒与防护

**计算机病毒的本质**：一段**具有破坏性、能自我复制**的计算机程序/代码，不是生物病毒，也不是硬件故障。

**六大特征**：**寄生性、传染性、潜伏性、隐蔽性、破坏性、可触发性**。
（记忆：寄、传、潜、隐、破、触。）

**传播途径**：U 盘等移动存储、下载的软件与文件、邮件附件、网页挂马、局域网共享。

**防护措施（按重要性排序）**：

1. 安装并及时更新杀毒软件，定期全盘扫描。
2. 及时安装操作系统**安全补丁**（Windows Update）。
3. 不打开来源不明的邮件附件与链接，不下载破解软件。
4. 移动存储设备接入前先查毒。
5. 重要数据**定期备份**（离线 + 云端双备份）。
6. 开启防火墙；公共 Wi-Fi 下不进行网银等敏感操作。

### 4.4 个人信息与隐私保护

| 场景 | 正确做法 |
|---|---|
| 设置密码 | 强密码：长度≥8 位、大小写字母+数字+符号混合、定期更换、不同平台不重复 |
| 注册网站 | 非必要不填真实身份证号、家庭住址、手机号；阅读隐私条款 |
| 社交平台 | 不晒含门牌号、校名、车牌、定位的照片；关闭"允许陌生人查看" |
| 学生信息 | 教师不得在公开平台发布学生姓名+照片+成绩的组合信息；家长群不外传 |
| 公共电脑 | 用完退出账号、清除浏览记录 |
| 个人信息泄露后 | 立即改密、冻结相关账户、保留证据并向平台/监管部门投诉 |

> **教师视角的特别提醒**：《中华人民共和国个人信息保护法》将不满十四周岁未成年人的个人信息列为**敏感个人信息**，处理时需取得监护人同意。教师在班级群、公众号发布学生照片前，应征得家长同意。

| .pdf | 便携文档格式 | PDF 阅读器 / 浏览器 | **版式固定、跨设备显示一致**，不易被随意改动；适合最终稿与打印 |
| .txt | 纯文本 | 记事本 | 无格式，最通用 |
| .jpg / .jpeg | 位图图像 | 看图软件 | **有损压缩**，体积小，适合照片；反复保存会失真 |
| .png | 位图图像 | 看图软件 | **无损压缩**，**支持透明背景**，适合图标、截图 |
| .gif | 位图图像 | 看图软件 | 支持**动画**与透明，颜色最多 256 色 |
| .bmp | 位图图像 | 看图软件 | **不压缩**，体积大，画质无损 |
| .mp3 | 音频 | 播放器 | **有损**压缩，体积小，最通用的音乐格式 |
| .wav | 音频 | 播放器 | 无损，体积大，多用于录音原始素材 |
| .mp4 | 视频 | 播放器 | 通用性最好的视频容器格式，兼容性强 |
| .avi | 视频 | 播放器 | 较老的容器格式，体积大 |
| .zip / .rar / .7z | 压缩包 | 解压软件 | 多文件打包、减小体积；**rar、7z 压缩率通常高于 zip** |
| .exe | 可执行程序 | Windows | **来源不明切勿双击运行** |
| .html | 网页 | 浏览器 | 可用浏览器直接打开 |

### 5.2 压缩与解压

- **压缩的目的**：①减小体积，便于传输与存储；②把多个文件打包成一个，便于管理。
- **常见压缩格式**：zip（系统自带可解压）、rar（需 WinRAR 等）、7z（压缩率高）。
- **操作要点**：右键 → 压缩到……；解压时**优先"解压到当前文件夹"或指定目录**，不要直接双击打开压缩包内的文件运行。
- **安全提醒**：压缩包可以加密，也常被用来绕过邮件附件检测。**陌生压缩包解压后先杀毒再打开。**

### 5.3 格式选择建议（教学场景实用）

| 场景 | 推荐格式 | 理由 |
|---|---|---|
| 交论文/正式材料给上级或打印店 | **PDF** | 版式不会因对方电脑字体缺失而错乱 |
| 需要对方修改的文稿 | .docx | 可编辑 |
| 课件 | .pptx | 可编辑、可放映 |
| 成绩统计表 | .xlsx | 可计算、可排序筛选 |
| 网页用图/带透明背景的图标 | .png | 无损 + 透明 |
| 摄影照片 | .jpg | 体积小 |
| 微信传大文件 | .zip / .rar | 打包压缩 |

**1. 在 Word 中，要把文档中所有"教师"改为"老师"，最规范高效的做法是（ ）**
A. 逐个双击修改
B. 使用 Ctrl+H 的"查找和替换"
C. 使用格式刷
D. 全选后重新输入

**答案：B**。解析：批量替换必须用"查找和替换"（Ctrl+H）；格式刷只复制格式，不改文字。

**2. 在 Word 中，要使第 3 页开始的页面变为横向，正确做法是（ ）**
A. 在第 3 页前插入分页符
B. 在第 3 页前插入分节符（下一页），再单独设置该节纸张方向
C. 直接改整篇文档的纸张方向
D. 用回车把内容推到新页

**答案：B**。解析：纸张方向、页眉页脚等属于"节"级属性，必须用**分节符**把文档分成两节；分页符只能换页，不能改变排版规则。

**3. 在 Word 中，取消新一节页眉与上一节的关联，应（ ）**
A. 直接删除新一节的页眉文字
B. 在页眉页脚工具的"设计"选项卡中点击"链接到前一条页眉"使其取消选中
C. 插入分页符
D. 把字体改小

**答案：B**。解析：新节默认"链接到前一条"，不取消链接就直接改，第一节也会同步改变。

**4. 在 Word 中要自动生成目录，前提是（ ）**
A. 文档已插入页码
B. 正文标题已应用"标题 1/2/3"等内置样式
C. 文档已分节
D. 文档已保存为 PDF

**答案：B**。解析：目录依据"样式"提取标题层级，手动加粗放大的文字无法被识别为标题。

**5. 单元格 C5 中的公式 `=SUM(A1:A3,B4)` 的含义是（ ）**
A. 求 A1 到 A3 与 B4 的总和
B. 求 A1 到 A3 的平均值
C. 求 A1 到 B4 矩形区域的总和
D. 求 A1、A3、B4 三个单元格之和

**答案：A**。解析：逗号表示多个**不连续**区域，`A1:A3` 是连续区域（含 A1、A2、A3），`B4` 是单个单元格。

**6. 要统计某班 40 名学生中语文成绩达到 90 分及以上的人数，应使用（ ）**
A. `=SUM(B2:B41)`
B. `=COUNTIF(B2:B41,">=90")`
C. `=COUNT(B2:B41)`
D. `=AVERAGE(B2:B41)`

**答案：B**。解析：带条件的计数用 COUNTIF，条件是文本表达式，须加英文双引号。C 项 COUNT 只统计数值单元格个数，不加条件。

**7. 要用 VLOOKUP 根据学号精确查姓名，正确的写法是（ ）**
A. `=VLOOKUP(A2,B2:C40,2,1)`
B. `=VLOOKUP(A2,B2:C40,2,0)`
C. `=VLOOKUP(A2,C2:B40,2,0)`
D. `=VLOOKUP("A2",B2:C40,2,0)`

**答案：B**。解析：第 4 参数用 0（或 FALSE）表示精确匹配；C 项区域方向写反（区域须从查找列开始向右）；D 项给 A2 加了引号就变成查找文本"A2"而非单元格引用。

**8. 在 Excel 中，公式 `=RANK(C2,$C$2:$C$51,0)` 中 `$C$2:$C$51` 的作用是（ ）**
A. 使排名按降序排列
B. 使引用区域在向下填充公式时保持不变，保证都拿同一组数据排名
C. 统计 C2 到 C51 的个数
D. 对 C2 到 C51 求和

**答案：B**。解析：`$` 表示绝对引用。若写成 C2:C51（相对引用），向下填充时区域会跟着下移，排名结果全错。第 3 参数 0 才是"降序"。

## 七、高频易错点清单（考前 3 分钟看）

1. **分页符 ≠ 分节符**：换页用分页符，改排版规则（纸张方向、页眉）必须用分节符。
2. **页眉改之前先取消"链接到前一条"**。
3. **格式刷单击刷一次，双击可连续刷**。
4. **Excel 公式必须以 = 开头，文本参数用英文双引号**。
5. **VLOOKUP 第 4 参数要写 0（精确匹配），查找值必须在查找区域第一列**。
6. **RANK 第 3 参数 0 = 降序，非 0 = 升序**。
7. **绝对引用 $ 用 F4 切换**；排名、查表几乎都要用绝对引用。
8. **比大小用柱形，看趋势用折线，看占比用饼图**；饼图只有一个数据系列。
9. **切换管翻页，动画管对象**；F5 从头，Shift+F5 从当前。
10. **DNS 把域名解析成 IP**；域名从右到左级别由高到低。
11. **病毒是程序，六大特征是寄生、传染、潜伏、隐蔽、破坏、可触发**。
12. **PDF 保版式，PNG 可透明，JPG 有损，MP3 有损，ZIP/RAR 打包压缩**。
