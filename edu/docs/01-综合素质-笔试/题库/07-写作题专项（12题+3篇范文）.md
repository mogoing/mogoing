# 小学教师资格证《综合素质》写作题专项（12题 + 3篇范文 + 3篇病文诊断）

| 项目 | 内容 |
| --- | --- |
| 科目 | 《综合素质》（小学） |
| 模块 | 写作题（第 33 题，50 分，文体不限，不少于 800 字） |
| 题量 | 12 个作文题 + 3 篇完整范文 + 3 篇病文诊断 |
| 建议用时 | 审题立意 8 分钟 + 列提纲 7 分钟 + 写作 40 分钟 + 检查 5 分钟 = 60 分钟 |
| 重要度 | ★★★★★（写作 50 分，占总分三分之一，是拉开差距的关键） |

> 原创模拟题，非官方真题。所给材料、名言出处均按公开通行表述引用，题目为原创设计，不代表当次考试实际命题。

## 一、评分参考与得分要害

以下为常见的评卷参考区间（经验总结，非官方标准，仅供自测参考）：

| 等级 | 分数区间 | 主要特征 |
| --- | --- | --- |
| 一类文 | 41—50 分 | 紧扣题意，立意深刻有新意；结构严谨、层次分明；材料充实、分析到位；语言流畅、有文采；书写工整 |
| 二类文 | 31—40 分 | 符合题意，中心明确；结构完整；材料较充实；语言通顺 |
| 三类文 | 21—30 分 | 基本符合题意，中心不够明确；结构基本完整但松散；材料单薄；语病较多 |
| 四类文 | 0—20 分 | 偏离题意或另起炉灶；内容空洞；结构混乱；字数严重不足 |

**三条硬规则**：必须写标题（缺标题一般扣 2 分）；不少于 800 字（不足按每少 50 字扣 1 分累计）；文体不限但必须"像一篇议论文"，不能写成材料分析题或教学设计的答法。

**四个得分要害**：

1. **立意要"准"且"正"**。材料作文的第一步是把材料"翻译"成一句判断句，作为中心论点。立意偏离材料，语言再好也上不了 30 分。
2. **结构要"三三制"**。开头引出中心论点，中间三个分论点（每段"观点句 + 分析 + 例证 + 回扣"），结尾升华。这是最稳的结构。
3. **材料要"教育味"**。阅卷者期待看到教育视角：陶行知、苏霍姆林斯基、于漪、张桂梅、魏书生等教育人物，或课堂、家访、作业、评价等教育场景。通篇写"社会上"如何如何，会被判"脱离教育"。
4. **语言要"有句"**。每段至少一句概括性、有力量的话，可用引用、排比、比喻，让阅卷老师在快速浏览时"看得见亮点"。

## 二、通用写作模板（可直接套用）

**标题**：观点式（如《让期待成为孩子成长的灯》）或对举式（如《慢一点，才能快一些》）。

**开头（100—130 字）**：引材料 → 一句话点出材料指向 → 提出中心论点。"材料中……看似……，实则……。这提醒我们：……。"

**主体（三段，每段 180—220 字）**：
- 分论点句（首句，独立成句，用"首先/其次/再者"或"……，方能……"）
- 说理（2—3 句，讲清"为什么"）
- 例证（1 个具体事例，或一句名言 + 一处教育场景，60—90 字）
- 回扣（1 句，把小结论拉回中心论点）

**结尾（100—120 字）**：回扣中心论点 → 联系教师身份或教育现实 → 升华。"作为一名未来的小学教师，我愿……。因为……。"

**避坑清单**：不要通篇举例不分析；不要三个分论点意思重复；不要开头抄材料超过 80 字；不要在结尾突然提出新观点；不要写"我认为这个材料告诉我们"这类口语。

## 三、12 个作文题训练

### 题目 1　材料作文·期待与标签

**材料**

陶行知先生说："你的教鞭下有瓦特，你的冷眼里有牛顿，你的讥笑中有爱迪生。你别忙着把他们赶跑。你可不要等到坐火轮、点电灯、学微积分，才认识他们是你当年的小学生。"

**审题立意提示**

- **审题眼**：材料的核心不是"不要体罚"这么窄，而是"教师的态度会决定一个孩子被看见还是被埋没"。三个词是递进的：教鞭（行为）—冷眼（态度）—讥笑（评价），共同指向"否定性对待"。
- **推荐立意**：①教师应摘掉"标签"，用发展的眼光看待每一个学生；②教育要用期待代替否定，让潜能有机会显形；③真正的教育公正，是不提前给任何孩子下结论。
- **易偏题**：只写"教师要爱学生"（太泛，未扣"冷眼/讥笑"的否定性评价）；只写"瓦特、牛顿、爱迪生的故事"（变成人物介绍）；写"如何提高教学质量"（脱离材料）。

**三个可选论点**

1. 标签是教育的"隐形天花板"，教师的一句定论可能关掉孩子一生的门。
2. 期待不是空洞的表扬，而是具体的信任与台阶——让学生"够得着"成功。
3. 承认成长的滞后性，是教师最重要的职业耐心。

**可用素材**

- 名言：苏霍姆林斯基"让每一个学生都抬起头来走路"；罗森塔尔效应（教师期待会影响学生表现）；"教育是一棵树摇动另一棵树"（雅斯贝尔斯）。
- 事例：爱迪生被老师认定为"低能儿"、由母亲带回家教育；华罗庚初中数学曾不及格，后被熊庆来发现；张桂梅为大山女孩"撕掉"嫁人标签。
- 教育场景：教师把"你怎么又错了"换成"这一步你是怎么想的"。

**提纲**

标题：《别用一句定论，关掉一扇门》
开头：引陶行知话 → "冷眼与讥笑，本质是提前结案" → 中心论点：教师应放弃终审式的评价，用期待为成长留出可能。
分论点一：标签之所以可怕，在于它会变成学生的自我认知。（分析 + 罗森塔尔效应 + 一个课堂场景）
分论点二：期待要落地为具体台阶，而不是廉价表扬。（分析 + 分层任务/一句追问的事例）
分论点三：承认成长的滞后性，教师才等得起。（分析 + 爱迪生、华罗庚事例）
结尾：以"今天坐在教室里的瓦特"作结，落到教师身份与责任。

### 题目 2　名言作文·点燃与灌输

**材料**

诗人叶芝说："教育不是注满一桶水，而是点燃一把火。"

**审题立意提示**

- **审题眼**：材料是一组对立比喻——"注满一桶水"（灌输、被动、以量为标准）与"点燃一把火"（唤醒、主动、以兴趣和内在动机为标志）。写作重点是论证"为什么要点燃"以及"怎样点燃"。
- **推荐立意**：①教育的价值在于唤醒内在动机，而非堆积知识；②兴趣是最好的老师，教师要做"点火者"；③从"教会知识"到"教会学习"，是教学观的转变。
- **易偏题**：只写"要激发兴趣"三句就结束（无分析、无方法）；写成"减负"专论（沾边但重心跑偏）；通篇批判应试（情绪化，不解决问题）。

**三个可选论点**

1. 灌输能带来短期分数，却会熄灭长期的学习愿望。
2. 点燃的关键，是让学生看见知识与自己生活的连接。
3. 火要持续燃烧，需要教师提供"柴"——方法、支持与正向反馈。

**可用素材**

- 名言：孔子"不愤不启，不悱不发"；苏格拉底"教育不是灌输，而是点燃火焰"（常与叶芝此语并引，注意区分）；第斯多惠"教学的艺术不在于传授本领，而在于激励、唤醒和鼓舞"。
- 事例：法布尔观察昆虫写出《昆虫记》；教师带学生用测量法计算操场面积，学生从此爱上数学。
- 教育场景：把"背下这个公式"换成"你能不能用它算算你家水费"。

**提纲**

标题：《做那个点火的人》
开头：引叶芝名言 → 指出"桶"与"火"的分野是"被动接受"与"主动生长" → 中心论点：教育的首要任务是点燃。
分论点一：灌输以"量"为尺度，点燃以"愿"为标志。（分析 + 短期分数与长期兴趣的对比）
分论点二：点燃需要把知识接回生活。（分析 + 操场测量/水费计算事例）
分论点三：点燃之后还要添柴，兴趣才能变成能力。（分析 + 方法指导、及时反馈）
结尾：回到小学课堂，写"我愿做那个蹲下来点火的人"。

### 题目 3　现象作文·放手与包办

**材料**

某小学门口，放学时常见这样的场景：爷爷奶奶接过书包背在自己肩上，孩子空手走在旁边；有的家长怕孩子忘带作业，每天在群里问三遍；有孩子到五年级还不会系鞋带、不会剥鸡蛋。一位班主任在家长会上说："我们能替孩子背六年书包，替不了他走六十年路。"

**审题立意提示**

- **审题眼**：材料的核心矛盾是"爱"与"害"的辩证——过度的代劳看似关爱，实则剥夺了孩子练习独立的机会。班主任那句话是文眼："六年"对"六十年"。
- **推荐立意**：①真正的爱是得体地退出，让孩子在承担中长大；②教育要培养自理能力与责任意识，而不是"高分低能"；③家庭与学校都应把"做事的机会"还给孩子。
- **易偏题**：只写"家长不容易"（立场倒了）；只写"要孝顺"（方向错）；大谈"现在的孩子太娇气"（只有情绪没有论证）。

**三个可选论点**

1. 包办是最温柔的剥夺——它拿走的是孩子练习"我能行"的机会。
2. 独立不是天生的，是在一次次具体的小事中练出来的。
3. 放手不是撒手，而是"退半步、扶一把"的智慧。

**可用素材**

- 名言：卢梭"你知道用什么方法一定可以使你的孩子成为不幸的人吗？这个方法就是对他百依百顺"；陶行知"生活即教育""六大解放"（解放双手、头脑、眼睛、嘴、空间、时间）。
- 事例：日本幼儿园让孩子自己背书包、自己整理物品；芬兰学校开设"生活课"教烹饪、缝纫；国内某小学设"自理小达人"闯关活动。
- 教育场景：班级设"值日班长轮岗""自己的书包自己整"。

**提纲**

标题：《替不了的六十年》
开头：描绘校门口背书包的场景 → 引出"爱的方式"之问 → 中心论点：真正的爱是放手，让孩子在承担中成长。
分论点一：包办剥夺的是"我能行"的体验，损伤的是自我效能感。（分析 + 心理学"习得性无助"）
分论点二：能力只能在具体的事里长出来。（分析 + 生活课、值日轮岗事例）
分论点三：放手需要分寸，是"退半步"而不是"撒手不管"。（分析 + 家长与教师如何搭台阶）
结尾：回扣"六年"与"六十年"，落到教师应培养什么样的人。

### 题目 4　材料作文·多元评价

**材料**

某小学期末评选"优秀学生"，成绩平平的小轩落选了。班主任却在一次家访中发现，小轩把家里的阳台变成了"小花园"，20 多盆花草被照顾得极好，他还给每盆花做了"生长记录卡"。班主任把这些记录卡带到班上展示，并增设了"小小园艺师"奖。小轩第一次站在讲台上领奖，脸红到耳根。后来，他在作文里写道："原来我也有一样东西，是别人比不上的。"

**审题立意提示**

- **审题眼**：材料的关键转折是"评价标准的改变"——从单一分数到多元赏识。小轩那句"原来我也有一样东西，是别人比不上的"是文眼，指向"被看见"的需求。
- **推荐立意**：①多一把尺子，就多一批好学生；②教育的使命是帮每个孩子找到自己的"第一"；③评价应发现优势，而不只是筛选优劣。
- **易偏题**：只写"要表扬学生"（层次太浅）；写"如何提高成绩"（与材料相反）；把重点放在"家访很重要"（只是情节，不是主题）。

**三个可选论点**

1. 单一评价标准会让多数孩子成为"失败者"。
2. 发现优势，是唤醒自信最有效的入口。
3. 多元评价不是降低标准，而是承认"好"有多种形态。

**可用素材**

- 名言：加德纳多元智能理论；"多一把衡量的尺子，就会多出一批好学生"（教育界通行说法）；陶行知"人像树木一样，要使他们尽量长上去，不能勉强都长得一样高"。
- 事例：某校设"进步之星""助人之星""劳动之星"；爱因斯坦、达尔文童年被老师认为"平庸"；张桂梅办学从"比分数"转向"比进步"。
- 教育场景：期末评语写"你照顾花草的耐心，老师都看在眼里"。

**提纲**

标题：《多一把尺子，多一批好学生》
开头：引材料结尾那句"原来我也有一样东西" → 指出这句话背后的渴望 → 中心论点：评价应发现优势。
分论点一：单一尺子会把差异判为缺陷。（分析 + 多元智能 + 分数排名的副作用）
分论点二：被看见的优势，是自信生长的支点。（分析 + 小轩事例 + 迁移效应）
分论点三：多元评价要有具体载体，不能停在口头。（分析 + 奖项设置、成长档案、评语改革）
结尾：以"教育的使命是让每个孩子找到自己的第一"作结。

### 题目 5　观点作文·教育是慢的艺术

**材料**

一位教师在随笔中写道："我教了三十年书，越来越觉得教育是慢的。一个字写不好，可能要练一学期；一个道理讲不通，可能要等一次他自己摔跤。可我们总在赶：赶进度、赶考试、赶着把孩子送进下一个年级。有时候我想，是不是我们跑得太快，把孩子弄丢了。"

**审题立意提示**

- **审题眼**：材料反复出现"慢"与"赶"的对立，落点在"把孩子弄丢了"——快，丢的是对个体的关注和成长规律。注意"慢"不等于"拖延""放任"，而是"尊重节奏"。
- **推荐立意**：①教育要尊重成长规律，允许反复与等待；②"慢"是一种专业耐心，也是一种教育智慧；③在效率时代，教师要为孩子的成长"留白"。
- **易偏题**：把"慢"写成"不要留作业"（极端化）；通篇批判"内卷"（只剩情绪）；写成"我的一次拖延经历"（跑题）。

**三个可选论点**

1. 成长有节气，催熟的果子不甜。
2. "慢"的背后是专业判断——知道何时推、何时等。
3. 为成长留白，才容得下兴趣、发呆与自我修复。

**可用素材**

- 名言：卢梭"大自然希望儿童在成人以前就要像儿童的样子"；张文质《教育是慢的艺术》；"教育是农业，不是工业"。
- 事例：苏霍姆林斯基给"难教儿童"做长期观察记录；一位教师用一学期陪学生改正握笔姿势；某校设"无作业日"让学生自由阅读。
- 教育场景：作文讲评不急于给分数，先让学生改三遍。

**提纲**

标题：《慢一点，才能快一些》
开头：引教师随笔 → 点出"赶"的代价 → 中心论点：教育应尊重节奏，慢是另一种快。
分论点一：成长有节气，催熟必然失真。（分析 + 卢梭 + 提前学习的危害）
分论点二：慢是专业判断，不是无所作为。（分析 + 何时推、何时等的分寸）
分论点三：留白让兴趣与自我修复有处安放。（分析 + 无作业日、自由阅读）
结尾：回扣教师身份——"我愿做一个等得起的人"。

### 题目 6　现象作文·把课间还给孩子

**材料**

有媒体调查发现，部分小学的课间十分钟"静悄悄"：学生除了上厕所不出教室，走廊里贴着"禁止追逐"的提示，有的教师拖堂到下一节上课。学校的理由是"怕出安全事故"。一位校长说："把孩子圈在教室里最安全，可也把童年圈没了。"后来该校试行"课间微运动"：走廊设跳格子、教室外放跳绳筐、每层安排值周教师巡查。

**审题立意提示**

- **审题眼**：材料呈现"安全"与"成长"的张力。"怕出事"是表面原因，"圈养"是管理逻辑，而校长的"把童年圈没了"是文眼，指向"教育不能以安全之名牺牲发展"。
- **推荐立意**：①教育管理不能因噎废食，要在安全与成长之间找到平衡；②课间十分钟是儿童社会化与身体发展的必要空间；③好的管理靠制度设计，而不是"一禁了之"。
- **易偏题**：只写"安全事故多可怕"（与材料立场相反）；写"学生要遵守纪律"（重心反了）；泛谈"减负"（未扣住"课间"）。

**三个可选论点**

1. "一禁了之"是最省事的管理，也是最昂贵的教育。
2. 课间是儿童练习交往、规则与身体的天然课堂。
3. 安全与成长可以兼得，前提是管理精细化而非简单化。

**可用素材**

- 名言：《关于全面加强和改进新时代学校体育工作的意见》强调"保障学生每天校内外各一小时体育锻炼"；"文明其精神，野蛮其体魄"。
- 事例：某校"课间微运动"；日本学校重视课间外玩；芬兰学校每 45 分钟必有 15 分钟户外休息。
- 教育场景：走廊画跳格子、班级设"器材筐"、值周教师分楼层巡查。

**提纲**

标题：《别把课间锁进教室》
开头：写"静悄悄的课间"这一反差场景 → 引出管理逻辑之问 → 中心论点：安全不能成为取消成长的理由。
分论点一：因噎废食的管理，省了麻烦却亏了孩子。（分析 + 童年只有一次）
分论点二：课间是身体、交往与规则意识的练习场。（分析 + 具体发展价值）
分论点三：精细化管理能兼顾安全与成长。（分析 + 微运动、值周巡查、器材配置）
结尾：升华到"好的教育管理，是把风险想在前面，而不是把孩子关在后面"。

### 题目 7　名言作文·学高为师，身正为范

**材料**

"学高为师，身正为范。"这八个字被无数师范院校刻在墙上。一位从教四十年的老教师说："前半句让人站上讲台，后半句让人留在学生心里。学生记不住我讲过的题，但记得我捡起地上纸屑的样子。"

**审题立意提示**

- **审题眼**：材料把"学高"与"身正"并置，并用老教师的话点明"身正"的持久影响。核心是"教师人格的示范作用"，而非单纯"要提高业务水平"。
- **推荐立意**：①师德是教师的第一素养，示范是最有力的教育；②教师既要精于业务，更要严于律己；③教育的说服力来自"言行一致"。
- **易偏题**：只写"要好好学习、提升学历"（丢了"身正"）；写"教师待遇低"（跑题）；堆砌师德口号而无事例（空洞）。

**三个可选论点**

1. 学生是"看"会的，不是"听"会的——示范比说教更有力。
2. 学高是底气，身正是底线，二者缺一不可。
3. 师德藏在细节里：一句话、一个动作、一次守时。

**可用素材**

- 名言：孔子"其身正，不令而行；其身不正，虽令不从"；陶行知"先生不应该专教书，他的责任是教人做人"；《中小学教师职业道德规范》"为人师表"。
- 事例：张桂梅每天陪学生晨读、把工资用在学生身上；于漪"一辈子做教师，一辈子学做教师"；教师随手捡纸屑、关灯、向前来送作业的学生道谢。
- 教育场景：教师答应学生"明天讲那本书"，第二天真的讲。

**提纲**

标题：《留在学生心里的，不只是那道题》
开头：引老教师的话 → 指出"记住"与"记住什么"的差别 → 中心论点：身正是教育最持久的力量。
分论点一：学生的眼睛，是教师最严格的考官。（分析 + 模仿心理 + 细节事例）
分论点二：学高提供底气，身正建立信任。（分析 + 二者关系）
分论点三：师德要在制度与日常中养成。（分析 + 守时、承诺、公正、廉洁）
结尾：以"师范"二字作结，落到"我愿成为学生记得住的那个样子"。

### 题目 8　现象作文·AI 时代的教育

**材料**

某小学语文课上，学生用 AI 工具三分钟生成了一篇"我的妈妈"，词句工整，却把妈妈写成了"温柔的天使"。教师问："你妈妈真的从不发火吗？"学生愣住。教师随即布置新任务：不用 AI，写一件"妈妈让你有点烦的小事"。交上来的作文里，有妈妈催作业的唠叨、有把剩菜热三遍的固执，读来令人动容。

**审题立意提示**

- **审题眼**：材料对比"工整但失真"与"粗糙但真实"，指向 AI 时代教育的核心命题——什么不可被替代。"真的从不发火吗"是关键一问，指向真实经验与独立思考。
- **推荐立意**：①技术可以代劳表达，却不能代劳体验与思考；②教育的不可替代性在于唤醒真实感受与独立判断；③教师应教学生"用好工具"，更要教他"做自己"。
- **易偏题**：一味批判 AI、呼吁禁用（极端且不可行）；只写"科技改变生活"（无教育立场）；写成"如何提高作文水平"（窄化）。

**三个可选论点**

1. AI 能生成文字，生成不了"妈妈热三遍剩菜"这样的真实。
2. 越是被技术包围，越要守护学生独立判断与真实体验。
3. 教师的角色不是与 AI 竞争记忆，而是培养 AI 给不了的东西：共情、审美、价值判断。

**可用素材**

- 名言：雅斯贝尔斯"教育的本质是一棵树摇动另一棵树"；"技术解决效率问题，教育解决意义问题"（可自拟概括）。
- 事例：学生用 AI 写读后感被教师引导重写"自己真实的困惑"；芬兰重视现象式学习与真实情境；某校开设"媒介素养课"教学生辨别 AI 生成内容。
- 教育场景：作文课设"只有你能写"的题目——写你家窗外的声音。

**提纲**

标题：《AI 写不出你妈妈的那声唠叨》
开头：引材料"温柔的天使"与"热三遍的剩菜"的对比 → 中心论点：技术可代劳表达，不能代劳体验。
分论点一：真实经验是写作与思考的根。（分析 + 材料事例）
分论点二：独立判断是 AI 时代最稀缺的能力。（分析 + 信息茧房、辨别真伪）
分论点三：教师的不可替代性在于育人而非传输。（分析 + 共情、审美、价值观）
结尾：提出"善用工具、守住自己"，落到教师使命。

### 题目 9　材料作文·错误是资源

**材料**

两个教师处理同一件事。学生小凯在黑板上做题，算错了。甲教师说："这么简单都错，站到后面去。"乙教师说："大家看看，他这一步是怎么想的？"小凯小声说："我把 7 看成 1 了。"乙教师说："这个错误很有价值，它提醒我们看题要看清数字。"此后，班里学生开始主动把"自己错在哪"讲给同学听。

**审题立意提示**

- **审题眼**：材料是典型的"对照式"结构，两位教师代表两种错误观：错误是"耻辱"还是"资源"。乙教师那句"这个错误很有价值"是文眼。
- **推荐立意**：①教师应把错误当作教学资源，而不是惩罚理由；②容错的环境才能培养敢想敢说的学生；③对待错误的态度，决定课堂的思维深度。
- **易偏题**：只写"教师不要体罚"（窄化）；只写"要鼓励学生"（浅层）；写"如何提高计算正确率"（跑偏）。

**三个可选论点**

1. 错误暴露的是思维的路径，是最真实的教学起点。
2. 惩罚错误，会让学生学会隐藏；善待错误，才让学生敢于暴露。
3. 把错误变成资源，需要教师有分析与追问的能力。

**可用素材**

- 名言：布鲁纳"学生的错误是有价值的"；"错误是正确的先导"；斯金纳/建构主义关于"错误是学习的一部分"。
- 事例：数学特级教师把"错题"做成"错例分析课"；某班设"错题博物馆"，学生自愿展出自认为"最有价值的错"；爱迪生寻找灯丝材料"我没有失败，我只是找到了一万种不可行的方法"。
- 教育场景：把"谁错了"换成"这个思路走到哪里卡住了"。

**提纲**

标题：《让错误站到讲台上来》
开头：对比两位教师的处理 → 指出同一错误两种命运 → 中心论点：错误是资源，不是耻辱。
分论点一：错误暴露思维路径，是教学的真正起点。（分析 + 材料中小凯"把 7 看成 1"）
分论点二：惩罚错误会训练出"隐藏"，宽容错误才培养"表达"。（分析 + 心理安全感）
分论点三：把错误变资源，需要追问与分析的专业能力。（分析 + 错例分析课、错题博物馆）
结尾：以"善待错误的课堂，才配得上'思维'二字"作结。

### 题目 10　材料作文·阅读的力量

**材料**

某小学五年级的一个班，学生几乎不读课外书。新来的语文教师没有讲大道理，只是每天早读前读 10 分钟书给学生听。她读《城南旧事》，读到英子与"疯子"秀贞告别时，教室很安静；她读《草房子》，读到桑桑生病，有学生偷偷抹眼泪。三个月后，班里出现了第一本被传阅到卷边的《窗边的小豆豆》。一年后，全班人均课外阅读量从 2 本增加到 26 本。

**审题立意提示**

- **审题眼**：材料的关键不是"阅读很重要"，而是"教师怎样让学生爱上阅读"——先"读给他们听"，用故事本身的力量，而不是用要求和检查。数据变化（2 本→26 本）是结果，过程才是立意所在。
- **推荐立意**：①教育是示范与感染，不是要求与考核；②把好东西"递到"学生面前，比命令他去拿更有效；③阅读是慢功夫，需要教师先成为读者。
- **易偏题**：只写"要多读书"（空泛）；写"如何提高阅读题得分"（功利化）；忽略教师"读给学生听"这一关键动作。

**三个可选论点**

1. 让学生爱上阅读的，从来不是书单，而是有人先读给他听。
2. 教师的示范，是最低成本、最高效率的教育。
3. 阅读的回报是慢的，教师要有"等一本书被传阅"的耐心。

**可用素材**

- 名言：苏霍姆林斯基"让学生变聪明的方法，不是补课，而是阅读、阅读、再阅读"；吉姆·崔利斯《朗读手册》"你或许拥有无限的财富，但你永远不会比我富有——我有一位读书给我听的妈妈"。
- 事例：某教师坚持"每天十分钟朗读"；"亲子共读"项目；于永正"把书读给学生听"。
- 教育场景：早读前的十分钟、班级"漂流书袋"、教师办公桌上放着一本正在读的书。

**提纲**

标题：《先读给他听》
开头：引材料中的两次"安静"与"抹眼泪" → 指出这是故事在起作用 → 中心论点：教育的入口是感染，不是要求。
分论点一：示范比要求更有力量。（分析 + 教师读书的姿态）
分论点二：故事本身就有唤醒人的力量。（分析 + 情感共鸣与价值传递）
分论点三：慢功夫需要耐心与持续。（分析 + 2 本到 26 本的一年）
结尾：写"我愿做那个每天读十分钟书的人"。

### 题目 11　名言作文·立德树人

**材料**

有人说，教育的本质是"使人成为人"。也有人说，小学六年，学生学过的公式终会忘记，但被教会如何待人、如何面对失败、如何对待弱者，会跟着他一辈子。

**审题立意提示**

- **审题眼**：两句材料同向叠加，落点是"教育的第一任务是成人，而非成才"。"如何待人、如何面对失败、如何对待弱者"给出了三个具体维度，可作为分论点的切入口。
- **推荐立意**：①立德树人是教育的根本任务；②比成绩更重要的是健全人格；③小学阶段的教育，应把"做人"放在"做题"之前。
- **易偏题**：写成"德育工作如何开展"的工作总结（文体不符）；只谈"成绩不重要"（绝对化）；堆砌道德口号（无实例）。

**三个可选论点**

1. 分数决定一时的去向，人格决定一生的走向。
2. "如何面对失败"，是小学最该补上的一课。
3. 善待弱者的能力，是衡量一个孩子教养的真实标尺。

**可用素材**

- 名言：《中小学德育工作指南》"育人为本、德育为先"；赫尔巴特"教学永远具有教育性"；陶行知"千教万教教人求真，千学万学学做真人"。
- 事例：某校设"失败课"，请学生讲一次"我搞砸了"；班级设"同伴互助岗"照顾行动不便的同学；张桂梅以"红色教育"立人。
- 教育场景：运动会最后一名跑完，全班鼓掌；把"你怎么这么笨"换成"我们再试一次"。

**提纲**

标题：《先成人，再成才》
开头：引"使人成为人" → 指出教育的顺序问题 → 中心论点：立德是教育的根本。
分论点一：分数是一时的，人格是一世的。（分析 + 遗忘曲线与人格的持久）
分论点二：教孩子面对失败，比教他避免失败更重要。（分析 + 抗挫力 + 失败课）
分论点三：如何对待弱者，检验教养的真伪。（分析 + 同伴互助 + 班级氛围）
结尾：以"小学六年，播下的是人的种子"升华。

### 题目 12　现象作文·劳动与生活

**材料**

某小学调查显示：86% 的学生在家从不洗碗，过半学生不会整理书包；但同一批学生在"校园美食节"上包饺子、做水果拼盘时兴致极高，有学生说："原来我做的饭这么好吃。"一位教师感慨："不是孩子不爱劳动，是我们很少给他真正动手的机会。"

**审题立意提示**

- **审题眼**：材料包含一个反差与一个判断——反差是"日常不做"与"活动中爱做"，判断是教师那句"不是不爱，是没机会"。立意应落在"提供真实劳动机会"，而非"批判孩子懒惰"。
- **推荐立意**：①劳动教育的钥匙是"真实的任务"，不是"说教与打卡"；②在动手中，学生获得能力感与价值感；③把劳动还给学生，是培养责任与自信的起点。
- **易偏题**：写"劳动最光荣"的空洞论述；写"家长太溺爱"（只批评不建设）；把重点放在"美食节很好玩"（浅化）。

**三个可选论点**

1. 劳动不是负担，是孩子确认"我能行"的方式。
2. 劳动教育要真实：真任务、真成果、真评价。
3. 劳动连接生活与责任，是完整教育的必修课。

**可用素材**

- 名言：陶行知"生活即教育""在劳力上劳心"；苏霍姆林斯基"劳动的欢乐是人的尊严的源泉"；《大中小学劳动教育指导纲要（试行）》要求"出力流汗"。
- 事例：某校"校园农场"由学生承包；芬兰"生活课"教烹饪缝纫；日本小学"给食当番"轮流分餐。
- 教育场景：班级"岗位制"——图书管理员、绿植养护员、电器管理员，人人有岗、周周轮换。

**提纲**

标题：《给他一次真正动手的机会》
开头：引调查数据与美食节的反差 → 引出教师那句感慨 → 中心论点：劳动教育的关键是提供真实机会。
分论点一：劳动带来能力感，"我能行"是自信的源头。（分析 + 心理学自我效能）
分论点二：真实任务才有真教育，形式打卡只会消耗兴趣。（分析 + 迎检式劳动的反例）
分论点三：劳动连接责任与生活，是完整教育的一环。（分析 + 岗位制、校园农场）
结尾：回扣"不是不爱，是没机会"，落到教师可做的三件小事。

## 四、3 篇完整范文

> 说明：以下范文为原创示例，用于展示"三三制"结构与论证方式，**不要整篇背诵套用**。请学习其段落功能与句式，把素材换成一你自己熟悉的例子。

### 范文一（对应题目 1）

# 别用一句定论，关掉一扇门

"你的教鞭下有瓦特，你的冷眼里有牛顿，你的讥笑中有爱迪生。"陶行知先生这句话，我读了很多遍，越读越觉得后怕——因为"教鞭""冷眼""讥笑"这三样东西，都不需要多大的恶意，往往只是一个成年人疲惫时的随口一句。可对一个正在长大的孩子来说，那可能就是一句终审判决。教育最需要警惕的，不是教师水平不够，而是教师太早给学生"结案"。

标签之所以可怕，是因为它会慢慢长成孩子对自己的认知。心理学上有个著名的"罗森塔尔效应"：研究者随机圈出一些学生，告诉教师"这些孩子很有潜力"，一学期后，这些学生的成绩真的明显提高。反过来也成立——当教师反复说"你就是不行"，孩子接收到的不是批评，而是一个身份。他会想：既然老师都这么说了，那我大概真的不行。于是不举手了，不交作业了，不再尝试了。真正被关掉的不是某一扇知识的大门，而是他心里那盏"我可以试试"的灯。

期待也不能停留在嘴上，它必须落成孩子够得着的台阶。我见过一位数学老师，班上有个男孩总考四十几分。她没有说"老师相信你一定能考好"，那太轻了；她在他的卷子上写："第三题你的思路很特别，明天愿意讲给全班听吗？"男孩紧张地讲完，中间还错了一步，她带头鼓掌。后来这个男孩每周多领一道"挑战题"，题目只比他现在的水平高一点点。一年后他考了七十八分。期待之所以有力量，不是因为这句话好听，而是因为它背后有具体的动作：一次展示的机会，一道刚够得着的题，一个允许出错的课堂。

更难的，是承认成长有滞后性。爱迪生被老师认定"低能"，是母亲把他领回家；华罗庚初中数学曾经不及格，是熊庆来发现了他。这些故事被讲了很多遍，可我们常常只记住"他们后来很成功"，忘了"他们当时被放弃过"。成长不是一条匀速上升的直线，它更像种子在土里：地表看不出动静的那段时间，根正在往下扎。教师要做的，不是每天把种子挖出来看看长了没有，而是浇水、松土，然后等。

作为一名未来的小学教师，我知道自己也会有疲惫的时候，也会有脱口而出"你怎么又错了"的瞬间。但我会提醒自己：我面对的不是一份试卷，而是一个人尚未展开的一生。别急着下结论，别用一句定论关掉一扇门——因为门后面站着谁，我们现在还不知道。

### 范文二（对应题目 2）

# 做那个点火的人

叶芝说："教育不是注满一桶水，而是点燃一把火。"桶与火的区别，不在于装了多少，而在于——桶里的水是被倒进去的，火是自己在烧。一个孩子被灌满了知识，可能依然厌恶学习；一个孩子被点燃了兴趣，却会自己去找柴。教育的成败，往往就分在这一个字上。

灌输能换来短期分数，代价却是长期的学习意愿。我们太熟悉这样的场景：一篇课文抄三遍，一个公式背十遍，一道题型刷五十道。分数确实会涨，可孩子看语文书的眼神也一点点暗下去。他不再问"为什么"，只问"考不考"；不再读整本书，只读"考点"。等到没有人给他布置任务的那一天，他就再也不会翻开一本书了。这不是教育，这是提前透支。桶总有一天会空，而一个不再想喝水的人，给他多大的桶都没有用。

点燃的关键，是让知识回到孩子的生活里。我听过一节很普通的数学课。教师没有先讲面积公式，而是问："我们教室的地面要铺地砖，得买多少块？"孩子们愣住了，然后开始量、开始算、开始争论边角怎么办。那节课下课，有学生追着老师问："那我家阳台呢？"——这就是火苗。知识一旦和"我的生活"接上，它就不再是需要背下来的负担，而成了解决问题的工具。教师要做的，往往只是把"背下这个公式"换成"你能不能用它算算你家的水费"。

当然，点燃之后还要添柴。兴趣是最初的火星，但火星撑不过一个冬天。真正让一个孩子把兴趣变成能力的，是方法、是反馈、是被看见的进步。书法家启功先生练字，是日复一日地临帖；一个孩子爱上写作，通常是因为他有一篇作文被老师当众读过。所以，点火不是教师的一次精彩表演，而是一段持续的陪伴：教他方法，指出他的进步，允许他慢，允许他反复。火要烧得久，柴要添得勤。反过来看，许多"三分钟热度"的悲剧，并不是孩子没有兴趣，而是兴趣刚冒头时没有人接住——他自己找了柴，火却灭了。

也正因如此，点燃这件事不能只靠一节课的精彩。它需要教师了解每个孩子的"引火点"在哪里：有的孩子被一句肯定点燃，有的孩子被一次成功点燃，有的孩子要等到自己亲手做出一样东西才肯相信"我可以"。这要求教师有耐心，也有辨别力。

作为一名未来的小学教师，我不指望自己能点亮一整片夜空。我只希望，在某个孩子快要熄灭的时候，我能蹲下来，替他挡一挡风，然后递上一根火柴。教育不是把桶灌满，而是让火自己烧起来——这大概就是"教师"这两个字最动人的地方。

**【范文点评·得分点拆解】**

| 得分维度 | 本文做法 | 具体位置 |
| --- | --- | --- |
| 立意 | 抓住材料的对立结构，用"桶里的水是被倒进去的，火是自己在烧"完成概念辨析，中心论点清晰 | 首段 |
| 结构 | "为什么不能灌输 → 怎样点燃 → 点燃之后怎么办"，三段呈递进而非并列，避免了"三个角度重复"的常见毛病 | 第 2、3、4 段 |
| 内容 | 有反面场景（抄三遍、背十遍、刷五十道）、有正面课例（铺地砖算面积）、有启功临帖，正反互补 | 第 2、3、4 段 |
| 分析 | 每段结尾都有一句机制性总结："桶总有一天会空""知识一旦和'我的生活'接上""火星撑不过一个冬天" | 各段末句 |
| 语言 | 全文围绕"火"的意象展开（火苗、火星、添柴、挡风、火柴），意象统一，是提分点 | 通篇 |
| 教师立场 | 末段自陈"未来的小学教师"身份，落点具体、不空喊 | 末段 |

**自评提示**：本文约 900 字。注意"添柴"一段容易被写成"要鼓励学生"的空话，本文靠"方法 + 反馈 + 被看见的进步"三个具体动作避免了这一点。

### 范文三（对应题目 5）

# 慢一点，才能快一些

一位教了三十年书的老教师在随笔里写："教育是慢的。可我们总在赶：赶进度、赶考试、赶着把孩子送进下一个年级。有时候我想，是不是我们跑得太快，把孩子弄丢了。"这段话让我沉默了很久。我们习惯了用"效率"衡量一切，却忘了成长本身是有效率之外的另一套时间。教育真正的智慧，也许恰恰在于敢慢。

慢，是因为成长有它自己的节气。卢梭说过，大自然希望儿童在成人以前就要像儿童的样子。可我们常常等不及：幼儿园学小学的拼音，小学学初中的语法，一年级要求写三百字，二年级要求读整本书。看上去抢跑了，实际上是"催熟"。被催熟的果子往往少了那一点甜——提前学过的孩子，一二年级很轻松，三年级开始走神，因为他早就"学过了"，也就再没学会"怎么学"。教育的规律不因我们的焦虑而改变，你催得越急，欠下的账越多。

慢，更是一种专业判断，而不是无所作为。真正的"慢"从来不是放任：它是知道什么时候该推一把，什么时候该退一步。一个孩子握笔姿势错了，你可能要陪他改一个学期；一个孩子作文写不长，你不能替他写，只能一次一次问他"然后呢"。这中间有反复、有停滞、甚至有倒退。教师要做的，是持续地照料，同时不催结果——像农人松土、施肥、引水，然后等。这种分寸感最难教，也最见功力：它要求教师既懂学科，又懂眼前这个具体的人。

慢，还是为成长留出空白。我们把孩子的时间填得太满了：早读、正课、课后服务、作业、辅导班，一格一格排得像张密不透风的网。可兴趣需要发呆，思考需要闲暇，自我修复更需要一段没人打扰的时间。有学校设"无作业日"，让孩子自由阅读；有教师每周留一节课"随便读"。这些"空"看起来是浪费，其实是给种子留出发芽的缝隙。一个从未闲过的孩子，很难长出属于自己的东西。

作为一名未来的小学教师，我知道自己会被进度表追着跑，会被家长问"为什么别人家孩子已经会了"。但我想记住那句话：不要跑得太快，把孩子弄丢了。慢一点，不是落后，而是让根扎得深一些——根扎得深，日后才长得快。

**【范文点评·得分点拆解】**

| 得分维度 | 本文做法 | 具体位置 |
| --- | --- | --- |
| 立意 | 抓住"慢"与"赶"的对立，并主动排除"慢 = 放任"的误解，立意有辨析、有深度 | 第 3 段"真正的'慢'从来不是放任" |
| 结构 | "成长有节气 → 慢是专业判断 → 慢是留白"，由"为什么"到"是什么"再到"怎么做"，层次递进 | 三段首句 |
| 内容 | 卢梭名言、催熟的反例、"握笔姿势改一学期"、"无作业日"，材料密度适中，不堆砌 | 第 2、3、4 段 |
| 分析 | 用"农人松土、施肥、引水"的类比把抽象道理讲具体；指出"提前学过的孩子三年级走神"的具体后果 | 第 2、3 段 |
| 语言 | 标题即观点，形成"慢—快"的张力；"密不透风的网""留出发芽的缝隙"等比喻形象 | 标题、第 4 段 |
| 教师立场 | 末段直面真实压力（进度表、家长追问），使文章不悬浮 | 末段 |

**自评提示**：本文约 930 字。"慢"类题目最大的风险是写成"反对一切作业"，本文用"专业判断"一段主动化解，这是重要的避坑动作。

## 五、3 篇病文诊断

### 病文一　偏题型

**题目要求**：根据题目 1 的材料（陶行知"教鞭、冷眼、讥笑"），自选角度，写一篇不少于 800 字的文章。

**病文（约 310 字，节选）**

> 教师是人类灵魂的工程师。作为一名教师，首先要有爱心。没有爱就没有教育。我们应当关心每一个学生，爱护每一个学生，让学生在爱的阳光下茁壮成长。
>
> 其次，教师要不断提高自己的业务水平。只有知识渊博，才能上好课。教师要钻研教材，认真备课，把每一节课都上成精品课。同时还要学习先进的教学方法，运用多媒体手段，激发学生的学习兴趣。
>
> 再次，教师要为人师表。教师的一言一行都会影响学生，所以教师要严格要求自己，做到言行一致，表里如一。
>
> 总之，教师要做到有爱心、有水平、有师德，才能成为一名合格的人民教师，才能为祖国的教育事业贡献自己的力量。

**诊断**

1. **偏题**：材料的核心是"否定性评价会埋没潜能"，病文把它替换成了"教师要有爱心、有水平、有师德"这一组通用口号。全文没有出现"标签""期待""冷眼"任何一处与材料直接呼应的概念，属于"背模板、套材料"，三类文偏下。
2. **空洞**：三个分论点都是结论，没有一处"为什么"，也没有一个人物、事件或课堂场景。全文没有一句引用材料，等于放弃了材料的支撑。
3. **结构**：三段是并列的"教师素质清单"，彼此没有逻辑关系，也无法递进；结尾是把分论点再说一遍，没有升华。
4. **语言**：通篇是"要……要……要……"的祈使句，缺少自己的判断句，读起来像倡议书而不是议论文。

**修改方向**

- 把中心论点改成一句有判断的话，如"教师不应过早给学生下结论"，并在开头直接引用材料中的"冷眼""讥笑"。
- 三个分论点改为递进：标签如何影响学生 → 期待怎样落地 → 教师为何要等，每段补一个具体事例。
- 删掉"业务水平""为人师表"等与材料无关的内容，宁可只写三点写透，也不要写五点写空。

### 病文二　空洞型

**题目要求**：根据题目 2 的名言（叶芝"教育不是注满一桶水，而是点燃一把火"），自选角度，写一篇不少于 800 字的文章。

**病文（约 300 字，节选）**

> 教育是一门艺术，是一门科学，更是一项伟大的事业。古往今来，无数教育家为我们留下了宝贵的思想财富。今天，我们更要重视教育，因为教育关系到国家的未来、民族的希望。
>
> 点燃一把火，就是要有热情。教师要有热情，学生要有热情，课堂要有热情。有了热情，一切困难都可以克服；有了热情，一切奇迹都可以创造。让我们都来做有热情的人吧！
>
> 点燃一把火，还要有方法。方法是多种多样的，可以表扬，可以鼓励，可以引导。只要我们用心，就一定能找到适合的方法。
>
> 同学们，让我们一起努力，点燃心中的火，照亮前方的路，为实现中华民族伟大复兴贡献青春力量！

**诊断**

1. **空洞**：全文只有"热情""方法""努力"三个大词，没有一个具体的人、事、课、书。所谓"方法是多种多样的"，等于什么都没说；"用心就一定能找到适合的方法"，是典型的循环论证。
2. **偏离文体与身份**：结尾"同学们，让我们一起努力"把议论文写成了演讲稿，且对象错位——考场作文的读者是阅卷教师，不是同学。人称一旦滑向"我们大家"，论证就散了。
3. **审题不落地**：材料的关键是"注满"与"点燃"的对比，病文完全没有辨析这两个概念，也没有回答"为什么点燃比注满更重要"，只是把"点燃"当成"热情"的同义词。
4. **结构**：开头三段都在讲"教育很重要"，与题目无关；两个分论点之间没有逻辑关系；结尾直接跳到"民族复兴"，属于拔高式跑偏。
5. **语言**：排比句密集但内容重复，"热情"一词出现 6 次，没有一个反例、一个细节。

**修改方向**

- 开头用一句话完成概念辨析："桶里的水是被倒进去的，火是自己在烧"，立刻建立对比框架。
- 每个分论点必须配一个具体材料：一节算地砖面积的数学课、一次被当众朗读的作文、启功临帖，任选其二。
- 结尾改成"我"的视角（未来教师），落点小而实，不要跳到"民族复兴"。
- 通篇删掉"热情"一词，改用可验证的行为描述："把'背下公式'换成'算算你家水费'"。

### 病文三　结构松散型

**题目要求**：根据题目 5 的材料（教育是慢的、不要把孩子弄丢），自选角度，写一篇不少于 800 字的文章。

**病文（约 300 字，节选）**

> 现在的教育太卷了。孩子们每天写作业到十一点，周末还要上各种补习班。有的孩子才上小学就戴上了眼镜，有的孩子因为压力太大学会了撒谎。这都是因为家长太焦虑。
>
> 我的表弟就是一个例子。他上四年级，每天作业写到十点半，周末要上三个补习班。有一次他跟我说，他最想做的事情是"什么都不做"。听到这句话，我很难过。
>
> 所以，教育应该慢下来。慢下来，孩子才有时间玩；慢下来，孩子才不厌学；慢下来，家长才不焦虑；慢下来，老师才不累。慢，是一种智慧，也是一种境界。
>
> 我们应该向国外的教育学习。芬兰的教育就很好，他们不排名，作业很少，孩子很快乐。所以中国的教育应该改革，减少作业，取消考试，让孩子快乐成长。

**诊断**

1. **结构松散**：第一段谈"太卷"，第二段讲"我表弟"，第三段是四个"慢下来"的排比，第四段跳到"芬兰"，四段之间没有论证关系，只是四个话题并置。全文没有一个贯穿的中心论点。
2. **以叙代议**：表弟的例子占了整段，但只停留在"我很难过"的情绪层面，没有分析"作业多"与"厌学"之间的机制，也没有回扣"慢"这一主题。
3. **观点绝对化**：结尾提出"取消考试"，属于情绪化主张，既不符合现实也不符合材料——材料说的是"尊重节奏"，不是"取消评价"。这种极端结论会被直接判为三类文。
4. **审题偏差**：材料中教师的落点是"是不是我们跑得太快，把孩子弄丢了"，指向教师的反省；病文把矛头全部指向"家长焦虑"和"中国教育"，主体错位。
5. **语言**：第三段四个"慢下来"内容重复（玩、不厌学、不焦虑、不累），属于同义反复，没有层层推进。

**修改方向**

- 先立一句中心论点："教育应尊重成长的节奏，慢是另一种快"，然后拆成三个递进分论点：成长有节气 → 慢是专业判断 → 慢是留白。
- 表弟的例子要压缩到 60 字以内，并加上分析："他不是不想学，是已经没有力气学了——这正是'赶'的代价。"
- 删掉"取消考试"这类极端主张，改为可操作的温和建议：分层作业、无作业日、过程性评价。
- 把"芬兰"改为一句带过，避免变成中外对比的泛论；主体应回到"教师能做什么"。

## 六、考场写作流程（考前最后看一遍）

| 步骤 | 时间 | 动作 |
| --- | --- | --- |
| ① 审题 | 3 分钟 | 圈出材料中的关键词与矛盾对；用一句话写出"材料在说什么" |
| ② 立意 | 5 分钟 | 把这句话升级为判断句（"应当……""……比……更重要"），确认它教育味足、不偏激 |
| ③ 定分论点 | 5 分钟 | 写 3 句分论点，检查是否有递进、是否重复；每句后面配 1 个材料 |
| ④ 列提纲 | 2 分钟 | 标题 + 5 段首句 + 2 个金句 |
| ⑤ 写作 | 40 分钟 | 按提纲写，开头不超过 130 字，每段 180—220 字 |
| ⑥ 检查 | 5 分钟 | 看标题、字数（≥800）、错别字、分论点句是否独立成句、结尾是否回扣 |

**最后三条提醒**：字迹工整比文采更值钱；标题必须有；无论多急，结尾一定要写完整——没有结尾的文章通常直接掉一个等级。
