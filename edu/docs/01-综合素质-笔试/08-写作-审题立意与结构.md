# 08 写作 · 审题立意与结构

> 一句话定位：综合素质能不能过，一半看作文。而作文能不能上 40 分，**95% 取决于“立意准不准”和“结构清不清”，而不是辞藻堆得多不多**。本讲义给的是可以背、可以直接套的模板。

---

## 一、评分标准与档次（先明确“写成什么样给多少分”）

### 1.1 硬性要求（不满足直接降档）

| 项目 | 要求 |
|---|---|
| 文体 | **议论文**（绝不写记叙文、散文、诗歌，绝不写“题记体”“书信体”冒险） |
| 字数 | 一般要求**不少于 800 字**，建议写 **900—1100 字**（不足 800 字按规则扣分，写太多会写不完） |
| 标题 | **必须自拟**，不能无题，不能照抄材料原句 |
| 立意 | 必须从材料出发，**不能脱离材料另立炉灶** |
| 卷面 | 字迹工整、不涂改、分段清楚（每段首行空两格） |

### 1.2 四档评分参考（各地细则略有差异，以下为通行框架，**最终以当次官方公告与评分细则为准**）

| 档次 | 分值区间 | 内容 | 结构 | 语言 |
|---|---|---|---|---|
| 一类文 | 41—50 分 | 切合题意，立意深刻，中心突出，材料充实，观点有启发性 | 结构严谨，层次清晰，逻辑自洽 | 语言流畅，有文采，表达准确 |
| 二类文 | 31—40 分 | 符合题意，中心明确，内容较充实，能联系实际 | 结构完整，条理清楚 | 语言通顺，偶有小瑕疵 |
| 三类文 | 21—30 分 | 基本符合题意，中心基本明确，内容单薄或堆砌 | 结构基本完整，段落划分不清 | 语言基本通顺，有语病 |
| 四类文 | 20 分以下 | 偏离题意、中心不明、内容空泛或不当 | 结构混乱 | 语病多，表达不清 |

**关键认知三条**

1. **一类文和二类文的差距，往往就是“立意深浅”这一层**。同样写“因材施教”，写“要尊重差异”是二类；写“尊重差异的本质，是把每个学生当成目的而不是手段”是接近一类。
2. **三类文的典型死法不是跑题，而是“空”**：通篇讲道理，没有一个具体事例，没有一个具体场景。
3. **四类文的典型死法就一个字：偏**。材料说“坚守”，你写成“创新”；材料说“合作”，你写成“竞争”。**偏题是 50 分作文最大的风险，防偏题比追求文采重要一百倍。**

### 1.3 阅卷老师的真实视角（三秒钟决定你的档次）

> 阅卷是“快速定档 + 微调给分”。老师通常先看**标题 + 首段 + 每段首句 + 末段**，二十秒内定下档次，再上下浮动 2—3 分。
>
> 由此推出一条极其重要的应试结论：
> **① 标题要一眼看出立意；② 首段要在 3 行内亮明观点；③ 每个分论点必须放在段首（而且要句式整齐）；④ 末段要回扣标题。**
> 这四个位置写好了，中间段落即使平实，也能稳在二类上、冲一类。

## 二、审题立意四步法（抓关键词 — 辨关系 — 定角度 — 拟论点）

### 第一步：抓关键词

材料再长，核心信息通常只落在 **2—4 个词**上。做法：

1. 用铅笔在材料里划出**反复出现的词**（重复 = 强调）。
2. 划出**评价性词语**（“可贵的是”“遗憾的是”“真正”“恰恰”）。
3. 划出**转折词后面的词**（“但是”“其实”“然而”后面的才是重心）。
4. 划出**人物说的那句话**（材料里如果有对话，那句话几乎就是题眼）。

> **判断标准**：如果从材料里提不出 2—4 个关键词，说明你还没读懂，不要动笔。

### 第二步：辨关系（最关键的一步，也是拉开档次的一步）

关键词找出来之后，**不要急着写第一个关键词，要先判断它们之间是什么关系**。这一步决定你会不会写偏。

| 关系类型 | 材料特征 | 立意方向 |
|---|---|---|
| 并列关系 | 两个词地位相当，如“爱与责任” | 两者**缺一不可**，要兼顾 |
| 递进关系 | 一个词是另一个词的基础，如“积累与飞跃” | 前者是**前提**，后者是**结果**，重点写“如何从前者到后者” |
| 条件关系 | “只有……才……”“没有……就没有……” | 明确写出**条件与结果**，不可倒置 |
| 对立统一（辩证） | 两个词看似矛盾，如“快与慢”“规则与自由” | **不走极端**，写“在……中求……”的辩证统一，**这是最容易上一类的立意** |
| 主次关系 | 一个明显是手段，一个是目的 | 分清**手段与目的**，不可本末倒置 |
| 因果关系 | 材料给现象让分析原因 | 写**原因 + 对策** |

> **高分规律**：材料给了**两个看似矛盾的词**时，最佳立意几乎都是“**辩证统一**”——既肯定 A，也肯定 B，指出二者在什么条件下统一、如何统一。**绝对不要选边站**（只写 A 好、B 不好），那是最容易掉档的写法。

### 第三步：定角度（选“教育者视角”最稳）

同一个材料可以从多个角度写，**对小学教资考生而言，最稳妥、最容易拿分的角度是“教师/教育视角”**。

| 角度 | 优点 | 风险 |
|---|---|---|
| **教师/教育视角**（推荐） | 贴合职业，易联系“立德树人”“因材施教”“师生关系”，阅卷最认可 | 泛泛而谈“教师要有爱”会落入俗套，需要具体化 |
| 个人成长视角 | 好写、有真情实感 | 容易写成“心灵鸡汤”，缺乏教师职业视角 |
| 社会/时代视角 | 有格局，易显深刻 | 容易空、容易喊口号 |
| 文化/历史视角 | 有文采、有底蕴 | 容易掉书袋，与教育主题脱节 |

**最佳组合**：**以教育视角为主，辅以社会/时代视角作提升**。即主体写“教育中如何做”，结尾提升到“这对民族未来意味着什么”。

### 第四步：拟论点（一句能立住的话）

论点必须满足三个条件：**① 是判断句（不是短语）；② 有明确的态度（不是“要重视”这种废话）；③ 能拆成 3 个分论点。**

**论点句式库**：

- `……的本质，是……，而非……`（对比式，最显深刻）
- `唯有……，才能……`（条件式，最稳）
- `……与……并不对立，真正的……是在……中……`（辩证式，最易上一类）
- `……不是……的选择题，而是……的必答题`（对举式，气势足）
- `让……成为……的……`（号召式，适合结尾段）
- `……的关键，不在……，而在……`（破立式，最有锋芒）

**四个层次的对比例子（同一材料“教师要学会等待”，看立意如何拉开档次）**：

| 层次 | 论点写法 | 评价 |
|---|---|---|
| 三类 | 教师要学会等待。 | 只有态度，没有内容，无法展开 |
| 二类 | 教师要学会等待，因为每个孩子成长的速度不同。 | 有了理由，中规中矩 |
| 一类下 | 教师的等待不是放任，而是为成长留出必要的时间与空间。 | 破立结合，有辩证 |
| 一类上 | 教育中的“等待”，本质上是对人的成长规律的敬畏——它不是消极的不作为，而是积极地创造条件、耐心地守候时机。 | 有概念界定、有辩证、有价值提升 |

### 2.5 三步演练（用真题式材料走一遍）

> **材料**：一位老师在作文批改中发现，有个学生写“我的理想是当一名厨师”，字里行间满是真诚。同事劝他：“你得引导一下，这理想不够远大。”这位老师却在评语里写道：“愿你做出让更多人记住的味道。”
>
> 请根据上述材料，自选角度，自拟题目，写一篇不少于 800 字的议论文。

**第一步 抓关键词**：理想、厨师、不够远大、愿你做出让更多人记住的味道。
**第二步 辨关系**：“远大的理想”与“平凡的理想”是对立统一关系（表面看高低之分，实质是价值评判标准之争）。
**第三步 定角度**：教师视角——教师如何看待学生的理想。
**第四步 拟论点**：

- 论点（推荐）：**教育的可贵，不在于把每个孩子都推向“高处”，而在于帮他在自己的位置上看见价值。**
- 分论点一：以“远大”为唯一尺度，是一种对成长的窄化。
- 分论点二：真正的尊重，是看见平凡理想里的郑重。
- 分论点三：教育的使命，是让每个孩子在自己的选择里活出尊严。

## 三、5 种万能结构（骨架 + 示例）

> 说明：`【】`内是可替换的变量。所有结构都要求**段首句整齐**，这是阅卷最看重的形式感。

### 结构一：并列式（最稳、最好写，保底二类）

**骨架**：

```
标题
【开头】引材料 + 亮论点（3—4 行）
【分论点一】【观点】…… 【阐释】…… 【例证】…… 【小结】
【分论点二】【观点】…… 【阐释】…… 【例证】…… 【小结】
【分论点三】【观点】…… 【阐释】…… 【例证】…… 【小结】
【结尾】回扣论点 + 提升
```

**示例（标题：让教育在平凡处生根）**：

- 开头：引“厨师理想”材料 → 亮论点“教育的可贵，不在于把每个孩子推向高处，而在于帮他在自己的位置上看见价值”。
- 分论点一：**尊重平凡，是承认每个生命都有自己的重量。**（例：张桂梅让山里女孩走出大山，也让留下的女孩成为乡村教师）
- 分论点二：**尊重平凡，是看见职业背后的郑重与热爱。**（例：一位厨师对火候的讲究，与科学家对数据的严谨，同属一种匠心）
- 分论点三：**尊重平凡，是教育公平最朴素的表达。**（例：不因成绩分层，不因家境定调）
- 结尾：教育的伟大，恰恰长在平凡的土壤里。

**适用**：任何“谈品质、谈做法”的材料。**考场首选**。

---

### 结构二：递进式（最容易上一类）

**骨架**：

```
【开头】引材料 + 亮论点
【第一层 是什么】界定概念：所谓【核心词】，是指……
【第二层 为什么】分析原因/意义：之所以需要【核心词】，是因为……
【第三层 怎么做】提出路径：要真正做到【核心词】，需要……
【第四层 反面/深化】如果不这样，会……（可选）
【结尾】升华
```

**示例（标题：等待，是教育最深的耐心）**：

- 是什么：真正的“等待”，不是放任不管，而是为成长留出时间与空间。
- 为什么：人的成长有节律，认知的成熟、习惯的养成无法被压缩；急于求成会让孩子把学习当成任务而非乐趣。
- 怎么做：①给时间——允许“慢一点”的进步；②给空间——允许试错；③给方法——等待不等于无所作为。
- 深化：若不等待，教育就会退化为“催熟”，得到的是一时的分数，失去的是一生的兴趣。
- 结尾：教育是农业，不是工业。

**适用**：“谈认识、谈理解”的材料（如“谈谈你对‘慢教育’的理解”）。**最容易显深刻**。

---

### 结构三：对比式（最有说服力）

**骨架**：

```
【开头】引材料 + 亮论点
【正面一】正面事例/道理 → 说明……
【正面二】正面事例/道理 → 说明……
【反面一】反面事例/道理 → 说明……
【反面二】反面事例/道理 → 说明……
【辩证段】并非……而是……（防止绝对化，必写）
【结尾】升华
```

**示例（标题：教育需要“慢”的定力）**：

- 正面：一位老师用一学期等一个沉默的孩子举手；苏霍姆林斯基带学生观察自然，一节课只讲几句话。
- 反面：为赶进度跳过实验、用题海代替思考、用排名定义孩子。
- 辩证段：**提倡“慢”不是否定效率，而是反对用效率取代规律。**
- 结尾：慢下来，才看得见人。

**关键提醒**：**必须写“辩证段”**。有对比无辩证，容易被判“片面”；有辩证，就从二类进一类。

---

### 结构四：引—议—联—结式（最适合“给一则材料谈看法”）

**骨架**：

```
【引】用 2—3 行概述材料，引出话题（不要抄材料全文）
【议】就材料本身作分析：这则材料说明了什么？为什么？
【联】联系现实/教育现场/时代：类似的现象还有……（这是主体，占 60% 篇幅）
【结】回到材料，收束升华
```

**示例（标题：一句评语里的教育温度）**：

- 引：老师给“想当厨师”的学生写下“愿你做出让更多人记住的味道”。
- 议：这句评语的可贵，在于它没有用“远大”去校正“平凡”，而是接住了孩子的真诚。
- 联：现实中有多少“善意”的引导，本质是把自己的标准强加给孩子；分数排序、特长鄙视链、家长的“为你好”……
- 结：教育的第一步，是看见眼前这个人。

**适用**：材料是**一个故事、一段对话、一则新闻**。**最贴题、最不容易偏**。

---

### 结构五：观点 + 分论点式（最像“标准答案”，最保险）

**骨架**：

```
【开头】一句总论点（独立成段，不超 3 行）
【分论点一】……（段首句为整齐的短句）
【分论点二】……
【分论点三】……
【辩证/升华段】
【结尾】
```

**示例（标题：以尊重为底色，绘教育之美）**：

- 总论点：教育要以尊重为底色。
- 分论点一：尊重差异，让每个孩子都有被看见的机会。
- 分论点二：尊重规律，让成长不急不躁。
- 分论点三：尊重生命，让教育有温度也有边界。
- 升华：尊重不是迁就，而是在理解基础上的引导。
- 结尾：以尊重为底色，教育才有美可言。

**适用**：任何材料，尤其适合**时间紧、求稳**的考场。**三个分论点句式要统一**（本例为“……，让……”）。

### 3.6 五种结构怎么选？（30 秒决策表）

| 材料长什么样 | 选哪种结构 |
|---|---|
| 一个故事/对话/新闻 | **引议联结式** |
| 一句名言/一个概念（谈理解） | **递进式** |
| 两个并列的词（如“爱与责任”） | **并列式** |
| 两个矛盾的词（如“快与慢”） | **对比式 + 辩证段** |
| 心里没底、只剩 45 分钟 | **观点+分论点式** |

## 四、10 个万能开头模板

> 开头任务：**3—5 行内完成“引材料 + 亮论点”**。不要铺垫、不要绕弯、不要写“自古以来”。

**模板 1（引材 + 转折亮论）**
> 材料中，【人物/现象】让人【感受】。然而在我看来，比这更值得追问的是：【核心问题】。我认为，【论点】。

**模板 2（现象切入 + 亮论）**
> 生活中常有这样的场景：【具体场景】。它看似寻常，却指向一个并不轻松的问题：【问题】。我以为，【论点】。

**模板 3（设问开篇）**
> 什么是真正的【核心词】？是【常见误解】，还是【另一种可能】？在我看来，【论点】。

**模板 4（对比开篇）**
> 有人把【核心词】理解为【理解 A】，也有人把它理解为【理解 B】。而我认为，二者并非只能择一，【论点】。

**模板 5（名言引入 + 落地）**
> 【可靠名言】。这句话在今天依然有它的分量：当我们面对【现象】时，尤其需要理解——【论点】。

**模板 6（细节描写 + 提炼）**
> 那一【细节】，很轻，却有分量。它让我想到：【问题】。是的，【论点】。

**模板 7（破题式，先破后立）**
> 谈及【核心词】，人们习惯把它与【常见关联】联系在一起。这当然不错，却未必完整。【论点】。

**模板 8（场景+教育视角）**
> 走进任何一间教室，你都能看到【场景】：有的孩子【状态 A】，有的孩子【状态 B】。这提醒我们：【论点】。

**模板 9（让步式，显成熟）**
> 我不能否认【对方合理之处】。但若止步于此，我们可能错过更关键的一点：【论点】。

**模板 10（时间视角，显格局）**
> 每一代人都在回答同一个问题：【问题】。今天的答案，写在我们对【现象】的态度里——【论点】。

> **开头三忌**：忌抄材料原文超过 3 行；忌用“随着社会的发展”“在当今社会”开头；忌写“我认为”三次以上。

## 五、10 个万能结尾模板

> 结尾任务：**回扣论点 + 提升一层 + 有余味**。不要出现新的分论点，不要说“综上所述”就草草收场。

**模板 1（回扣+升华）**
> 所以，【论点】。这不是一句空话，而是我们每一个教育者可以用每一天去回答的题。

**模板 2（比喻收束）**
> 教育是【比喻】，【解释】。愿我们都有这样的【品质】。

**模板 3（呼告式）**
> 让我们记住：【一句话总结】。当每一个【角色】都这样做时，【愿景】。

**模板 4（反问式）**
> 试想，如果连【角色】都不愿意【行动】，我们又凭什么期待【结果】？

**模板 5（引名句收束）**
> 【名言】。愿这句话，不只出现在我们的笔记里，也出现在我们的课堂上。

**模板 6（对照收束）**
> 【做法 A】得到的是一时，【做法 B】得到的是一生。我们该选哪一个，其实并不难。

**模板 7（回到材料）**
> 回到那【材料中的细节】，我读出的不只是【表层的 A】，更是【深层的 B】。

**模板 8（格言式，短句收尾）**
> 教育的路上，快的是方法，慢的是人心。守住慢的那一半，才守住了教育。

**模板 9（视野升华）**
> 一个孩子的今天，是一个民族的明天。【论点】，因此不只是教育问题，更是时代命题。

**模板 10（留白式）**
> 也许我们无法立刻改变什么。但至少，我们可以从【最小可行的做法】开始。

## 六、20 个标题模板

> 标题要求：**含核心词 + 有观点/有意境**，8—14 字为宜。**不要用问句单独做标题**（除非非常有把握）。

**A. 论点型（最稳，一眼见观点）**
1. 让【核心词】成为教育的底色
2. 【核心词】，是教育最深的【品质】
3. 以【核心词】育人，以【核心词】立身
4. 【核心词】，比【对比项】更重要
5. 教育需要【核心词】的定力

**B. 对举型（有张力，易得高分）**
6. 慢一点，才看得见人
7. 不追求“高大”，只求“站得稳”
8. 少一点催促，多一点等待
9. 别让“为你好”变成“替我选”
10. 分数之外，还有人在

**C. 比喻型（有文采）**
11. 教育是农业，不是工业
12. 让每颗种子按自己的季节开花
13. 做一盏灯，不做一把尺
14. 以尊重为底色，绘教育之美
15. 把讲台站成一片沃土

**D. 概念型（显深刻，适合辩证材料）**
16. 等待，也是一种作为
17. “不完美”的成长，才是真实的成长
18. 规则之内，方有自由
19. 平凡的理想，也有不凡的重量
20. 教育的力量，在于“看见”

> **标题自检三问**：①有没有写出我的观点？②有没有出现材料的核心词？③换成别的题目还能不能用？（若"能用"，说明你写得太泛。）

## 七、考场 50 分钟时间分配

| 时间 | 环节 | 具体动作 | 硬性产出 |
|---|---|---|---|
| 0—3 分钟 | 读题 | 划关键词、辨关系 | 圈出 2—4 个词 |
| 3—8 分钟 | 立意 | 走完四步法，写下 3 个候选论点，选一个 | **纸上写出最终论点一句** |
| 8—12 分钟 | 拟纲 | 定结构、写 3 个分论点段首句、给每段配 1 个例子 | **提纲（标题+论点+3 个分论点+例子）** |
| 12—15 分钟 | 拟题 | 从模板中挑一个改成自己的 | 标题一句 |
| 15—55 分钟（模拟 40 分钟写） | 成文 | 按提纲写，**开头和结尾多留时间** | 900—1100 字 |
| 最后 5 分钟 | 检查 | 标题、错别字、字数、末段是否回扣 | 修改 3—5 处 |

> **考场节奏提醒**：
> - **提纲一定要写在答题卡外的草稿纸上**，哪怕只有 10 行，它能防止你写到第三段就不知道该写什么。
> - **每段 180—220 字**，5—6 段最舒服。段太少（3 段）显得单薄，段太多（10 段）显得零碎。
> - **写不完时，优先保证结尾**。有结尾的三类文，比没结尾的一类文得分可能更高——**残缺的作文直接降档。**

## 八、常见跑题与偏题诊断（8 种病症 + 对症下药）

| 病症 | 表现 | 病因 | 处方 |
|---|---|---|---|
| ① 换词跑题 | 材料说“坚守”，你全篇写“努力” | 没抓准核心词，用近义词替换 | 写完标题后自问：核心词在标题里吗？ |
| ② 缩小跑题 | 材料谈“教育”，你只写“语文教学” | 角度取得太窄 | 概括层用大词，例证层用小例 |
| ③ 扩大跑题 | 材料谈“师生关系”，你写成“人类文明” | 拔得太高，脱离材料 | 每一段都要能回到材料 |
| ④ 选边站 | 材料给“快与慢”，你只骂“快” | 没辨清辩证关系 | 必须加“辩证段” |
| ⑤ 立意肤浅 | 通篇“要重视”“很重要” | 没有界定概念 | 用“本质是……而非……”句式 |
| ⑥ 材料堆砌 | 三个例子排比，无一句分析 | 缺“阐释”环节 | 每个例子后加一句“这说明……” |
| ⑦ 空喊口号 | 通篇“我们应该”“我们必须” | 没有具体场景 | 每段至少一个具体细节 |
| ⑧ 结构松散 | 段落之间无关联，想到哪写到哪 | 没写提纲 | 分论点用统一句式 |

### 8.1 “三段式体检法”（写完用 2 分钟自查）

1. **看标题**：标题的核心词，在首段出现了吗？在末段出现了吗？（两处都要有 → 不偏题）
2. **看段首**：把 3 个分论点的段首句单独抄出来，连起来读，是不是一句通顺的话？是不是都在支撑总论点？（是 → 不散）
3. **看末段**：末段有没有出现新的观点？（有 → 结构破了，改掉）

### 8.2 高频“材料—立意”对照表（提前想清楚，考场直接用）

| 材料核心词 | 常见浅层立意（二类） | 推荐深层立意（一类） |
|---|---|---|
| 等待 | 教师要有耐心 | 等待是对成长规律的敬畏，不是消极不作为 |
| 差异 | 因材施教 | 差异不是要被消除的缺陷，而是教育得以发生的资源 |
| 鼓励 | 多表扬学生 | 真正的鼓励是让学生看见自己努力的过程，而非只盯结果 |
| 规则 | 要遵守纪律 | 规则不是限制自由，而是自由得以共存的前提 |
| 失败 | 失败是成功之母 | 允许失败，是给创新留出必要的成本空间 |
| 平凡 | 平凡也伟大 | 平凡之所以伟大，在于有人在其中做到了“不苟且” |
| 阅读 | 多读书 | 阅读是与他人经验建立连接，从而扩大自己的世界 |
| 创新 | 要勇于创新 | 创新的前提是允许“无用的探索”，急功近利会杀死创新 |
| 合作 | 团结力量大 | 合作的难点不在“一起做”，而在“如何容纳不同意见” |
| 匠心 | 精益求精 | 匠心是对“差不多”的持续拒绝，是一种自我要求 |

## 九、3 篇考场作文提纲（可直接背结构）

### 提纲一：《等待，是教育最深的耐心》

- **材料**：一位老师面对一个始终不肯开口回答问题的学生，没有点名批评，只是每天课后多留十分钟，陪他把问题再说一遍。一学期后，这个孩子第一次主动举手。
- **立意**：教育中的等待不是放任，而是为成长留出时间与空间，是对成长规律的敬畏。
- **结构**：递进式
- **提纲**：

| 段落 | 内容 | 例证 |
|---|---|---|
| 开头 | 引材料 + 亮论点“等待不是放任，而是敬畏规律” | 材料 |
| 段二（是什么） | 界定“真正的等待”：不催促、不放弃、持续创造条件 | 反面衬托：“催促”式教育的常见样态 |
| 段三（为什么） | 人的成长有节律，认知成熟无法被压缩 | 苏霍姆林斯基主张让孩子在自然与活动中慢慢体会（教育理念层面） |
| 段四（怎么做之一） | 给时间：允许“慢一点”的进步，用纵向比较代替横向排名 | 原创示例：把“进步幅度”写进评语 |
| 段五（怎么做之二） | 给方法：等待不等于无所作为，要提供支架 | 原创示例：把大问题拆成小问题，让学生“答得出来” |
| 段六（深化） | 若只追求即时反馈，教育会退化为“催熟” | 反面：题海战术带来的兴趣流失 |
| 结尾 | 回扣标题：教育是农业，不是工业 | 收束升华 |

- **关键句**：“等待的背面不是无所作为，而是有准备的守候。”

---

### 提纲二：《让每颗种子按自己的季节开花》

- **材料**：某校运动会上，一个平时成绩平平的孩子在接力赛中跑出了全场最快的一棒，全班为他欢呼。班主任说：“今天我第一次看见他抬头。”
- **立意**：每个孩子都有自己的“高光时刻”，教育的责任是提供足够多的舞台，让不同的天赋被看见。
- **结构**：并列式（3 个分论点）
- **提纲**：

| 段落 | 内容 | 例证 |
|---|---|---|
| 开头 | 引材料（“第一次看见他抬头”）+ 亮论点 | 材料 |
| 分论点一 | **看见差异：单一尺度必然埋没天赋。** | 反例：只用成绩排名定义学生 |
| 分论点二 | **创造舞台：教育要主动提供多元的“被看见”的机会。** | 例：社团、劳动、体育、艺术活动中的岗位设置（原创示例） |
| 分论点三 | **给予确认：及时而具体的肯定，是自信的起点。** | 例：把“你今天跑得很好”说清楚好在哪里 |
| 辩证段 | 提供舞台不是降低标准，而是让标准多元化 | — |
| 结尾 | 回扣标题：让每颗种子按自己的季节开花 | 升华到教育公平 |

- **关键句**：“教育最残忍的事，不是孩子不够好，而是他从没被允许好一次。”

---

### 提纲三：《别让“为你好”变成“替我选”》

- **材料**：一位家长替孩子把兴趣班从“画画”换成了“奥数”，理由是“画画没用”。孩子不再说话，只是每天把画本藏在床底下。
- **立意**：真正的教育之爱，是尊重孩子的选择权，在引导中成全而非替代。
- **结构**：引—议—联—结式
- **提纲**：

| 段落 | 内容 | 例证 |
|---|---|---|
| 引 | 2—3 行概述材料 + 指出“床底下的画本”是无声的抗议 | 材料 |
| 议（1） | 家长的出发点未必是错的（承认合理），错在**把“有用”窄化为“可加分”** | — |
| 议（2） | 当“为你好”变成“替我选”，孩子失去的不只是兴趣，还有表达意愿的能力 | 心理学常识层面的分析 |
| 联（1） | 教育现场的同构现象：替学生选答案、替学生定目标、替学生写结论 | 原创示例：课堂上“标准答案”式的追问 |
| 联（2） | 时代层面的反思：我们需要的是能自主选择的人，还是只会执行的人 | 提升格局 |
| 结 | 回到画本：教育的第一步，是先问“你想要什么” | 回扣材料 |

- **关键句**：“教育的分寸，在于把选择权还给孩子，把判断力教给孩子。”

## 十、语言提升：三种立刻能用的论证方法

### 10.1 “三步例证法”（治好“堆砌例子”的病）

> **一句事例 + 一句分析 + 一句回扣**

示例：
> 一位老师用一学期等一个孩子举手。（事例）他没有用“点名”去逼出答案，而是用“多留十分钟”去造出一个可以开口的空间。（分析）可见，等待不是时间的空转，而是条件的创造。（回扣）

### 10.2 “让步—转折”句式（显得成熟、有思辨）

> 诚然，【对方合理之处】。但问题在于，【指出局限】。真正值得追问的是，【推进到更深一层】。

示例：
> 诚然，严格的训练能在短期内提高分数。但问题在于，分数只是学习的一个切面。真正值得追问的是，当外部压力撤走之后，这个孩子还会不会自己往前走。

### 10.3 “概念界定”句式（把立意拉深一层）

> 所谓【核心词】，并非【常见误解】，而是【你的界定】。这一界定的意义在于，它把问题从【表层】推到了【深层】。

示例：
> 所谓“尊重”，并非不加评判地顺从，而是先把对方当作一个有能力作出判断的人来对待。这一界定的意义在于，它把问题从“态度”层面推到了“关系”层面。

### 10.4 可以放心使用的引用（都是真实出处）

- 《礼记·学记》：“学然后知不足，教然后知困。……故曰：教学相长也。”
- 《礼记·学记》：“道而弗牵，强而弗抑，开而弗达。”
- 《论语·述而》：“不愤不启，不悱不发。”
- 《论语·雍也》：“知之者不如好之者，好之者不如乐之者。”
- 韩愈《师说》：“师者，所以传道受业解惑也。”
- 荀子《劝学》：“不积跬步，无以至千里；不积小流，无以成江海。”
- 陶行知：“千教万教教人求真，千学万学学做真人。”
- 陶行知：“你的教鞭下有瓦特，你的冷眼里有牛顿，你的讥笑中有爱迪生。”

> **提醒**：引用**宁少勿错**。不确定出处的名言，一律改成自己的话说出来——**编造名言是作文里最致命的失分点之一，一旦被阅卷老师发现，直接降档。**

## 十一、考前自查清单（写完照此打勾）

- [ ] 是否写了 3 个分论点，且段首句句式统一？
- [ ] 每一段是否都有“例子 + 分析 + 回扣”，而不是只有例子？
- [ ] 是否有辩证段（尤其材料涉及两个概念时）？
- [ ] 末段是否回扣标题、是否出现新观点？
- [ ] 字数是否在 900 字以上？
- [ ] 是否误用了不确定出处的名言？
- [ ] 是否有“待补充”式的空话、套话堆砌？
