> 一套**从入门到考场**的小学教资（笔试两科 + 面试）资料库：**58 份 Markdown 资料 + 1 份 Excel 打卡表**，合计约 **90 万字**、**1100+ 道成题**。

## 五、推荐学习顺序（详见 90 天计划）

```
第 1 天   读 00 目录的 4 份文档 → 打印 90 天计划 + 打开打卡表
第 2—45 天 两科讲义（按 01、02 目录顺序）→ 每节配套刷单选
第 46—75 天 主观题模板 → 材料分析/简答/教学设计专项 → 每周 1 篇作文
第 76—90 天 背诵手册 + 易混对比 + 口诀 + 4 套模拟卷（严格计时）
笔试通过后  03-面试（3 周：结构化 → 试讲稿 → 全真模拟）
```

**每天最低配比**：看讲义 30%、做题 40%、背诵/复盘 30%。**视频只作补充，不能替代做题。**

## 六、几点必须说明

1. **全部为原创整理**：知识点体系参考通行教材与现行法规，文字与题目均为原创，题目明确标注「原创模拟题，非官方真题」。
2. **不提供官方真题原文**：教资真题原卷官方不公布，市面流传的多为考生回忆版。`06-模拟卷与真题资源/00-真题获取渠道与使用方法.md` 讲清了怎么找、怎么辨别、怎么用。
3. **政策与法条口径**：以现行有效版本为准（《教育法》2021 修正、《未成年人保护法》2020 修订、《家庭教育促进法》2022 年施行、《中小学教育惩戒规则（试行）》2021 年施行、2022 年版义务教育课程方案与课程标准等）。
4. **考试时间以官方公告为准**：文中 2027 年上半年笔试/面试时间为按往年规律的**预估**，请以「中小学教师资格考试网 ntce.neea.edu.cn」和本省教育考试院公告为准。
5. **视频资源会变动**：链接失效时按名称在平台内搜索，不要执着于某一条。
