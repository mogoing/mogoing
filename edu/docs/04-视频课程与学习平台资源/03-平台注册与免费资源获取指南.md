# 平台注册与免费资源获取指南

> 这份指南解决"卡在注册这一步"和"不知道哪些钱根本不用花"两个问题。
> **核心结论先说**：教资备考的**必要支出只有报名费**（笔试按科目收、面试单独收，标准见各省公告）。视频课、题库、讲义、公开课，全部有免费且够用的版本。

> **总提醒：平台内容与链接可能变动，失效时请按名称在平台内搜索；以官方公告为准。**

## 二、逐平台注册要点

### 1. 中小学教师资格考试网：报名的 6 个细节

1. **提前注册**。报名开始当天系统拥堵，提前 1–2 天注册好账号、填好个人信息。
2. **照片一次拍对**：近 6 个月免冠正面证件照，白底，露出双耳双眉，不戴帽子头巾，不修图过度。尺寸与格式以报名系统页面提示为准（系统会校验，不合格直接传不上去）。
3. **学历/学籍信息**要能对上：在校生填学籍信息，社会考生填毕业证信息；异地报考可能需要居住证，**看你所在省份的报名公告**。
4. **报考科目一次选对**：小学综合素质（201）+ 教育教学知识与能力（202），两科一起报。
5. **审核通过后及时缴费**，逾期视为放弃。
6. **保存好报名号与密码**，查成绩、打印合格证明都用它。

### 2. 中国大学MOOC：3 分钟注册，别买证书

- 手机号/邮箱注册即可，无需学生证。
- **学习、看视频、下课件全部免费**；页面会引导你买"认证证书"（几十到几百元不等），**备考不需要**，除非你想留个学习证明。
- 注册后先"关注" 2–3 门课，平台会在开课时提醒你。

### 3. 国家中小学智慧教育平台：不注册也能用

- 直接打开 `https://basic.smartedu.cn/` 就能浏览课程教学资源。
- 需要收藏、下载部分资源时，用手机号注册，1 分钟。
- **不需要教师身份、不需要学校账号**，社会考生同样可用。

### 4. 学习强国：实名是"可选"

- 手机号注册后即可浏览、搜索。
- 实名认证主要影响积分、答题、部分互动功能，**备考不必强求**。
- 只做一件事：搜"教育家精神""师德""教师"，做素材摘抄。

### 5. B站：注册 1 分钟，关键是"怎么用"

- 手机号注册；不注册也能看，但清晰度与时长受限。
- 注册后**立刻做三件事**：① 关闭个性化推荐（减少娱乐干扰）；② 只关注 2 个教资 UP 主；③ 把学习相关视频加入"稍后再看"，不刷首页。

### 6. 国家图书馆：读者卡怎么办

- 到 `https://www.nlc.cn/` 看"读者指南—办证须知"，按提示线上或到馆办理。
- **虚拟读者卡**通常可远程使用部分数字资源；具体能访问哪些数据库，以国图页面说明为准。
- 即使不办卡，**国图公开课、文津经典诵读**也能直接看/听。

## 三、免费与付费边界（哪些钱不必花）

### 3.1 必须花的钱

- **笔试报名费**：按科目收，各省标准不同，见本省报名公告。
- **面试报名费**：单独收，见本省公告。
- **交通、住宿**（异地考试）、**打印费**（准考证、资料）。

### 3.2 可以花但不必花的钱

| 项目 | 常见价格区间 | 建议 |
|---|---|---|
| 机构系统班/全程班 | 数百至数千元 | **不必买**。本套资料 + 免费视频已覆盖考纲 |
| 押题卷/密卷/"内部资料" | 几十至几百元 | **不要买**。官方从不发布押题，无法核实 |
| MOOC 认证证书 | 几十至几百元 | 不需要，学习本身免费 |
| 付费题库会员 | 几十元/年 | 免费题库够用；想要错题统计可考虑 |
| 面试培训班（线下） | 数百至数千元 | 谨慎。真正有用的是"录视频 + 找人点评"，可找同学互评 |
| "命题人""考官"授课 | 高价 | **一律不买**。考官身份不会公开售卖课程 |

### 3.3 关于教材的一个重要事实

官方（教育部教育考试院）**只发布考试大纲，不指定、不出版配套教材**。市面上所有"官方指定教材"的说法都不准确，教材均为出版社或培训机构自行编写。

**结论**：不需要买多套教材。**一套讲义（本套资料）+ 一套真题/模拟卷 + 官方大纲**，足够。

## 四、用公共资源白嫖（图书馆是隐藏宝库）

### 4.1 你能免费用到什么

| 资源 | 获取方式 | 对教资的用处 |
|---|---|---|
| 省/市/区县公共图书馆读者证 | 持身份证到馆办理，通常免费 | 借纸质书、用馆内数字资源 |
| 图书馆数字资源（知网、万方、超星、龙源等，各馆不同） | 凭读者证在馆内或远程登录 | 查教育理论、下载教育名著电子书 |
| 国家图书馆公开课/文津经典诵读 | 直接访问 nlc.cn | 文化素养、名著导读 |
| 高校图书馆（仅在校生/校友） | 校园网或校友卡 | 教育学、心理学教材与期刊 |
| 城市书房、职工书屋、社区图书室 | 就地借阅 | 借《给教师的建议》等名著 |

> 各馆采购的数据库不同、远程访问权限不同，**以你当地图书馆的公告为准**；办证前先打咨询电话问一句"能不能远程用知网/超星"，能省一趟路。

### 4.2 三个具体用法

1. **借教育名著，不买**：《给教师的建议》《爱弥儿》《民主主义与教育》这类书，图书馆基本都有，借 1 本看 2 周即可。
2. **用超星/知网补理论**：遇到"建构主义""最近发展区"讲不清，去搜 1 篇综述文章，10 分钟看懂，比看 1 小时视频快。
3. **用图书馆自习**：家里学不进去就去图书馆，**环境本身就是执行力**。

## 五、倍速刷课与做笔记（真正决定效率的部分）

### 5.1 倍速建议表

| 内容类型 | 建议倍速 | 原因 |
|---|---|---|
| 科普/规划/导论 | 1.5–2.0 倍 | 信息密度低，听懂即可 |
| 系统课（知识讲解） | 1.25–1.5 倍 | 需要跟着思考，太快会断片 |
| 答题技巧课 | 1.25 倍 | 要看清步骤，不能跳 |
| 试讲示范 | **1.0 倍** | 要听语速、停顿、语气，倍速会失真 |
| 冲刺带背 | 1.5–2.0 倍 | 只为唤醒记忆，不求新学 |

**关键**：倍速不是目的。**看完能用 3 句话复述，才叫看完**；复述不出来，退回 1.25 倍重看那一段。

### 5.2 视频笔记三栏法（推荐）

把一页纸竖分三栏：

| 左栏：老师讲的 | 中栏：我的理解 | 右栏：怎么考 |
|---|---|---|
| 关键概念、口诀、框架 | 用自己的话写一遍 | 题型、分值、常见陷阱 |

- 左栏**只记讲义上没有的**，讲义的原文不抄。
- 中栏是核心：**必须用自己的话**，写不出来说明没懂。
- 右栏决定这份笔记有没有用：不写"怎么考"，笔记就是废纸。

### 5.3 三种高效笔记法（按场景选）

1. **框架笔记**（入门/打基础）：只画层级结构，一个模块一页纸。
2. **对比表格**（易混点）：如"行为主义 vs 认知主义 vs 建构主义""教育目的 vs 培养目标"，一表胜十页。
3. **错题笔记**（强化/冲刺）：只记"题目 + 我错在哪 + 正确思路 + 同类题 1 道"，不抄题干全文。

### 5.4 费曼复述法（每天 5 分钟）

看完一节视频，合上屏幕，对着手机录音讲 3 分钟："今天我学了 ______，它的核心是 ______，考试会这样考 ______。"

回听录音，凡是"嗯、然后、就是"卡住的地方，就是你没懂的地方——回去看那 3 分钟。

### 5.5 防"假学习"自查（每周日问自己 5 个问题）

1. 这周我看的视频，能说出几个具体知识点？（说不出 = 白看）
2. 这周我手写了多少字？（少于 2000 字 = 输出不足）
3. 这周做错的题，我知道为什么错吗？（不知道 = 刷题无效）
4. 这周有没有一天完全没碰学习？（有 = 节奏断了）
5. 下周我要解决的一个具体问题是什么？（说不出 = 在漂）

## 六、账号与信息安全

1. **报名账号密码单独记**，不要和社交账号同密码。
2. **不要在任何"代报名""包过"网站填身份证号**。报名只在 ntce.neea.edu.cn 进行。
3. **不要买"内部题库""考前原题"**：既拿不到真东西，也可能泄露个人信息。
4. **警惕"教资包过""内部改分"**：成绩由教育部教育考试院统一发布，任何"改分"都是诈骗。
5. 社交平台上自称"考官""命题组"的账号，**默认不信**。

> **总提醒：平台内容与链接可能变动，失效时请按名称在平台内搜索；以官方公告为准。**

> 本资料为原创整理，仅供个人备考使用；考试要求以当次官方公告为准。
